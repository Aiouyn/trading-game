## Goal
Every 12 table and type in one place, with the privacy split built into the types: SEALED fields (rolls, `real`, `turnedBy`, session ids) live only in server rows, and the client `ConnectionEntry` type is the same whether the entry is hostile or legitimate.

## Imports
- T02-11 module contract; T02-06 stream registry (`conflict`, `world`); T02-07 deterministic ids. T03-05 reason-code catalog. T15A-02 `linkedAccounts`. T14A-08 protection, Rookie zone, dormancy, prestige. T13A-01 op-ban table (`opBanUntilTick` is written by 13).

## Implementation steps
1. Tables with owner `12`; SEALED columns tagged so the 02 delta filter (T02-13) never ships them.
2. `CODE12` binds the §3.8.1 classes to catalog rows: RANSOM→`CONFLICT_RANSOM`, CASH_LOOT→`CONFLICT_CASH_LOOT`, NPC_THEFT→`OPS_NPC_CREW_THEFT`, OP_COST_NPC→`OPS_COST_NPC`, BRIBE_NPC→`OPS_BRIBE_NPC`, BRIBE_PLAYER→`OPS_BRIBE_CORE`, DEFENSE_NPC→`OPS_DEFENSE_NPC`, DEFENSE_PLAYER→`OPS_DEFENSE_B2B`, OP_COST_PLAYER→`OPS_PI_FEE_B2B` (alias `CONFLICT_OP_COST_PLAYER`, E-46), HONEYPOT→`OPS_HONEYPOT_COST`, QUARANTINE→`OPS_QUARANTINE_FEE`, INFORMANT→`OPS_INFORMANT_FEE`, RECONNECT→`OPS_LOCKDOWN_RECONNECT`. COMPUTE_LEECH→`CONFLICT_COMPUTE_LEECH` (TRANSFER, E-46), FENCE→`OPS_FENCE_SALE_NPC` (TRANSFER from npcFirm, E-46; `CONFLICT_FENCE_HAIRCUT` dropped). The spec's `CONFLICT_*` names resolve through aliases.csv (E-46).
3. Deprecated aliases `OPS_RANSOM`, `OPS_LOOT_CASH` are never emitted.
4. Event schemas for every §5 row with their visibility.
