## Goal
Crime is a priced business: before confirming, the player sees success, detection, attribution and sanction bands; the roll is one replayable draw on the `conflict` stream, bounded by the L2 floor (no fortress) and the 0.90 ceiling (no sure thing).

## Implementation steps
1. `x = log2(AP/DP_eff) + bOp (+ strength bias)`; `pb = floor + (ceiling − floor)·σ(x)` if `AP ≥ DP_eff/8` (inclusive), else `(ceiling − floor)·σ(x)`; clamp to `[floorGate ? floor : 0, ceiling]`.
2. Roll `u ~ U(0,1)` on `streamKey12.conflict(tick)` in op id order; store `rollBreach` SEALED; success iff `u < pb`.
3. Catalog rows exactly as the §3.9 table; costs and prep marked [Quant]. Prep stored as ticks (1 real minute = 12 ticks).
4. Resolve: re-check op ban (a ban landing in P11 of the launch tick does not stop an already sealed op, §8 #12); vanished target unit → re-pick same class, none → FAIL with 50% refund.
5. Loud ops (C03, C09) emit `ops.incident_detected` on the `me` channel the same tick.
