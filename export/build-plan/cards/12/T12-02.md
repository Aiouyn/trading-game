## Goal
Wealth is attackable because breadth is scarce: depth grows with the square root of spend, but coverage is linear in budget units and capped at 1.3, so the weakest unit always lags. Heat raises exposure only, never breach or detection odds.

## Imports
- T11-?? `dpAi`, defense model tier (cached each game hour). T09A-01 business events; T10A-07 property events; 11 model and dataset events. T14A-08 prestige (heat). T03-06 payment rail for day-close defense postings.

## Implementation steps
1. Recompute per owner once per game hour, staggered `hash(ownerId) mod 30`.
2. `dpEff = (dpAi + dpMoney + 10)·coverage·patch·(1 + 0.2·soc)·(irActive ? 1.5 : 1)` [Quant: 40, 10, 0.2, 1.5 are spec constants]. Cyber ops never pick PHYSICAL; E5 only PHYSICAL.
3. Layer costs [Quant]: perimeter `perimeter_cost_per_unit`·units, endpoint $1,000·units, training $5,000·staff, monitoring $20,000·2^L, backups $10,000·businesses, legal $50,000·G, IR $100,000 per activation; alliance SOC $50,000·4^level from the alliance treasury.
4. Patch decay applied at day close as 0.02/24 per game day; lapsed VENDOR_LINK published via 15 filings.
