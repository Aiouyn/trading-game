## Implementation steps
1. Ops planner never shows victim presence; market-conduct view shows only the player's own surveillance gauge.
2. Tone lint runs in CI over op names, tooltips, news templates and Academy strings (forbidden-term list owned by Designer, E-46; engineering ships the lint, Designer edits the list).
3. **Tone lint data and matching (E-61).** Sources:
   - Primary (required): `specs/data/forbidden-real-world-terms.json` (Designer; v1.0.0, 372 entries, 7 categories, 27-name `allowlist`; rules in `README-forbidden-real-world-terms.md`). Missing or malformed (bad JSON, missing `categories`/`allowlist`, non-string term) → CI fails.
   - Optional second source: Trust & Safety's technique list (CV24 / V12 name list) once it exists. Missing file → skipped with an info log; present but malformed → CI fails. Its entries are merged as extra categories; the Designer allowlist still applies.
   - Matching: `terms` case-insensitive; `case_sensitive_terms` exact case (short acronyms: SEC, Fed, ECB, BTC…). Whole word, where a **word character is any Unicode letter, digit or underscore** (so `SEC_OFFENSE`, `BTC_npc`, `EUR30` do not match). A term that begins/ends with a non-word character (`€`, `£`, `¥`) has no boundary check on that side, so `€5` matches. A space in a term matches any whitespace run. Accents fold: accented and unaccented forms both match (Société / Societe). Every string is checked in both EN and FR.
   - Allowed: `dollar`, `dollars`, `$` (Federal Dollar). Banned: `euro(s)`, real ISO codes, `€ £ ¥`.
   - Allowlist overrides: a hit wholly inside an `allowlist` span (case-sensitive exact phrase) is not reported. `allowlist.patterns` (E-61 addendum) are regexes, matched case-sensitively against the whole token that holds the hit (tokens split on whitespace and markdown/punctuation, with `-` kept inside the token). First pattern: `^SEC-\d{2}$`, for internal screen ids SEC-01…SEC-14 only, so a bare `SEC`, `SEC-7` or `SEC-07x` still hits.
   - Scope (E-61 addendum): the list governs **in-fiction text only**. `scope_exclusions.rules[]` in the JSON hold `{id, file glob, section regex?, line regex?, categories?, reason}`. A hit is skipped only when every given field matches; the section regex is tested against any enclosing heading. The rules cover sign-in providers (Google/Apple), app stores, real-money pricing (EUR/USD/GBP/€, 21 §3.11) and backend security (19 §3.9, e.g. "credential stuffing"). Each rule is limited to the categories it needs, so a fiction term (e.g. Bitcoin) inside an excluded section still hits. Player-visible fiction is never excluded. Game content strings (`content/*.json`) are always fully in scope. No inline suppression in content (README false-positive policy).
   - **p10 bug, do not copy:** p10's `bannedIn()` (`src/world/text/banned.ts`, frozen, tests/ideas only) treats only letters as word characters, so it flags `SEC_OFFENSE` and `EUR30`. V3 `toneLint` must use the letter+digit+underscore rule above; do not port `bannedIn()`.

  - **AC-12-12-TONE-SOURCES** T&S file absent → lint runs on primary only; T&S file malformed → load throws; primary malformed → load throws.
  - **AC-12-12-TONE-UIFILES** (E-61 fix2) the lint CLI takes file paths and globs plus a UI mode (E-65) that scans every `strings.ts` and `about-data.ts` under `src/` (`src/apps/**`, `src/shell/**`, …) in all locales. In `.ts` files it extracts string literals, including template-literal text parts, and reports `file:line [category] term`. Fixture: a temp `src/apps/demo/strings.ts` with `` `… ${x} Goldman Sachs desk` `` on line 3 → exit 1 and `strings.ts:3 [real_companies_brands] Goldman Sachs` in the output; the same tree with only allowlisted/allowed strings → exit 0. Contract:
    - It prints every file scanned and the totals, so a 0-hit result shows its coverage.
    - Exit codes: 0 clean, 1 hits, 2 any error (missing or unreadable file, a glob with no match, a malformed term list, a timeout, or no inputs).
    - It never reads stdin.
    - Timeouts: per file (default 20 s) and total (default 300 s). Exceeding either exits 2.
  - **AC-12-12-COPY-NO-LITERALS** (E-66; T12-12 because no 17 UI card exists yet; move it to the 17A/17B card when one is written) `tools/copylint.py --ui ROOT` scans `src/**/*.tsx`. It flags JSX text with a letter, and string/template literals (including conditional branches) in player-visible props: title, aria-label, placeholder, alt, label, tooltip, children, … and any prop ending in Label/Text/Title/Message/Hint/Placeholder/Tooltip/Caption/Description/Heading.
    - Not flagged: whitespace or text with no letter; className/style/data-*/id/key/testid/href/type/role values; imports; strings.ts; test, spec and story files; dev-only routes (`exclude_globs`, e.g. /__ds); brand tokens in `copylint-allow.json`; lines marked `// copylint-ignore: <reason>`.
    - Self-test: `<button>Buy now</button>` and `title="Sell"` → exit 1 with both reported; `S.buy` → exit 0; a className-only file → exit 0.
    - Same contract as tonelint (no stdin, per-file and total timeouts, exit 0/1/2, coverage printed). It is report-only and not part of `assemble --all`.
  - **AC-12-12-TONE-CATALOG** lint over all spec-22 content (`content/*.json`) EN+FR → zero hits (renames of E-61 and its addendum applied: Mirage Dollar/MDOL, SECTOR, Corvane Macro Data).
