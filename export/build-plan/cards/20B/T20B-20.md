## Implementation steps
1. Playtest data: sessions and consent records are entered by staff through 21's console into the TM store; `playtestPlan` derives the required sessions for a gate from the changed modules and screen families; `playtestRecordsFor` produces G3/G4 checks (category E5_PLAYTEST); each confusion point becomes a ticket; de-identification is scheduled at ≤ 7 real days.
2. Rule 1 (no ranked solo play): for every public API path that can create a board, ladder, league, tournament or Hall of Fame entry, submit results from a sandbox run, a practice world and an imported run file; all must be rejected; board writers accept scores only from TickRecord-backed production (or server-run challenge) events (INV-SOC-004).
3. Rule 2: weekly challenges and the weekly AI tournament run only on the server with TOURNAMENT seeds committed before the lock.
4. Rule 3: no money, asset, rank, title, license, AI research or Reputation import path; Academy completion flags and sandbox-only badges stay in the Academy and sandbox; real-money cosmetics are account entitlements everywhere.
5. Rule 4: in the sandbox (any speed) and in practice worlds a verdict applies fines, op bans and the record entry only; no Held state is ever set (13 §3.10).
6. Rule 5: the ad service refuses sandbox and practice characters.
