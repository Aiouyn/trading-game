## Goal
Run, on the whole monorepo with every unit built, the structural checks behind 20 AT 9, 10, 11 and 37: the commerce paths can never reach `packages/engine` directly or transitively on the resolved module graph and no configuration can waive that (INV-STR-002, registered by 21); the engine bundle contains no commerce or ad module and the world host's deployment manifest holds no commerce-schema or ad-network credentials (INV-STR-003, -004, registered by 21 and 19); every intent kind in `packages/protocol` maps to exactly one engine handler and appears in its module spec's intent list (INV-STR-005, 19); and there is no intent kind, API path or support tool that imports sandbox state into an online character (20 §3.15 rule 3, AT 37). The checkers of the owning units are reused; this card supplies the whole-game runner, the fixtures that prove each check bites, and the `truth:structural` gate entry used by G0 and G2 (T20B-21).

## Implementation steps
1. Commerce graph (AT 9): build the module graph with the TypeScript resolver over the whole workspace (not grep); for every file under `COMMERCE_PATHS` walk imports transitively; any path reaching `packages/engine` (or a package that imports it) is a finding with the import chain. There is no allow-list, no inline disable comment and no CLI flag: `runStructural` ignores any such input and the test proves it (a fixture with a `// truth-ignore` comment still fails).
2. Bundle and manifest (AT 10): scan the built engine bundle's module ids and source map for `packages/platform/commerce`, the entitlement schema module and the ad module; scan every world-host manifest for keys matching the commerce DB role, entitlement schema DSN and ad-network key names (19's manifest schema lists the secret names).
3. Intent sync (AT 11): every kind in `packages/protocol`'s registry has exactly one IntentHandler across `ALL_MODULES` and appears in that module's spec §4 list exported to `docs/intents.json`; also every handler kind is in protocol (no orphan handlers).
4. Sandbox import audit (AT 37): no protocol kind matching `*.import_sandbox` or `*.import_run` and no kind whose payload schema accepts a run file or sandbox save; no API route and no admin support tool whose declared write targets include online character tables and whose input includes a sandbox or run-file reference (21's tool registry declares inputs and write targets; a tool without declarations fails the audit).
5. The STR-006/008/009 checkers of T20A-06 run in the same command so G0 has one structural entry.
