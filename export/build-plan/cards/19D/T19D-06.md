## Goal
Ship the web client as a PWA and as native shells (19 Rules 3.17.5, 3.17.6) and gate the client performance budgets of Rule 3.17.3 in CI and the device lab (19#55): trade screen first load <= `ui_js_budget_kb` (200 KB gzipped JS), tick render <= `ui_perf_tick_render_ms` (8 ms) on the reference mid-range Android device, 500-row lists at 60 fps (virtualized). Provides the offline screen data and the update-required path of 19 §7.

## Implementation steps
1. Structure (Rule 3.17.1): route groups `(marketing)`, `(account)`, `(game)`, `(store)` already exist (T19A-01, 17); the game shell is client-rendered after first load; HTTP reads via TanStack Query.
2. PWA (Rule 3.17.5): manifest via the metadata route; Serwist precaches the shell and static assets; `NEVER_CACHE` excludes every API path, the socket and market data; the offline screen (19 §7) renders `readMeSnapshot()` read-only with its tick. Web Push only for opted-in users; the server respects 15's cap (at most 5 per real day) and quiet hours.
3. Native (Rule 3.17.6): Capacitor wraps the static export of `(game)`; data only via socket and HTTP to the production origins; plugins for push, haptics on fills and alerts, secure storage for tokens and signing keys (`nativeSigner`), share sheet, biometric unlock of the session; CSP `frame-ancestors` allows the Capacitor origin (T19C-07). Update required (19 §7): on `bye UPGRADE_REQUIRED` native shows the store link; the gateway keeps current − 1 working for 14 real days (`proto_min_version`).
4. Budgets (Rule 3.17.3): CI `build` job runs `measureRouteJs` on the trade route and fails above 200 KB gzipped; Playwright `tick-render.spec.ts` replays 100 recorded `changes` messages (watchlist 50, one book, news, me) into the stores and measures the React commit time per tick through the Profiler API, failing when p95 > 8 ms under the reference device CPU throttle profile; `list-scroll.spec.ts` scrolls a 500-row virtualized list and asserts >= 60 fps (frame times <= 16.7 ms at p95). The device lab job runs the same specs on the reference Android device nightly; RUM samples (`client web vitals`, tick render) feed the metric of Rule 3.15.1.
5. City renderer budget (>= 30 fps, three.js instanced, chunks from the CDN) is measured by the same lab job against 17's city scene when that scene exists ("T17-??").
