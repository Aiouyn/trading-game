## Implementation steps
1. Field-for-field from §2.7–§2.9; `KnowledgeRecord` is PRIVATE to its character.
2. Ids: `hst_`, `chr`-scoped records keyed by (characterId, factId), `fct_`, `sec_`, `brf_`, `brk_` (in the E-26 id table and the lint allowed list, E-33).
3. Codes (E-33): `SECRET_PATH_FEE` is an alias of `WLD_ARCHIVE_PURCHASE`; `FACT_SALE_NPC` is a TRANSFER frm 5000 → player 4000. `CATALOG_GAPS_16C` is empty.
4. Event schemas for `world.history.entry`, `world.chronicle.published`, `world.tech.breakthrough`, `world.era.started`, `world.fact.learned` (PRIVATE), `world.fact.public`, `world.brief.issued` (PRIVATE).
