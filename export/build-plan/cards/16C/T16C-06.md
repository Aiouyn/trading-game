## Goal
Point each character to what matters to them, without ever telling them what to trade.

## Imports
- T16C-02 relevance (§3.9.3), T16A-06 open chains, T16A-07 telegraphed shocks, T16B-08 bills and elections; T16A-09 Research Desk depth.

## Exports
```ts
export function issueBriefs(ctx, characterId: Id, realDayIndex: number): OpportunityBrief[];   // ≤ 3, deterministic
export function dismissBrief(ctx, i: { briefId: Id }): void;   // kind weight −0.2 for 7 real days
```

## Implementation steps
1. Score `relevance × magnitude × uncertainty`; deterministic from the event log and the character's own public relations and holdings.
2. Text keys never contain a direction; a lint over brief templates forbids buy/sell wording.
3. Free players get the summary; Research Desk subscribers full depth with owner estimates.
4. Held characters may dismiss briefs (§4).
