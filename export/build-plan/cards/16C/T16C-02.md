## Goal
Make the world's past persistent, searchable and personally relevant.

## Imports
- T16A-08 newsworthiness (σ_h = nw × durationFactor); 15 `wywa` request and chapter recap, 14 Chapter Portrait (ports).

## Exports
```ts
export function maybeRecord(ctx, e: EngineEvent, nw: number, effectGameDays: number): void;   // σ_h ≥ 0.4
export function chapterChronicle(ctx, chapter: number): Chronicle;
export function sinceYouLeft(read, characterId: Id, sinceTick: Tick): HistoryEntry[];   // ≤ 7, σ_h × relevance

```

## Implementation steps
1. `durationFactor = min(2, 1 + log10(1 + days)/2)`; PERMANENT if σ_h ≥ 0.6 or a listed kind (elections, successions, eras, breakthroughs, listed-firm and bank bankruptcies, MAJOR shocks, Season Finals, Hall of Fame); else AGGREGATE_AFTER_YEAR (monthly digest per bloc after one real year).
2. Chronicle: top 25 world-wide plus 10 per bloc, ≤ 3 per subject, ties by entryId.
3. Since you left: relevance 1 holdings, 0.6 counterparties, 0.4 home city, 0.2 otherwise; reads only the character's own holdings (firewall).
4. Edge §8.19: anonymized authors appear as 'a former participant'.
