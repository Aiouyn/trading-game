## Goal
The shared delegation primitive: AIs (11), managers (09) and funds (08) act for a principal only within limits checked at P1.

## Imports
- T14A-07 principal licence caps. T03-17 NAV and positions of the scope. 13A gate for legal-risk tags.

## Exports
```ts
export function grantMandate(ctx, m: Mandate, contractId?: Id): Id|Reject;
export function validateMandateIntent(read, mandateId: Id, i: SealedIntent): Reject|null;   // called by 19 Rule 3.9 authority check
export function breakerCheck(ctx): number;   // P12
export function updateMandate(ctx, id, changes): void;   // tightening at tick + noticeTicksForChange; loosening immediate; revoke immediate
```

## Implementation steps
1. Validity: 0 < maxLeverage ≤ the principal's licence cap; 0 < maxPositionPctNav ≤ 1; 0 < maxDrawdownPct ≤ 0.9.
2. P1: kind allowed, asset class allowed, post-trade leverage and position on the scope, spend cap per game day, legal-risk tolerance, and the principal's own licences and holds.
3. Breaker: scope drawdown from the high-water mark > maxDrawdownPct → SUSPENDED_BREAKER (reduce-only) until re-enabled.
4. Fees: fixed per game day plus performance over the high-water mark, via `CTR_MANDATE_FEE` → `SOC_CONTRACT_PAYMENT` and `chargeP2P` (NPC managers: owner module's code).

## Test plan
  - **15#26** an order exceeding maxPositionPctNav is refused at P1; a drawdown beyond the limit sets SUSPENDED_BREAKER.
  - **AC-15A-07-1** tightening applies only at +noticeTicksForChange; revoke is immediate and positions stay open.
  - **AC-15A-07-2** a mandate with maxLeverage above the principal's licence cap is refused.
