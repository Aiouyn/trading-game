## Goal
What the engine can verify, it enforces: clause events run in a fixed order every tick, and missed payments become engine-verified breaches.

## Imports
- T15A-04 lifecycle. T15A-05 `chargeP2P`. T13A-03 `applySanction`/judgment debt via the 13A collector (shortfall). T03-19 statements (covenants). Ports for 09 (supply, service business), 11 (licence), 12 (op events) and 13 (bounty conviction); each defaults to 'not present', with INERT ACs.

## Exports
```ts
export function executeDue(ctx: PhaseCtx): number;   // P12, ordered by (contractId, clauseIndex)
export function onDayClose(ctx): void;               // per-period payments, covenants, retries
export function nonCompeteGate(read, entityId, intentKind, scope): Reject|null;   // P1 hook for biz.open
export function exercise(ctx, contractId, clauseIndex): void|Reject;
```

## Implementation steps
1. Order: due events sorted by (contractId, clauseIndex). Per-period payments post at the day close of the period end.
2. Default: an uncovered payment is retried at each day close for 3 game days, then it is a breach.
3. LOAN default: collateral is seized to the lender (gap code `CTR_COLLATERAL_SEIZE`; until the errata, `BNK_COLLATERAL_SEIZE`-style MOVE_QTY is not usable from 15, open question 1). Any shortfall becomes a judgment debt through the 13A obligation API (garnishment, floor).
4. LEASE: rent per period, and operating rights move to the lessee (09/10 port); missed rent → the lease ends and the deposit goes to the lessor.
5. REVENUE_SHARE: share × the day's positive operating profit.
6. OPTION: the premium is paid at activation; exercise before expiry settles from the collateral; otherwise it expires.
7. SERVICE_LEVEL SECURITY: when 12 records a successful op on a covered unit, refund refundPct × the period's fees in the next tick.
8. NON_COMPETE: refuse the restricted party's `biz.open` in scope at P1 with `NON_COMPETE`.
9. BOUNTY: paid on a 13 conviction in the class before expiry, otherwise returned.
10. PENALTY: auto-paid from escrow on its engine trigger.
11. GUARANTEE: the guarantor pays up to the cap on a covered breach.
12. SUPPLY / SUBCONTRACT: shares and penalties per the table (09 port).
13. ASSIGNMENT: refused when the assignee is linked to the assigner.
