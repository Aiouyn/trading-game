## Goal
Projects can stop, and existing buildings can change. Pausing costs site security; cancelling writes off spent cost and leaves a stalled shell as a sellable LAND prop with a 40% shell credit, while presale deposits go back in full; any later owner can resume. Renovation, grade upgrades, conversions and redevelopment are the only ways structures change.

## Imports
- T10B-07 / T10B-08: project, permits (DEMOLITION, heritage rules), budget and phases.
- T10A-06 / T10A-07: leases (vacate, buy-out at 3 months' rent), condition, props.

## Implementation steps
1. Pause ≤ 28 GD, no progress, daily security TRANSFER to frm (`PROP_SITE_SECURITY_NPC`). Cancel: spent cost written off (REVALUE via 03), parcel STALLED (ghost-tower archetype where personality allows), a LAND prop with residual value including the shell credit, `dev.cancelled` PUBLIC transition without name; presale deposits refunded from escrow in full (`ESCROW_REFUND`).
2. Resume by any owner at remaining budget × input-index change.
3. Renovation keeps tenants; grade upgrade is a RENOVATION_MAJOR project requiring vacancy; conversion requires all leases ended; demolition forbidden in heritage for old stock and for owned assets by any visual rule (LC08).
4. Strata (§8 edge 11): whole-building renovation needs ≥ 75% of area owners' consent.
