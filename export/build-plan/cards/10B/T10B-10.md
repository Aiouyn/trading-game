## Goal
The city grows and shrinks from the economy, not from a script. NPC developers start projects where pressure has been high for a week, up to a pipeline target and a city-wide start cap; parcels are chosen by a deterministic priority; low pressure lets pooled vacant stock decay; the land authority services new corridors when serviced land runs short; a new city opens as the active population grows. A credit crunch flows through this same machinery into a price-index drawdown.

## Implementation steps
1. Priority = 0.35·access + 0.30·adjacency + 0.20·demandFit + 0.15·planSuitability; tie-break stable parcel hash (no RNG). Adjacency is recomputed, never accumulated.
2. NPC starts each day close for each (district, use) with `pressureHighDays ≥ growth_days_required`; stop the same day pressure falls below the threshold (ongoing projects continue). Start cap per GD `clamp(start_cap_share × developed, 3, 120)`; player starts count but are never blocked; NPC starts queue behind them.
3. Decline: player-owned buildings never become derelict by a visual rule (only at condition 0); dormant owners' props never darkened (LC07, LC16). §8 edge 15 (zero demand): pressure floors at 0.5, rents fall ≤ 0.5%/GD.
4. Corridors: generate region if needed, grade roads, parcels SERVICED in priority order, next auctions include them; existing neighbourhoods never regenerated (§8 edges 7, 8).
5. New city (§3.2.3): bloc by the 10A rule, Wire announcement 5,040 ticks before opening.
6. Crisis path (§3.12): nothing scripted; this card's test harness drives 04 inputs and checks the price index.
