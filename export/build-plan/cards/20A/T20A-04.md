## Goal
Fix the shapes every harness run uses (20 §2.2 equivalence and shadow state, §2.3 tests and evidence, §2.4 harness worlds, populations, agents and runs) and provide the engine-agnostic headless runner: a loop that drives any world implementing `HeadlessWorldDriver` tick by tick, collects per-tick digests, evaluates "stop" conditions and records a `HarnessRun`. Unit 02's `stepWorld`/`TestWorld` and 20B's harness host plug a real engine in later. Also define the player run-file format (Rule 3.10.5) so sandbox exports can become regression cases.

## Implementation steps
1. Types and zod schemas exactly as in 20 §2.2–§2.4 (Date fields become ISO strings in persisted form). `permissions` is the literal 'PLAYER' only (Rule 3.5.2); the schema rejects anything else.
2. `runHeadless`: for i in 0..ticks-1: hooks.beforeTick(world.tick); d = world.step(); push; hooks.afterTick(d); record `firstFailure` on the first `!committed || failedInvariants.length > 0`; stop when `hooks.stop(d)` is true. Wall time via the injected `clock` (default `performance.now` in harness code). No wall clock enters `world`.
3. `compareDigestStreams`: first index where any of the three digests differ (Rule 3.3.1 triple), or length mismatch.
4. Run file: canonical encoding; `verifyRunFile` replays through the injected function (the 02 engine in 20B) and compares the final hash; a tampered file reports FINAL_HASH_MISMATCH (Rule 3.10.5, the report is still triaged).
