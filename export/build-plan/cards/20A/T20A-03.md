## Goal
Define how the Truth Machine names and derives world seeds (20 §2.5 `SeedRef`, Rule 3.10.1 seed sets with salts, rotation and visibility), the WITHHELD retirement rule (Rule 3.10.2, 20 §8 edge case 9), and the permanent regression-case format (`RegressionCase`, `ReproBundle`, FAST/NIGHTLY tiers, Rule 3.10.3) including a canonical on-disk encoding. This is harness code (apps/harness, Node allowed: fs, node:crypto) and needs no engine.

## Implementation steps
1. Schemas: zod objects matching the TS interfaces; `createdAt` is an ISO string in the file format (harness code may use Date).
2. `SEED_SETS` from Rule 3.10.1: DEV 1,000 TEAM NEVER [DEV,CI]; VALIDATION 1,000 GATE_SERVICE PER_CHAPTER [CI]; WITHHELD 400 GATE_SERVICE PER_CHAPTER [GATE]; REGRESSION GROWS TEAM NEVER [CI]; PLAYER_PRACTICE 10,000 TEAM NEVER [PLAYERS]; PLAYER_WITHHELD 1,000 SERVER_ONLY PER_CHAPTER []; TOURNAMENT 3 SERVER_ONLY PER_WEEK [] (revealed after results).
3. `deriveSeed`: bytes = UTF-8("tycoon-seed") ‖ UTF-8(set) ‖ uint32 BE(index) ‖ salt; SHA-256 via `node:crypto` createHash; lowercase hex. Index out of `[0,size)` -> SEED_INDEX_RANGE (REGRESSION unbounded). `salts.salt` returning null -> SEED_NOT_ENTITLED. The live world's seed is never derivable here (it is in no set).
4. `WithheldLedger.draw`: returns indices `nextFresh, nextFresh+1, ...` skipping retired; when indices reach 400, fresh indices continue past 400 under the same salt (20 §8 edge case 9: "fresh indices are drawn from the same salt; the set never reuses a retired index"). `retire` adds to the sorted retired list. Drawing a retired index directly via a `SeedRef` is refused by `assertUsable(ref)` (add as a method) with SEED_RETIRED.
5. `aggregateOnlyReport`: for WITHHELD rows returns `perSeed: 'HIDDEN'`; for other sets returns rows.
6. `caseFromViolation`: title `"<invariantId> at T<tick> (<partitionId>)"`, source 'INVARIANT', expected 'INVARIANTS_HOLD', status 'OPEN', tier 'NIGHTLY' until classified, `expectedDetail` = observed/expected. `validateCase` enforces: WONT_FIX_BY_DESIGN requires decisionRef matching /^(D\d{3}|R\d{2}|Y\d)$/; inline seeds only when the case is from DEV or REGRESSION (bundle.seedRef inline allowed; the check is that a `{set}` ref of WITHHELD/PLAYER_* is never stored inline).
