## Goal
The glue that turns the 04 rule cards into a running macro economy. It creates the genesis state, calls every 04 rule at the tick and in the order 04 §3.1 fixes, runs the 13-step macro day step at t = 719, keeps the input snapshot, the daily history and its pruning, and exposes the read api other modules import. It contains no new formula: every number comes from a function of T04-01 to T04-19. The `defineModule` call, intent handlers, invariants, reason-code and entity registration and the integrated reruns with 05 belong to T04-21; this card exports the parts T04-21 assembles.

## Implementation steps
1. **Genesis (`macroGenesis`)**, once, before tick 0. Order fixed: global first, then blocs in `BLOC_ORDER` (FDL, EUN, PYN, NKR, SRL), matching 04 §3.19 draw order.
   1. Global: `worldScale S0 = scaleTarget(N_a, p)` with `N_a = ports.players.activityWeighted(store)`; no players → `S0 = macro_scale_min = 0.2` (04 §3.2, edge 17). `globalRegime = 'EXPANSION'`, `globalRegimeSinceTick = 0`; `fearIndex = 22`, `riskAppetite` from T04-15 at F = 22; `financialStressIndex = 0`; `tariffLevel = 0.03`, `tariffBase = 0.03` (E-94 (a)); `worldTradeIndex = 100` (T04-15 genesis WTI exactly 100); `energyIndex = foodIndex = 100` (E-87 (5)); `aiRaceIndex 50`, `worldHackRate 0`, `geopoliticalTension 30` (T04-05 input defaults); the `mac.inputs` row `HOURLY` with `tick 0`, `staleKeys []` and values `rv21Gx 0.16`, `gxReturnToday 0` and the six `fsi.*` keys at 0, with `igCreditSpreadIndex` absent until its first non-null read (E-93 (2)); `chapterIndex 0`; `scheduler` via `chapterStart(ctx)` (T04-17); `stabilizer` row `mac.stab` with zeros and `lastPublishedReportTick = null`.
   2. Per bloc `b`: `appointGovernor(ctx, b, 'GENESIS', ports)` (draws `S.cbPersonality(b)`), then the output-gap estimate seed `ε0 = 0.005 × Z0` where `Z0` is the first draw of `macro.gapest:<b>` (E-62; T04-01b has no init function, so it is done inline here).
   3. Real side: `regime = 'EXPANSION'`, `regimeSinceTick = 0`; public `cycleLabel = 'EXPANSION'`, `cycleLabelSinceDay = 0`; `outputGap 0`; `realGdpIndex = potentialIndex = cpiLevel = coreCpiLevel = wageIndex = 100`; `π_core = π_headline = π_e1 = π_e5 = inflationTarget_b`; `u = nairu_b`; `rStar = rStar0_b`; `peNorm = ` content value (22) or 1 sample when missing (open point).
   4. `realRateGapSmoothed R̃0 = initialPolicyRate − π_e1,0 − rStar0` (E-87 (7)): FDL 0.0025, EUN 0, PYN −0.0075, NKR 0, SRL 0.035.
   5. Policy: `cb.policyRate = initialPolicyRate_b`, then `setCorridor(ctx, b)`; `credibility = credibility0_b`; `reserveRequirement = rrDefault_b`; `hHat = 0.5` (T04-07).
   6. Credit (E-87 (6), "T04-05 (d)"): `nominalGdp0 = genesisNominalGdp(b, S0, p)`; `credit = fromMoney(nominalGdp0)` (1.0 × nominal GDP), `creditGdp = 1.0`, `creditGdpTrend = 1.0`, `creditGap = 0`, `credit364 = null`, `credit0 = credit`.
   7. Fiscal: `debt = toMoney(initialDebtGdp_b × fromMoney(nominalGdp0), ccy_b)`, then `debt = launchDebtSplit(b, S0, p).debt` (E-97: the sub-1,000-unit residue is not issued, so `debt` equals the launch bond face exactly), `primaryBalanceGdp = initialPrimaryBalanceGdp_b`; remaining `FiscalState` fields per T04-10's own genesis note, else 0.
   8. FX: `spot = fx0_b`, `fairValueLn = pppLn0 = ln fx0_b`, `regime = fxRegime0_b`, `capitalControls = 0`; for b ≠ FDL `reservesFdl = openingReservesFdl(b, S0, p)` (T04-22, the amount T04-22 minted) and `reserveCoverMonths = mac_cbk_reserve_cover0_<b>` (E-93 (6)).
   9. Sovereign: `λ = λ0_b`, `depthIndex = 1`; then `recomputeCurve(ctx, b, 'GENESIS')`; `refreshPublicView(ctx, b)`.
   10. Calendar: `writeQuarterSchedule(ctx, 0)` and `writeQuarterSchedule(ctx, 91)` (current and next quarter, T04-02); `planQuarter(ctx, b, ports)` for quarter 0 per bloc.
   11. History: write day-0 rows only at the first day close (no row before tick 719). No negative tick is ever written (AC-04-02-PREGENESIS).
2. **P2 dispatch (every tick).** One handler, fixed order, all blocs in `BLOC_ORDER`; `macroBoundaries` stays empty so the order is not left to the engine's hook order:
   1. `cal.tickOfDay = 0`: `mirrorStabilizer(ctx)` (T04-19); on `QUARTER_OPEN` in `cal.boundaries`: `writeQuarterSchedule(ctx, startDay + 182)` (the quarter after next) and `planQuarter` per bloc; on `CHAPTER_OPEN`: `chapterStart(ctx)`.
   2. Releases: `releasesDue(store, tick)` → `postConsensus` / `publishRelease` per due row; each published bloc is marked for a `'RELEASE'` recompute.
   3. CB: guidance ticks → `guidanceAt` + mark `'GUIDANCE'`; decision ticks → `runMeeting(ctx, b, false, null)`, `setCorridor`, `macroprudentialAtMeeting`, `realignAtMeeting` (PYN only), mark `'DECISION'`; minutes ticks → `minutesAt` + mark `'MINUTES'`. Emergency (E-100 (c)): when `cb.pendingEmergency?.tick === now` → `runMeeting(ctx, b, true, pendingEmergency.triggers)` (clears the field), `setCorridor`, mark `'DECISION'`; it runs after step 2, so releases at t = 45 that tick are seen.
   4. Auctions: `announceDue(ctx, ports)`.
   4b. `cal.tickOfDay = 45`: `breakRuleCheck(ctx, b, ports)` for each b in `BLOC_ORDER` (FDL returns null) (E-104 (1): T04-14 step 5's break at t = 45 of the next trading day; it was never called). A break here changes the regime, so step 5 marks `'FX_REGIME'` on the same tick.
   5. FX regime events at their tick (T04-14 rows with `tick = now`): mark `'FX_REGIME'`. 08 rating action for `govId(b)`: mark `'RATING'` (detection: see Open points).
   6. Recompute: for each bloc in `BLOC_ORDER`, for each marked reason in the order RELEASE, GUIDANCE, DECISION, MINUTES, FX_REGIME, RATING: `recomputeCurve(ctx, b, reason)`, then `refreshPublicView(ctx, b)` once.
   7. `cal.tickOfDay % 30 = 0`: `hourlyFsi(ctx, ports)` (which calls T04-06 `scheduleEmergency` with the FSI trigger, E-100 (c)), then `hourlyFear(ctx, ports)` (04 §3.1 row 2; fear reads this hour's FSI, FSI reads no fear value, E-93 (1)).
   8. `cal.weekday = 0` and `cal.tickOfDay = 45`: `weeklyStabReport(ctx, stab)`.
   9. `cal.tickOfDay = 719`: `macroDayStep(ctx, ports)`; releases at t = 45 or 300 always ran before it (T04-16 note).
3. **Macro day step (`macroDayStep`, 04 §3.1 row 3)**, exactly this order:
   1. Inputs: `inputSnapshot` = `collectInputs(store, ports, prevInputs, tick)` reading data committed through tick 718; missing values hold the last value (edge 23); the stale keys are the union of `staleKeys` and the `HOURLY` row's `staleKeys` (sorted, no duplicates); if that union is non-empty emit `macro.input.stale { keys }` SEALED once, then set `HOURLY.staleKeys = []` and leave its values as they are (E-93 (2)). With `ports.credit = null` credit inputs come from 04 §3.14.4 (edge 18, 04#43).
   2. Global indicators and scale: `S ← stepScale(S, scaleTarget(N_a))` (≤ 0.5% shrink per day, floor 0.2; edge 17); `dailyTrade(ctx, ports)`; energy and food indices; `worldNominalGdpFdl`.
   3. Regimes: global regime first, then `stepRegime` per bloc (draw order 04 §3.19); `cycleLabelStep` writes `cycleLabel`, `cycleLabelSinceDay` to `mac.public_view` and emits `macro.cycle.declared` on change; `peNorm ← updatePeNorm(peNorm, peAgg)` before `imbalanceZ`.
   4. Real side: `smoothRealRateGap`, `gapTerms`, `stepOutputGap`, `stepOutputGapEstimate`, `stepLevels`, `stepUnemployment`, `wageGrowth`, `stepNeutralRate`; `nominalGdp_b = nominalGdpLocal(...)`.
   5. Inflation and expectations (T04-05; E-87 (2): core → level → headline → e1 → e5); `creditAggregates(nominalGdp, { credit, creditGdpTrend, credit364, credit0, days: gameDay }, supplied)`. `credit364` = the `credit` value of day `gameDay − 364` (see Open points), null before day 364.
   6. Fiscal: `stepFiscalDay`, `postFiscalCash`, `swfStep`, `runFiscalRuleChecks`, `handleProgramSpend`, `acceptProposals`; quarter end: `quarterFiscalEvent`, `quarterEndDealerReview`.
   7. Sovereign credit: `stepSovereignCredit`, `igExclusionCheck`, `checkDefaultTriggers`, `stepDefaultCase`.
   8. FX: `stepFxDay(ctx, ports)`, `stepCapitalControls`, `concordTranches`, `swapLineStep`.
   9. Curves: `recomputeCurve(ctx, b, 'DAY_CLOSE')` per bloc.
   10. Macroprudential: `macroprudentialRelease` per bloc.
   11. Crisis scheduler: `stepPhases`, `emergentCheck`, `schedulerDay`. Then, per bloc in `BLOC_ORDER`: `scheduleEmergency(ctx, b, emergencyTriggers({ day-close FSI, eqDrop5d, interbankSpread, fxDrop3d, majorPolicyHere = a crisis in b entered POLICY today }), tick)` (T04-06, E-100 (c)).
   12. Stabilizer: nothing to compute (04 runs no controller); T04-19 handles the mirror and report.
   13. Emit: `writeHistoryRows`, `pruneHistory`, `refreshPublicView` per bloc, `publishMsi`, daily PUBLIC events of the steps above; every PUBLIC payload passes `assertNoHiddenFields` in tests.
4. **P4**: `applyPoolFills(ctx, ports)` for fills of the previous tick, then `writePoolOrders(ctx, ports)` and on rebalance days `reserveRebalanceOrders`. **P6** (auction ticks): `clearAuction` then `settleAuction` per auction in id order. **P8** (t = 719): `facilityDaily`, `postInterestOnReserves`, `remitProfit` per bloc. 04 posts no coupon or redemption (E-104 (3)); 04 exports the schedule `sovCase.payments` and 06 posts servicing. **Same-day order (E-101):** auction settlement (P6 at `macro_auction_tick` = 330) and syndication settlement (pricing tick 420, T04-12) commit in P13 of their own tick, so on a day with both, settlement posts before that day's coupons and redemptions; those are 06's DAY_CLOSE P2 postings at t = 719 (T06A-08 step 7); with 06 absent there are none (E-104 (3) strikes "04 P8 with 06 absent"). Constraint: `macro_auction_tick < 719` and the syndication pricing tick `< 719` (at 719, 06's P2 would post before 04's P6). Tested by AC-04-11-SETTLEFIRST.
5. **History.** `writeHistoryRows` writes `DailyHistoryRow` id `${key}:${gameDay}` for each bloc and `GLOBAL` from the post-step state. The GLOBAL row's `equityIndex` is `ports.markets.gxLevel(store)` read at the day close, null when the port returns null; it is never filled with a held value (the hold lives in T04-15's HOURLY `gxReturn63d`, E-103 (4)). `pruneHistory` deletes rows with `!keepHistoryDay(day, today)`; month starts are days `91q`, `91q + 28`, `91q + 56` (T04-02 months 28/28/35).
6. **peNorm.** `DailyHistoryRow` has no `peAgg`, so an exact 5-game-year trailing mean cannot be computed; `updatePeNorm` uses a 1820-day running mean, `peNorm + (peAgg − peNorm)/1820`.
7. **api.ts** functions are pure reads of `mac.*` rows. `factorJumps` converts `releaseRiskReactions` of the tick into 05 factor jumps with `causeId = releaseId`. `scheduledMandateFlows` returns hook rows written by T04-07 `igExclusionCheck` (10 trading days) and T04-09 reserve rebalancing (quarterly).
8. RNG: no draw in this card except through called functions; streams registered by their owning cards, listed in `ModuleDef.streams` by T04-21.
