## Goal
Carry the E-45 items moved off T04-01 by E-54: the region-slug to canonical-bloc normaliser, the public `DailyHistoryRow.outputGapEstimate` field and its per-bloc AR(1) update, and a strict check that the published `macro.cb.decision` ruleTerms object has exactly the spec'd keys.

**Amends merged PR #17 (E-54 item 6, Producer ruling).** This card edits #17's `packages/engine/macro/events.ts` (the `macro.cb.decision` ruleTerms schema goes from 6 to 7 strict keys, adding `outputGap` = coef × outputGapEstimate, published at 0.25 pp) and `schema.test.ts` (the test "never publishes the output-gap term" flips to AC-04-01b-RULETERMS-KEYS and AC-04-01b-NOTRUEGAP).

## Implementation steps
1. `regionSlug.ts`: the E-45 region map (avalon→FDL, meridian→EUN, kaiyo→PYN, nordhaven→NKR, sundara→SRL). Slugs are ids only and are normalised at the content boundary; display names come from 22.
2. `DailyHistoryRow.outputGapEstimate` is added to the T04-01 interface and the `history` table (formerly a T04-01 field). It is public; `outputGap` stays in `HIDDEN_FIELD_NAMES`.
3. **outputGapEstimate** (formerly T04-01 step 7c; E-45, E-43 PROVISIONAL [Quant]): at each day close per bloc, ε ← 0.98·ε + 0.005·√(1 − 0.98²)·Z with Z from stream `macro.gapest:<bloc>` (one draw per bloc per GD; 02 §3.10.4 row); `outputGapEstimate = outputGap + ε`.
   - **Initial state (E-62, Quant ruling):** at genesis, ε0 = 0.005·Z0, where Z0 is the first draw of stream `macro.gapest:<bloc>` (stationary start). The AR(1) update above runs from there with no burn-in, and day-close draws continue from the second draw of that stream.
4. `RULE_TERMS_KEYS` = the 04 §2.1 `ruleTerms` keys (04 :258): neutral, inflation, inflationGap, outputGap, finStress, fx, bias. E-45 changes only rounding (published 0.25 pp) and the outputGap input (coef × outputGapEstimate), not the keys. The `ruleTerms` sub-schema of `macro.cb.decision` is `.strict()` over exactly these keys.

## Test plan
`gapest.test.ts`:
  - **AC-04-01-SLUG** (E-45) `blocOfRegionSlug('avalon'|'meridian'|'kaiyo'|'nordhaven'|'sundara')` → FDL/EUN/PYN/NKR/SRL; an unknown slug throws; no FU/EC/PL/NA/SC or slug key survives past the content boundary (static scan of `BLOC_DEFAULTS` keys = canonical codes); each sectorWeights row sums to 1.000.
  - **AC-04-01-GAPEST-STATS** (E-45, E-43 PROVISIONAL [Quant]) over 10,000 ticks (≥ 13 GD × 5 blocs pooled to ≥ 10k day-steps in the harness), the empirical stationary σ of ε is within ±10% of 0.005 and the lag-1 autocorrelation within ±10% of 0.98.
  - **AC-04-01-GAPEST-DET** (E-45) same seed → identical ε paths; adding the `macro.gapest:<bloc>` stream leaves every other stream's draws and the baseline world hashes of all fields other than `outputGapEstimate` unchanged (02#18).
  - **AC-04-01-GAPEST-LEAK** (E-45) no PUBLIC event or view contains `outputGap` (true value); `outputGapEstimate` − `outputGap` is never 0 for > 1 consecutive GD on any seed.
  - **AC-04-01b-RULETERMS-KEYS** (E-54; 04 §2.1 :258, §5 :1123, E-45 item 5) the `ruleTerms` object of every emitted `macro.cb.decision` payload has exactly the key set {neutral, inflation, inflationGap, outputGap, finStress, fx, bias}, no more and no less: `Object.keys(ruleTerms).sort()` equals `[...RULE_TERMS_KEYS].sort()`; the strict schema rejects a payload with an extra key (e.g. `hawkishness`) and one missing a key.

  - **AC-04-01b-GAPEST-INIT** (E-62, Quant) at genesis each bloc's ε0 equals 0.005 × the first draw of its own `macro.gapest:<bloc>` stream. It is deterministic per seed: the same seed gives the same ε0, and different blocs draw from their own streams, so their ε0 values are independent. No burn-in steps occur before the first day close.
  - **AC-04-01b-NOTRUEGAP** (E-54 item 6) the true output gap x, or coef × x, never appears in any public payload, event, view or log reachable by players (HIDDEN_FIELD_NAMES scan, 04#15). The published `ruleTerms.outputGap` equals the 0.25 pp rounding of coef × outputGapEstimate. In a seeded test, wherever ε ≠ 0 it differs from the 0.25 pp rounding of coef × x on at least one decision. The schema test rejects `outputGapTerm` and any true-gap field (e.g. `outputGapTrue`, `trueOutputGap`).
