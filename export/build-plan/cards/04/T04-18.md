## Goal
What each crisis is and does. The 15 major kinds with their eligibility, base weight and vulnerability (which make crises caused by real imbalances), their precursor, trigger and contagion shocks on 04 variables, the hook calls other modules implement (equity risk premium, corporate PD, deposit confidence, repo haircuts, stablecoins, commodity supply, AI race, market makers, house prices, pools, zero-days, politics), each crisis's specific policy response, the storm and ripple effects, and the emergent labels that open a WorldEvent record when rules have already produced a crisis. Every hook carries the WorldEvent id so 16 can build the causal chain.

## Imports
- T04-01: `WorldEvent`, `ActiveShock`, `HookCall`, `CrisisKind`, `StormKind`, `RippleKind`, `BlocId`, `BLOC_ORDER`, `macroTables`, `MacroPorts`.

- T04-09: `openLtro`, `macroprudentialRelease`, QE mix override (`eligible` with corpIG or ABS), swap-line activation request.
- T04-10: `addProgram` (HOUSING, energy subsidy and trade support programs, `source: 'CRISIS_RESPONSE'`).
- T04-14: `setCapitalControls`, `openConcord`.
- T04-15: F and FSI values and components.

## Implementation steps
1. **Catalog (§3.16.4), exactly as the table, in this order** (eligibility / base / vuln; shocks scale with severity; durations in game days):
   - EQUITY_BUBBLE_BURST: valuation z ≥ 1 in a bloc with ≥ 20% world GDP / 1.0 / that z. Precursor: `erpShock(bloc, null, −0.003, ramp over the precursor)` (06), guidance hawkish tilt +0.2 (one-off on the next guidance score). Trigger: `erpShock(bloc, null, +0.025·sev, halfLife 120)`, `fear_add +25·sev` (DECAY 7), `x_target −0.015·sev` STEP 180 days. Response RULE_CUTS, CCYB_RELEASE. Calibration: GX −30% to −45% within 14–42 days (05), tech −60% (05), gold +15% (06).
   - CREDIT_CRUNCH: credit z ≥ 0.5 or rising default rate (07 port flag) / 1.0 / credit z. Precursor: IG spreads +5 bp per game week (`corporatePdMultiplier` ramp 1 → 1.2), `credit_conditions_add −0.1`. Trigger: `corporatePdMultiplier(bloc, 3, 120)` (07), `credit_conditions_add −0.6`, new-loan LTV −20 points (07 and 10 hook `ltvTighten(−0.20)`), `x_target −0.025·sev`. Response: RULE_CUTS (FSI term), QE_CORP_IG, LTRO.
   - BANKING_PANIC: ≥ 1 NPC bank below 1.2× its capital minimum or FSI ≥ 0.4 / 0.6 / (FSI − 0.3)/0.1. Precursor: `interbank_add +0.002`, bank equities −10% (05 value shock on the bank sector). Trigger: `depositConfidenceShock(weakest 1–3 NPC banks, −0.4·sev)` (07), `interbank_add +0.015·sev`, `fear_add +20·sev`. Response ELA, DEPOSIT_GUARANTEE (07 hook), RESCUE_MERGERS (16 and 07 hooks).
   - CRYPTO_WINTER: hype ≥ 0.5 or a stablecoin backing < 1.02 / 0.8 / 2(hype − 0.5)/0.5. Precursor: redemptions up (06 hook), exchange outflow rumors (16 WIRE_ITEM). Trigger: `stablecoinDepeg(assetId, 0.85 + 0.12·(1 − sev/1.4), days)` or `venueCollapse(venueId)` (06 picks the weakest; 04 passes the filter), hype → 0 (06). Response NONE (no CB backstop for crypto).
   - OIL_SHOCK: always / 0.8 / (tension − 40)/20. Precursor: tension +10 (16 hook), crude +5% (06 `commoditySupplyShock(CRUDE, −0.02, precursor)`). Trigger: `commoditySupplyShock(CRUDE, −0.08·sev, 60 + 120·u)` and `(GAS, −0.05·sev, same)`, `fear_add +15·sev`. Response LOOK_THROUGH_ENERGY (the rule already uses core), ENERGY_SUBSIDY (16 `fiscalProgramProposal`).
   - CURRENCY_CRISIS: SRL (or PYN) with cover < 9 or CA < −0.02 / 0.8 / (9 − cover)/3. Precursor: `capital_flow −0.2`, reserves fall (through flows). Trigger: `capital_flow −0.8` for 30 days (attack dynamics of T04-14), one-off `fx_fair_ln ln(0.90)`. Response BREAK_RULE, CONCORD.
   - SOVEREIGN_DEBT_CRISIS: some bloc λ ≥ 0.01 / 0.6 / ln(λ/0.01). Precursor: `auction_stress +0.05`, `politicalStabilityShock(bloc, −0.1, precursor)` (16). Trigger: `politicalStabilityShock(bloc, −0.3·sev, 63)`, `lambda_raw_mult ×3` for 63 days, `auction_stress +0.3`. Response CONCORD, AUSTERITY (programs via T04-10), restructuring if T04-13 triggers fire.
   - AI_BUBBLE: AI race ≥ 70 and semis valuation z ≥ 1 / 0.7 / (aiRace − 70)/10. Precursor: compute spot +20% (06 value shock). Trigger: `aiRaceIndexShock(−30·sev)` (11), compute demand −40% for 120 days (06). Response NONE.
   - CYBER_PANDEMIC: emergent only (hack rate ≥ 85 for 2 game days) / – / –. Trigger hooks for emergent are none (step 5). Response CYBERCERT_PATCH (12, 13 hook).
   - FLASH_CRASH: always / 0.6 / F/50. Precursor: generic (book depth −10%: `makerWithdrawal(ALL, 0.9, precursor ticks)`). Trigger: `makerWithdrawal(GX constituents, 0.2, 30)` and `npcSellProgram(GX constituents, 0.03, 20)` (05). Response CIRCUIT_BREAKERS (05's own).
   - HOUSING_CRASH: house gap ≥ 0.15 / 0.7 / house z. Precursor: mortgage approvals down (07 hook), listings up (10). Trigger: `housePriceShock(bloc cities, −(0.20 + 0.15·(sev − 0.6)/0.8), 180)` and `transactionFreeze(cities, 0.5, 180)` (10), banks −15% (05 value shock). Response LTV_RELEASE (T04-09 LTV to baseline), HOUSING_PROGRAM.
   - STAGFLATION: world headline inflation > 0.035 / 0.5 / (π_world − 0.035)/0.01. Precursor: `pi_e1_add +0.005`. Trigger: one-offs π_e1 +0.02·sev, π_e5 +0.008·sev, credibility −0.15 (all CBs), `commoditySupplyShock(CRUDE, −0.03, 90)`. Response RULE_HIKES.
   - SECURITIZATION_CRISIS: 08 underwriting quality ≤ 0.6 / 0.5 / (0.7 − q)/0.1. Precursor: ABS spreads up (08 hook), delinquencies up (07). Trigger: `correlationShock(MORTGAGE, +0.2)`, `pdShock(MORTGAGE, 2, 180)` (08), `repoHaircutShock(ABS, +15, 120)` (07). Response QE_ABS, LTRO.
   - FUNDING_RUN: repo leverage ≥ 1.2 / 0.5 / (lev − 1.2)/0.2. Precursor: repo rates +10 bp (07 hook). Trigger: `repoHaircutShock(ALL, +10, 60)`, prime-broker margin calls and procyclical CCP margin (07 hooks). Response SWAP_LINES, LTRO.
   - TRADE_WAR: tension ≥ 50 / 0.5 / (tension − 50)/15. Precursor: tariff talk (16 WIRE_ITEM). Trigger: `tariff_level +0.10` STEP 364 days, `x_target` PYN −0.02, FDL −0.007, one-off `fx_fair_ln` PYN ln(0.95). Response FISCAL_SUPPORT (program 0.5% GDP INDUSTRIAL_SUBSIDY in PYN).
   `vuln` values are clamped to [−3, 4] before `e^{vuln}` (unit decision, same bound as the imbalance z). Calibration bands are attached to each kind for T04-21 and 20.
2. **Storms** (scaled by severity `U(0.6, 1.4)` from the scheduler): RATE_SCARE `tp10 +0.004·sev` RAMP over 5 days then DECAY half-life 10 ending day 30 (one bloc by GDP weight); OIL_SPIKE_LITE `commoditySupplyShock(CRUDE, −0.03·sev, 20)`; CRYPTO_FLUSH hype −0.4 (06) and `makerWithdrawal(CRYPTO, 0.5, 720)` (target −30%); CREDIT_WOBBLE `corporatePdMultiplier(WORLD, 1.4, 30)` (IG +40 bp); FX_SQUALL `capital_flow −0.4·sev` 10 days on SRL or PYN (50/50); SECTOR_ROTATION `erpShock(WORLD, s1, +0.01)`, `erpShock(WORLD, s2, −0.005)`; EARNINGS_SCARE 06/09 consensus EPS −5% broad (hook `consensusEpsShock(−0.05)`); LIQUIDITY_HICCUP `makerWithdrawal(one asset class, 0.5, 60)`. `STORM_EFFECT_DAYS` = { RATE_SCARE 30, OIL_SPIKE_LITE 20, CRYPTO_FLUSH 1, CREDIT_WOBBLE 30, FX_SQUALL 10, SECTOR_ROTATION 1, EARNINGS_SCARE 1, LIQUIDITY_HICCUP 1 }.
3. **Ripples:** SECTOR_SHOCK and REGULATORY_NOTE → `sector_value:<sector>` shock ±size over `length` days (05 reads through T04-20 `macroValueShocks`); COMMODITY_SUPPLY / COMMODITY_DEMAND → `commoditySupplyShock(id, ∓size, length)` (06); LOCAL_BOOM → `city_activity:<cityId>` +size (09 and 10 read city activity).
   **Sub-defs within existing kinds (E-35 §5, moved 16 items; weights PROVISIONAL [Quant]):** COMMODITY_SUPPLY: DROUGHT 0.25 and CROP_DISEASE 0.15 (agricultural commodity, sign fixed: supply cut, price up), CHIP_FAB 0.15 (sign fixed negative for semis), SHIPPING_LANE 0.15 (plus C18 trigger: 09 delivery delays +1–3 GD for 7–56 GD), generic 0.30. SECTOR_SHOCK: scope COMPANY (one listed firm, sign negative) for RECALL 0.2 (−2% to −8% revenue for 28–91 GD), SCANDAL 0.15 (−2% to −8% revenue for 28–91 GD plus 14 Rep/CEO hook), CYBER 0.15 (firm offline, capacity −20–50% for 0.5–2 GD, outcome-only text); DATA_CENTER 0.1 (plus C17 trigger, compute price up); generic 0.4. Storm CREDIT_WOBBLE: BANK_RUN_LOCAL 0.5 → `depositConfidenceShock([weakest NPC bank in the bloc], −U(0.10, 0.20))`, 0–2 GD, precursor 1–2 GD; else the bloc-wide PD ×1.4. Sub-defs draw inside the kind rate, so the total stays 1/7 + 1/91 ≈ 0.154 per GD.
4. **Shapes.** `shockValue`: STEP constant in `[startTick, endTick)`; RAMP rises linearly from 0 at start to `value` at end; DECAY `value × 2^(−(tick − start)/(halfLifeDays × 720))` until end; 0 outside. Additive targets sum (`activeShockSum`), `lambda_raw_mult` multiplies (`activeShockProduct`). Consumers: T04-04 `x_target`, T04-07 `tp10`, `lambda_raw_mult`, T04-11 `auction_stress`, T04-07 z5 `z5_fear_add`, T04-14 `fx_fair_ln` and `capital_flow`, T04-15 `tariff_level`, `fear_add` (added to F after smoothing), `interbank_add` (FSI component and T04-06 trigger), T04-05 `credit_conditions_add`, `pi_e1_add`.
5. **Hooks (§3.16.6).** `writeHook` stores `HookCall { owner, hook, args, worldEventId, createdTick, startTick = tick + 1 }`; owners read `hookCallsFor(store, owner, tick)` (05 also through T04-20's `marketHookCalls`). Exact hook names and args: `erpShock(bloc|'WORLD', sector|null, deltaPremium, halfLifeDays)` 06; `corporatePdMultiplier(bloc|'WORLD', mult, days)` 07; `depositConfidenceShock(bankIds[], delta)` 07 (bank ids from `ports.credit.weakestNpcBanks(store, n)`, n = 1 + floor(3u) with the kind draw); `repoHaircutShock(assetKind, deltaPts, days)` 07; `stablecoinDepeg(assetId, target, days)` / `venueCollapse(venueId)` 06; `commoditySupplyShock(commodityId, pct, days)` 06; `aiRaceIndexShock(delta)` 11; `makerWithdrawal(assetFilter, depthMult, ticks)` / `npcSellProgram(assetFilter, advPerTick, ticks)` 05; `housePriceShock(cityIds[]|'WORLD', pct, days)` / `transactionFreeze(cityIds[], level, days)` 10; `correlationShock(poolKind, delta)` / `pdShock(poolKind, mult, days)` 08; `zeroDay(severity)` 12; `politicalStabilityShock(bloc, delta, days)` / `fiscalProgramProposal(program)` 16; plus 04's own `WIRE_ITEM(key, …)` 16, `HOLDOUT_CLAIM` 13 (T04-13), `MANDATE_SELL` 05 (T04-07), `DEPOSIT_GUARANTEE_RAISE` 07, `RESCUE_MERGER_PROPOSAL` 16 and 07, `CYBERCERT_PATCH` 12 and 13, `ltvTighten` 07 and 10, `consensusEpsShock` 06 and 09. All deterministic, applied by owners from the next tick.
6. **Responses.** `fireResponse` at TRIGGER (and again each day while CONTAGION if not yet fired): CCYB_RELEASE → `macroprudentialRelease`; QE_CORP_IG / QE_ABS → QE eligible mix override for the event's blocs at the next meeting; LTRO → `openLtro(..., 'CRISIS_POLICY')` for the POLICY phase; DEPOSIT_GUARANTEE, RESCUE_MERGERS, CYBERCERT_PATCH → hooks; ENERGY_SUBSIDY → 16 hook; HOUSING_PROGRAM, FISCAL_SUPPORT → `addProgram(source 'CRISIS_RESPONSE')`; CONCORD → `openConcord` when it qualifies; SWAP_LINES → force activation check; RULE_CUTS, RULE_HIKES, LOOK_THROUGH_ENERGY, BREAK_RULE, ELA, CIRCUIT_BREAKERS, NONE → nothing extra (automatic rules). A fired response or any CB emergency meeting of the event's blocs marks POLICY (`crisisResponseFired`).
7. **Emergent labels (§3.16.5)**, checked each game hour: FSI ≥ 0.75 at every hourly check of the last 72 game hours → BANKING_PANIC if the interbank or bank-drawdown component is the largest weighted component, else FUNDING_RUN; `ports.markets.gxDrawdown21d ≥ 0.20` → EQUITY_BUBBLE_BURST (label key `market_crash`); currency break (T04-14 calls) → CURRENCY_CRISIS; selective default (T04-13 calls) → SOVEREIGN_DEBT_CRISIS; world hack rate ≥ 85 at every check of the last 48 game hours → CYBER_PANDEMIC with origin PLAYER_CAUSED when `ports.conflict.playerHackShare ≥ 0.5`, else EMERGENT; `ports.assets.maxStablecoinDepeg > 0.10` → CRYPTO_WINTER; `ports.markets.indexWideHalt` → FLASH_CRASH. Emergent events apply no trigger shocks; they open the record, phases and history (T04-17 `attachEmergent`), and responses run as usual. Each label fires once per episode (re-armed after the condition has been false for 7 game days).
8. **Outcomes.** `measureOutcomes` at ENDED: peak FSI, peak F, bloc s10 peak, SRL spot change, PYN change, headline inflation change, plus the market metrics that 05, 06, 10 publish (GX drawdown, sector moves, crypto, house prices) read through ports; stored in `macro.event.ended`.
