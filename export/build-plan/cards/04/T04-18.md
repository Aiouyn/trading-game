## Goal
What each crisis is and does. The 15 major kinds with their eligibility, base weight and vulnerability (which make crises caused by real imbalances), their precursor, trigger and contagion shocks on 04 variables, the hook calls other modules implement (equity risk premium, corporate PD, deposit confidence, repo haircuts, stablecoins, commodity supply, AI race, market makers, house prices, pools, zero-days, politics), each crisis's specific policy response, the storm and ripple effects, and the emergent labels that open a WorldEvent record when rules have already produced a crisis. Every hook carries the WorldEvent id so 16 can build the causal chain.

- T04-01: `WorldEvent`, `ActiveShock`, `HookCall`, `CrisisKind`, `StormKind`, `RippleKind`, `BlocId`, `BLOC_ORDER`, `macroTables`, `MacroPorts`.

- T04-14: `setCapitalControls`, `openConcord`.
- T04-15: F and FSI values and components.

3. **Ripples:** SECTOR_SHOCK and REGULATORY_NOTE → `sector_value:<sector>` shock ±size over `length` days (05 reads through T04-20 `macroValueShocks`); COMMODITY_SUPPLY / COMMODITY_DEMAND → `commoditySupplyShock(id, ∓size, length)` (06); LOCAL_BOOM → `city_activity:<cityId>` +size (09 and 10 read city activity).

Sub-defs draw inside the kind rate, so the total stays 1/7 + 1/91 ≈ 0.154 per GD.
4. **Shapes.** `shockValue`: STEP constant in `[startTick, endTick)`; RAMP rises linearly from 0 at start to `value` at end; DECAY `value × 2^(−(tick − start)/(halfLifeDays × 720))` until end; 0 outside. Additive targets sum (`activeShockSum`), `lambda_raw_mult` multiplies (`activeShockProduct`). Consumers: T04-04 `x_target`, T04-07 `tp10`, `lambda_raw_mult`, T04-11 `auction_stress`, T04-14 `fx_fair_ln`, T04-15 `tariff_level`. Consumers with formulas (E-104 (1)); each reads `activeShockSum` at the point named and adds it to the value read there, never into stored state: `fear_add` (WORLD and bloc): `hourlyFear` adds Σ to F after smoothing, then clamps to [0, 100]. `interbank_add` (WORLD): `hourlyFsi` interbank input = (held 07 value, or 0 when `ports.credit` is null or a bloc is missing) + Σ, before the divisor 0.015; the same input feeds T04-06's FSI trigger. `capital_flow` (bloc b ≠ FDL, regime ≠ FREE_FLOAT): at b's trading-day close in `stepFxDay`, after CA absorption and before the reserve read, the CB sells `κ_cf × |Σ| × reservesFdl` FDL to `row` when Σ < 0 (buys the same when Σ > 0) through `ctx.ledger.fx`, reason `MAC_FX_CAPITAL_FLOW`, FDL amount rounded half-even to micro, X leg at spot; `κ_cf` = param `macro_fx_capital_flow_kappa` = 0.15 per trading day. `pi_e1_add` (bloc or WORLD): T04-05 adds Σ to `inflationExp1y` where the day step reads it. `credit_conditions_add` (bloc): T04-05 adds Σ to `creditConditions` where it is read. `z5_fear_add` (bloc): T04-07 adds Σ to the z5 fear input of λ.
5. **Hooks (§3.16.6).** `writeHook` stores `HookCall { owner, hook, args, worldEventId, createdTick, startTick = tick + 1 }`; owners read `hookCallsFor(store, owner, tick)` (05 also through T04-20's `marketHookCalls`). Exact hook names and args: `erpShock(bloc|'WORLD', sector|null, deltaPremium, halfLifeDays)` 06; `corporatePdMultiplier(bloc|'WORLD', mult, days)` 07; `depositConfidenceShock(bankIds[], delta)` 07 (bank ids from `ports.credit.weakestNpcBanks(store, n)`, n = 1 + floor(3u) with the kind draw); `repoHaircutShock(assetKind, deltaPts, days)` 07; `stablecoinDepeg(assetId, target, days)` / `venueCollapse(venueId)` 06; `commoditySupplyShock(commodityId, pct, days)` 06; `aiRaceIndexShock(delta)` 11; `makerWithdrawal(assetFilter, depthMult, ticks)` / `npcSellProgram(assetFilter, advPerTick, ticks)` 05; `housePriceShock(cityIds[]|'WORLD', pct, days)` / `transactionFreeze(cityIds[], level, days)` 10; `correlationShock(poolKind, delta)` / `pdShock(poolKind, mult, days)` 08; `zeroDay(severity)` 12; `politicalStabilityShock(bloc, delta, days)` / `fiscalProgramProposal(program)` 16; plus 04's own `WIRE_ITEM(key, …)` 16, `HOLDOUT_CLAIM` 13 (T04-13), `MANDATE_SELL` 05 (T04-07), `DEPOSIT_GUARANTEE_RAISE` 07, `RESCUE_MERGER_PROPOSAL` 16 and 07, `CYBERCERT_PATCH` 12 and 13, `ltvTighten` 07 and 10, `consensusEpsShock` 06 and 09. All deterministic, applied by owners from the next tick. **worldEventId (E-105).** Never empty: `writeHook` is the only writer of `mac.hookCall` and throws `MAC_STATE_MISSING` on ''. The field holds the source id: the WorldEvent id (`wev_…`) for hooks a WorldEvent writes, else the id of the 04 object that stands in for one, deterministic and unique per (kind, bloc, day): crisis week `WIRE_ITEM crisis_week_announced` → `cwk_WORLD_<⌊startTick / 720⌋>` (T04-17); weak auction `WIRE_ITEM weak_auction` → the `SovAuction.id` (`auc_<B>_<tenor>_<n>`, T04-11); YCC `WIRE_ITEM ycc_under_pressure` → `ycp_<B>_<day>` (T04-09); GRACE `WIRE_ITEM sov_grace` → the case id (`sdc_…`, as the restructuring hooks already do, T04-13); CSF `WIRE_ITEM csf_tranche_suspended` → `<programId>_t<k>` (`csf_<B>_<startTick>_t<k>`, k ≥ 1, T04-14); IG exclusion `MANDATE_SELL` → `igx_<B>_<day>` (T04-07). `<day>` = ⌊tick / 720⌋, `<B>` the bloc id. `newId` kinds `cwk`, `ycp` and `igx` are reserved (a digest id `<kind>_<base32>` has one underscore; every composite id above has two or more, so they cannot collide). Consumers: only a `wev_` id joins to `mac.event`; any other prefix is a non-event source (05 `mkt.eventMoves` returns null for it; 16 threads wire items by the id).
6. **Responses.** `fireResponse` at TRIGGER (and again each day while CONTAGION if not yet fired): CCYB_RELEASE → `macroprudentialRelease`; QE_CORP_IG / QE_ABS → QE eligible mix override for the event's blocs at the next meeting; LTRO → `openLtro(..., 'CRISIS_POLICY')` for the POLICY phase; DEPOSIT_GUARANTEE, RESCUE_MERGERS, CYBERCERT_PATCH → hooks; ENERGY_SUBSIDY → 16 hook; HOUSING_PROGRAM, FISCAL_SUPPORT → `addProgram(source 'CRISIS_RESPONSE')`; CONCORD → `openConcord` when it qualifies; SWAP_LINES → force activation check; RULE_CUTS, RULE_HIKES, LOOK_THROUGH_ENERGY, BREAK_RULE, ELA, CIRCUIT_BREAKERS, NONE → nothing extra (automatic rules). A fired response or any CB emergency meeting of the event's blocs marks POLICY (`crisisResponseFired`).
7. **Emergent labels (§3.16.5)**, checked each game hour: FSI ≥ 0.75 at every hourly check of the last 72 game hours → BANKING_PANIC if the interbank or bank-drawdown component is the largest weighted component, else FUNDING_RUN; `ports.markets.gxDrawdown21d ≥ 0.20` → EQUITY_BUBBLE_BURST (label key `market_crash`); currency break (T04-14 calls) → CURRENCY_CRISIS; selective default (T04-13 calls) → SOVEREIGN_DEBT_CRISIS; world hack rate ≥ 85 at every check of the last 48 game hours → CYBER_PANDEMIC with origin PLAYER_CAUSED when `ports.conflict.playerHackShare ≥ 0.5`, else EMERGENT; `ports.assets.maxStablecoinDepeg > 0.10` → CRYPTO_WINTER; `ports.markets.indexWideHalt` → FLASH_CRASH. Emergent events apply no trigger shocks; they open the record, phases and history (T04-17 `attachEmergent`), and responses run as usual. Each label fires once per episode (re-armed after the condition has been false for 7 game days).
8. **Outcomes.** `measureOutcomes` at ENDED: peak FSI, peak F, bloc s10 peak, SRL spot change, PYN change, headline inflation change, plus the market metrics that 05, 06, 10 publish (GX drawdown, sector moves, crypto, house prices) read through ports; stored in `macro.event.ended`.
