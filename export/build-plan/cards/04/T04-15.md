## Goal
The three world indicators other modules key off. The Fear Index (the game's VIX, 0 to 100) and risk appetite, updated every game hour from equity volatility, credit spreads, financial stress, crises, tension, hacking and equity returns, with a 2-hour half-life. The Financial Stress Index (0 to 1, public on MKT-07), a weighted average of eight normalized components from 05, 06, 07, 08 and sovereign stress. The world trade index from real GDP and the tariff level. Missing inputs hold their last value (edge 23).

## Implementation steps
1. **Order inside the hour.** At each game hour boundary (P2, `cal.boundaries` HOUR), `hourlyFsi` reads the components first, then `hourlyFear` uses the new FSI. Both use only state committed at the end of the previous tick.
2. **Fear (§3.14.1).** Inputs: `rv21Gx = ports.markets.rv21Gx` (annualized, 21 trading days), `gxReturnToday = ports.markets.gxReturnToday` (since the day open), `gxReturn63d` from the GX level history (`ports.markets.gxLevel` daily closes kept in `DailyHistoryRow.equityIndex` of the GLOBAL row), `creditSpreadIdx = igCreditSpreadIndex / mean364(igCreditSpreadIndex)` (`ports.assets.igCreditSpreadIndex`, history kept daily), `FSI` this hour, `crisisTerm`, tension and hack rate from the input snapshot (genesis 30 and 0). Any null input → its last value (genesis neutral values: rv 0.16, csi 1, returns 0) and the key enters the day's stale list (edge 23). `F ← stepFear(F, fearRaw)`; genesis `F = 22`; RA = `1 − F/50`. Emit `macro.fear` PUBLIC (F, RA) every hour. 06 reads `impliedVolAnchor` (DEFAULT; 06 owns the surface).
3. **FSI (§3.14.2).** Components: interbank spread over the policy rate (`ports.credit.creditAggregates(...).interbankSpread`, GDP-weighted over blocs; null without 07, edge 18, then 0 and never an emergency trigger), repo haircut index change vs its 1-year mean (`ports.credit.repoHaircutIndexChange`, points), CCP default fund usage share (`ports.credit.ccpDefaultFundUsage`), NPC bank equity drawdown from the 364-day high (`ports.markets.bankEquityDrawdown364(store, 'WORLD')`), IG credit spread level (`ports.assets.igCreditSpreadIndex`, decimal), largest stablecoin depeg (`ports.assets.maxStablecoinDepeg`), ETF discount index (`ports.funds.etfDiscountIndex`), largest sovereign `stressIndex` over the five blocs. Each normalized `clamp(value/divisor, 0, 1)`, then the weighted sum. Emit `macro.fsi` PUBLIC with FSI and the normalized components every hour; `GlobalMacroState.financialStressIndex` is the value T04-06, T04-07, T04-09 and T04-14 read.
4. **World trade (§3.14.3)**, day close: `tariffLevel` genesis 0.03; daily changes: `ports.world.tariffDelta(store, tick)` (16) plus active shocks with target `tariff_level` (TRADE_WAR, T04-18), `stepTariff` clamps to [0, 0.4]; `WTI = 100 × (Σ gdpShare0_b × realGdpIndex_b/100)^1.5 × ((1 − tariff)/0.97)²`; history keeps it (T04-03 trade z, T04-04 trade channel).
5. Exploit 16 note: no single input can move FSI or F to an emergency level; the weights and divisors above are the only path.
