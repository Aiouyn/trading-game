## Implementation steps
1. Inflation (§3.5), per bloc at macro step 5, after the gap step:
   1. `S_eff`: trade-weighted value of the bloc's currency against the other four: `ln S_eff,b = Σ_{Y≠b} w_Y (ln S_b − ln S_Y)` with `S` = FDL per unit (FDL = 1) and `w_Y` = the other blocs' current shares of world nominal GDP (FDL), renormalized to sum 1. `dep = −(lnS_eff,t − lnS_eff,t−364)` from history (before day 364: from genesis).
   2. `π_core* = π_e1 + 0.25·mean90(x) + fxPassThrough·dep` (`macro_phillips_slope`); `mean90(x)` = mean of the last 90 daily gaps (history; shorter at genesis).
   3. `π_core ← π_core + (ln2/0.5)(π_core* − π_core)Δ + 0.003√Δ ε`, `ε` = draw 3 of the bloc's `S.shock(b)` day draws; clamp [−0.05, 0.60] (edges 3, 4).
   4. `coreCpiLevel ×= exp(π_core Δ)`; headline `cpiLevel = coreCpiLevel × (E_loc,t/E_loc,0)^energyWeight × (Fd_loc,t/Fd_loc,0)^foodWeight`, `E_loc = energyIndex/spot_b`, `Fd_loc = foodIndex/spot_b` (genesis energy and food 100, spot_0 = fx0); `headlineInflation = ln(cpi_t/cpi_{t−364})` (before day 364: annualize from genesis, `ln(cpi/100) × 364/days`).
   5. Expectations with `cred` = the CB credibility: `π_e1 += (ln2/0.25)((1 − cred)·headline + cred·target − π_e1)Δ`, then `π_e5 += (ln2/1.0)((1 − cred)²·π_e1 + (1 − (1 − cred)²)·target − π_e5)Δ` using the updated π_e1.
   6. `priceIndexOf`: CPI = cpiLevel, CORE = coreCpiLevel, WAGE = wageIndex, ENERGY_LOCAL = 100·E_loc,t/E_loc,0, FOOD_LOCAL likewise. Rule: other modules multiply genesis prices by index ratios and never compound inflation themselves (served through T04-20 `priceIndex(store, bloc, kind)`). Lifestyle prices combine this with 03's lever L2 (owned by 14 and 03, R04); nothing in 04 reads L2.
2. Credit (§3.14.4): with `ports.credit` non-null and a supplied row: `creditGdp = credit/nominalGdp`, `trend ← EWMA(creditGdp, 3 × 364 days)` (factor `1 − 2^(−1/1092)`), `creditGap = creditGdp − trend`, `creditGrowth = ln(credit/credit_364)`; `creditConditions` and `interbankSpread` as supplied. Fallback when `ports.credit` is null or returns null (edge 18, 04#43): `creditConditions = 0.5·tanh(−2R̃/0.01) + tilt(regime)`, clamped to [−1, 1]; `credit ← credit × exp(nominalGdpGrowthLn × (1 + 0.5·creditConditions))`; `interbankSpread = null` (FSI component treated as 0, emergency trigger never fires on it). Genesis (unit decision; 04 gives no level): `credit = 1.0 × nominalGdp`, `trend = creditGdp`, so the gap starts at 0.
3. Inputs (§3.14.5): `energyIndex = 100·(0.5·crude/crude0 + 0.3·gas/gas0 + 0.2·MWh/MWh0)`, `foodIndex = 100·(0.3·wheat + 0.3·corn + 0.2·coffee + 0.2·cocoa, each ÷ genesis)`, genesis prices captured at the first day close where 06 provides them (until then the indices stay 100). `aiRaceIndex` (11), `worldHackRate` (12), `geopoliticalTension` and `politicalStability_b` (16): missing ⇒ last value; genesis defaults 50, 0 (hack rate), 30 (tension), 0.7 (stability) (unit decision, documented in `_unit.md`). Every key that was missing this day is listed in `staleKeys` and T04-20 emits one `macro.input.stale` (SEALED, internal) per day with the list (edge 23).
