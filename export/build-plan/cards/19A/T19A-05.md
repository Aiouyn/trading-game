## Goal
Implement the CI pipeline of 19 Rule 3.18.2 so every later task is checked the same way: lint (determinism and import boundaries), typecheck, unit and property tests, static invariants (`verify:static`), protocol contract tests, golden replay of 20's regression seeds, partition-independence run, e2e smoke, build and image signing. Jobs that belong to packages built later are turbo tasks: the job runs `turbo run <task>`, which executes the task in every package that defines it (none yet), so nothing in this task is a placeholder rule. A static-invariant registry lets later tasks plug their INV-STR checks into one `verify:static` report.

## Imports
- T19A-01: turbo tasks and root scripts.
- T19A-03: ESLint config. T19A-04: `checkGraph` (via `verify:static`).
- T19A-02: protocol package (contract tests job runs `test:contract`, defined later by T19C-01).

## Implementation steps
1. `.github/workflows/ci.yml` on `pull_request` and `push` to `main`: one setup step (checkout, `pnpm/action-setup` with the pinned pnpm, `actions/setup-node` with `node-version-file: .nvmrc`, `pnpm install --frozen-lockfile`, turbo cache). Jobs in this order with `needs` edges: `lint` (`pnpm -w lint`), `typecheck`, `test` (`pnpm -w test`, env `TYCOON_NIGHTLY=0`), `verify-static` (`pnpm -w verify:static`), `contract` (`pnpm -w test:contract`), `golden-replay` (`pnpm -w test:replay`), `partition-independence` (`pnpm -w test:partition`, which 19B/20A define as a 3-game-day headless world run with 1, 3 and 17 partitions), `e2e-smoke` (`pnpm -w e2e:smoke`, starts `infra/local/docker-compose.yml` services), `build` (`pnpm -w build`), `sign-images` (on `main` only: build container images for apps with a `Dockerfile`, sign with cosign keyless, attach an SBOM generated by syft; 19 Rule 3.9.7). `golden-replay`, `partition-independence`, `e2e-smoke` need `test`; `build` needs all checks; `sign-images` needs `build`.
2. Every job uploads its result line to the job summary via `ci-summary.ts`. A job whose turbo task matches no package prints `no package defines <task>` and passes.
3. Concurrency: cancel in-progress runs of the same PR. Timeout per job 30 minutes; the G0 budget of 20 (≤ 20 minutes total) is reported in the summary.
4. `nightly.yml` (schedule daily 02:00 UTC): same jobs with `TYCOON_NIGHTLY=1` (10,000 property cases) plus `pnpm -w test:regression-full` (defined by 20A).
5. `static-registry.ts` as in Exports; move the INV-STR-001 invocation of T19A-04 into `packages/config/graph/static-checks.ts` calling `registerStaticCheck({ id: 'INV-STR-001', owner: '19A', run: … })`, and make `@tycoon/config`'s `verify:static` run the registry CLI (which also runs `check-workspace`).
6. `docs/ci.md`: the job table with what each job runs and which spec rule requires it.
