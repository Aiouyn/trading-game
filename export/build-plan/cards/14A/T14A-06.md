## Goal
Licenses decide which instrument classes a character may open (06/07 own the class map). This task implements the §3.3.1 ladder, exams (free, retake after 1 game day, valid 2 chapters without the license, §8 #22), the purchase intent with rank gate, exam, 13 eligibility and a fee in real dollars paid from unrestricted cash, and the LIC1 grant paid once by the onboarding faucet.

## Implementation steps
1. `LADDER`: values from §3.3.1 (registry rows in 23 §4.13, E-28/E-29; LIC1 renewal is 0, the 10% applies to LIC2–LIC4 only). `renewalShareE6 = 100_000` is 10%. Producer ruling (E-21): these get PARAM keys, values confirmed by Quant (E-21 addendum (b)); tests: `feeNominal(LIC2)` at MSI 1.25 = `18_750_000_000n`, renewal `1_875_000_000n`; LIC1 `250_000_000n` (net 0 with ACCT_ONBOARD_GRANT); LIC3 `250_000_000_000n`; LIC4 `5_000_000_000_000n`. Keys: `license_fee_lic2_real` ($15,000), `license_fee_lic3_real` ($250,000), `license_fee_lic4_real` ($5,000,000), `license_renewal_share` (0.10), `license_fee_lic1_real` ($250). Code reads them with `ctx.params.money(...)` once the keys exist in 23; the constants live only in `params.ts` defaults.
2. `acct.exam.submit` (common validate): `examKey(examId)`; `lastAttemptTick + exam_retake_game_days × 720 > tick` → `ACCT_EXAM_RETAKE_WAIT`; score = count of equal answers; pass when `score >= passMark` → `passedTick = tick`. Always set `lastAttemptTick`. A pass is recorded even if the character cannot afford the license (§8 #22).
3. `examValid`: the character holds the license, or `passedTick != null && chapterOf(tick) − chapterOf(passedTick) < exam_valid_chapters`.
4. `acct.license.buy`, P1 order of checks (first failure wins):
   1. common validate (`ACCT_NOT_SELF`, `ACCT_ANONYMIZED`, `ACCT_ACCOUNT_BLOCKED`, `ACCT_HELD`);
   2. already ACTIVE, SUSPENDED or LAPSED for that id → `ACCT_ALREADY_HELD` (LAPSED uses `acct.license.renew`, T14A-07); REVOKED may buy again;
   3. ladder order: LIC(n) requires LIC(n−1) ACTIVE (conservative; spec implies a ladder, open question 5) → `ACCT_RANK_GATE` with `params.missing`;
   4. `rankAtLeast(rankOf(chr), rankGate)` else `ACCT_RANK_GATE`;
   5. exam required and not `examValid` → `ACCT_EXAM_REQUIRED`;
   6. `licenseEligibility(chr, lic).eligible` else `ACCT_NOT_ELIGIBLE` with `params.reason`;
   7. fee: `ledger.available(chr,'FDL') >= fee` (G7 `available` excludes restricted lots, 14 §4 "restricted cash not allowed") else `ACCT_INSUFFICIENT_FUNDS`; place `placeCashFor(chr,'FDL',fee,tick+1,intentId,'ACCT_LICENSE_FEE')`.
   - Apply P12: `burn(chr, fee, 'FDL', 'ACCT_LICENSE_FEE', { holdId })`; LicenseRow ACTIVE, `grantedTick = tick`, `renewalDueTick = tick + 262,080` (LIC1: null), `feePaid = fee`; emit `acct.license.granted` PRIVATE.
   - Restricted cash: ledger errata E-21 sets `ACCT_LICENSE_FEE` restrictedOk = N, so the rail never draws a restricted lot for the fee and the hold fails with `LED_RESTRICTED_FUNDS` when only restricted cash would cover it. INV-CHR-006 (T14A-08) stays as a second guard. Test `license fee never draws restricted cash`: unrestricted $15,000 plus restricted $10,000 → accepted, restricted lot unchanged; unrestricted $14,999 plus restricted $10,000 → `ACCT_INSUFFICIENT_FUNDS`.
5. `grantOnboardingLic1` (18 sends `acct.onboard.lic1` during onboarding, 00 §5.9): if `onboardGrantPaid` → return `ACCT_ALREADY_HELD` and post nothing. Else one entry pair: `mint(chr, realToNominal(250e6), 'FDL', 'ACCT_ONBOARD_GRANT')` then `burn(chr, same, 'FDL', 'ACCT_LICENSE_FEE')` in the same tick (net cash 0), LIC1 ACTIVE with `renewalDueTick null`, `onboardGrantPaid = true`. No exam, no eligibility call (R0).
6. `INV-CHR-003` (TICK, FATAL): every ACTIVE LIC2–LIC4 row had at grant time `reachedTick[rankGate] <= grantedTick` and an exam pass with `passedTick <= grantedTick`; every ACTIVE charter row satisfies the charter rank gate (T14A-07 table).
7. `INV-CHR-004` (TICK, FATAL): per character, the count of committed `ACCT_ONBOARD_GRANT` postings ever is ≤ 1 (kept as a counter in CharacterRow `onboardGrantPaid` plus a check of this tick's postings: a second posting for a character with the flag already true fails); LIC1 rows never have state LAPSED.
