## Goal
Every 14A rule is stated in real dollars and charged as `real × MSI(tick)`. This task gives one exact bigint conversion so no card ever converts money with floats, binds the 14 §3.17 codes that 14A posts to 03's catalog, and declares the ports (G6.1) for data owned by units built after 14A: sanctions and Held (13A), PROBATE (14B), linked accounts and chapters (15), exam keys (18) and reserved names (22).

## Imports
- T03-24: `msiValue(read)`.
- T03-17: `computeNwRank(read, id, tick, params)`.
- T03-02 / T03-05: `getCatalog()`, the codes `ACCT_START_CASH`, `ACCT_ONBOARD_GRANT`, `ACCT_FRESH_START`, `ACCT_LICENSE_FEE`, `ACCT_CHARTER_FEE`, `ACCT_BACKGROUND_DISCOUNT`.

## Implementation steps
1. `msiPpm`: `msiValue` is a float (03); convert once with `roundHalfEven(msi * 1e6)` and clamp to >= 1. All later money math is bigint. `realToNominal` and `nominalToReal` use bigint half-even division (write `divHalfEven(a, b)` locally: q = a / b, r = a % b, compare 2r with b, ties to even q).
2. Thresholds (rank, Fresh Start NW line) use `nominalAtLeastReal`, which never rounds. Fees use `realToNominal` (one rounding, half even).
3. `codes.ts`: bind the eight codes. `assertCodesRegistered` looks each up in `getCatalog()`. `ACCT_HANDLE_FEE` and `ACCT_HOME_CITY_FEE` were added to the ledger catalog by errata E-21 (SINK, BURN, legA 5250 FIXED, family S6, restrictedOk N, owner 14). E-21 also sets the owner of `ACCT_LICENSE_FEE` and `ACCT_ONBOARD_GRANT` to 14 (14 §3.17 is authoritative) and `ACCT_LICENSE_FEE` restrictedOk N. `assertCodesRegistered()` must return `[]`.
4. `DEFAULT_PORTS` (conservative "module not present" choices):
   - `licenseEligibility` → `{ eligible: true }`; `isHeld` → false; `handleChangeBlocked` → false; `inProbate` → false.
   - `hasHouse` → false (so R6 can never be awarded without 14B: conservative).
   - `linkedCharactersOf` → `[]`.
   - `chapterOf(tick)` → `Math.floor(tick / TICKS_PER_CHAPTER)` (genesis at tick 0).
   - `richestAllTimeTopN` → `[]` (no R6 without 15).
   - `examKey` → fixture keys: EX_PRO 10 questions, passMark 8 (14 §3.3.1); EX_DERIV and EX_INST 10 questions, passMark 8 (spec gives no mark: open question).
   - `reservedHandleKeys` → `{'admin','staff','support','moderator','system'}`; `cityBloc` → reads `ctx.content` when present, else 'FDL'.
5. Ports are pure reads. No port may write state.

## Test plan
- `money.test.ts`:
  - MSI 1.25 (msiPpm 1_250_000n): `realToNominal(15_000_000_000n)` = `18_750_000_000n`; renewal 10%: `realToNominal(1_500_000_000n)` = `1_875_000_000n`.
  - MSI 1.2: `realToNominal(5_000_000_000n)` = `6_000_000_000n`; `nominalToReal(24_999_990_000n, 1_250_000n)` = `19_999_992_000n`.
  - Half-even: `realToNominal(1n, 1_500_000n)` = 2n (1.5 → 2); `realToNominal(5n, 1_500_000n)` = 8n (7.5 → 8); `realToNominal(3n, 500_000n)` = 2n (1.5 → 2), `realToNominal(1n, 500_000n)` = 0n (0.5 → 0).
  - `nominalAtLeastReal(25_000_000_000n, 20_000_000_000n, 1_250_000n)` true; `(24_999_999_999n, same)` false.
  - Property (fast-check): for random real and msiPpm in [500_000, 5_000_000], `|nominalToReal(realToNominal(r)) − r| <= 1n + msi/1e6` (rounding bound).
- `codes.test.ts`: every bound code exists in the catalog with the class of 14 §3.17 (START_CASH, ONBOARD_GRANT, FRESH_START, BACKGROUND_DISCOUNT FAUCET; LICENSE_FEE, CHARTER_FEE SINK); `assertCodesRegistered()` returns `[]`; the catalog owner of all eight codes except `ACCT_CHARTER_FEE` (owner 13, posted by 13) is `14`; `ACCT_LICENSE_FEE`, `ACCT_HANDLE_FEE`, `ACCT_HOME_CITY_FEE` have restrictedOk N (E-21).
- Ports: `resolvePorts({})` returns every default; a partial override replaces only that function.
