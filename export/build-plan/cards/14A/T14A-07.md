## Goal
Licenses cost money every game year and can be lost. Renewal is charged at the due tick; unpaid, the license lapses after a 7-game-day grace and only closing orders remain allowed for its classes. 13 sanctions suspend or revoke; 14 applies them. Charter applications check the 14 rank gate (CH_FUND and CH_EXCHANGE_MEMBER at R3; CH_BANK, CH_INSURER and CH_CUSTODIAN at R4, owner decision) and forward to 13, which owns capital, record and fee. The $250k deposit guarantee per owner per bank is a 07 rule and is not computed here; the charter row only carries the bank entity id 07 needs.

## State model
`ACTIVE → (renewal unpaid at due) ACTIVE-in-grace (graceEndsTick set) → LAPSED (grace end) → ACTIVE (renew paid)`.
`ACTIVE/LAPSED → SUSPENDED (13) → ACTIVE (until reached or LIFT; LAPSED if renewal overdue)`. `any → REVOKED (13)`; REVOKED is terminal for that row; a new purchase creates a fresh row (T14A-06 step 4.2). LIC0 and LIC1 never renew and never lapse.

## Implementation steps
1. `runRenewals` at DAY_CLOSE P12, rows from `byRenewal` index with `renewalDueTick <= tick`, sorted by id:
   - fee = `renewalFeeNominal(lic)`; if `available(chr) >= fee` (unrestricted): `burn(... 'ACCT_LICENSE_FEE')`, `renewalDueTick += 262,080`, clear `graceEndsTick`.
   - else if `graceEndsTick == null`: set `graceEndsTick = renewalDueTick + license_grace_game_days × 720`.
   - else if `tick >= graceEndsTick` and state ACTIVE: state LAPSED, emit `acct.license.lapsed` PRIVATE.
   - Charters: renewal is 13's fee; skip rows with `CH_*`.
2. `acct.license.renew`: allowed when LAPSED or `renewalDueTick − tick <= 7 × 720`; else `ACCT_NOT_RENEWABLE`. Pays the renewal fee; restores ACTIVE immediately; `renewalDueTick = tick + 262,080` if it was overdue (LAPSED or in grace), else `renewalDueTick + 262,080` (conservative reading of "renewal due +1 game year", open question 6).
3. `onSanction` (13 is the only source, §3.3.2): SUSPEND sets SUSPENDED and `suspendedUntilTick`; REVOKE sets REVOKED; LIFT restores ACTIVE. Emits `acct.license.suspended` / `.revoked` PRIVATE (13 emits the PUBLIC verdict line itself). A message from any other module is ignored and logged via `ctx.fail` only if the sender is not 13 (structural guard; tested).
4. `licenseAllows` is the single gate 05/06/07 call in P1: `OPEN` requires ACTIVE; `CLOSE` is allowed in ACTIVE, SUSPENDED and LAPSED (14#11). 05 returns its own reject code using this boolean.
5. `acct.charter.apply`: common validate; rank gate `CHARTER_RANK_GATE` (bank and insurer at R4 per owner decision and 14 §3.2.2) else `ACCT_RANK_GATE`; `sponsorEntityId` must be controlled by the character (03 `rootOwnerId == chr`) and pass `validEntityId`, else `ACCT_ID_INVALID`. Effect: `ctx.send(sponsorEntityId, 'law.charter.apply', { chrId, charterId, sponsorEntityId }, 'NEXT')`. No fee here (13 posts `ACCT_CHARTER_FEE`).
6. `onCharterDecision`: approved → LicenseRow `{ holderId, chrId, licId: charterId, state ACTIVE, renewalDueTick null, feePaid }`, emit `acct.license.granted`. Rejected → nothing stored.
7. `INV-CHR-010` (TICK, FATAL): every ACTIVE charter row's `chrId` has `reachedTick[CHARTER_RANK_GATE[c]] != null` and `reachedTick <= grantedTick`.
