## Goal
Read models for the 14 §7 screens whose data 14A owns: the Rank and Licenses sub-view, the Fresh Start modal, Settings (identity, shell, publication consent with a preview), the rank progress line on Home, the restricted cash badge, and the public identity card fields 14A owns (handle, rank badge, shell, chosen title, tenure). Estate, Vault, Boutique, Clubs, Hosting, House and Legacy, Gilt List and Hall of Fame views are 14B. Public payloads are built from the `PublicationConsent` allowlist only (LC16, L11).

- T14A-05: `RANK_THRESHOLD_REAL`, `rankOf`. T14A-06: `LADDER`, `feeNominal`, `examValid`. T14A-07: `licenseAllows`, `CHARTER_RANK_GATE`. T14A-08: `restrictedBuckets`, `accountOf`. T14A-09: FreshStart rows, `cooldownUntil`, `leverageCapOf`, `creditBlocked`.

## Implementation steps
1. Owner-only views check `viewer.characterId == own chr`, else return an empty result with `forbidden: true` (never data of another character).
2. `MeView.rankBasisReal` is the last day-close value (stored by T14A-05 in the rank row as `lastEvaluatedTick` plus the peak); add a `lastRankBasisReal` read from 03's `led.nwrank` cache via `computeNwRank` only at view time if the cache is missing. The progress line "Next: Mogul · $412.9k / $5M" is formatted by 17 from these two strings.
3. `VIEW_FRESH_START.expectedTopUp` = `max(0, realToNominal(fresh_start_cash_real) − (liquid + restricted))`, or "0" in cooldown. `kept` and `lost` are i18n keys from §3.13.3 (fixed lists).
4. `VIEW_PUBLIC_IDENTITY` uses only allowlisted public fields. The rank badge is public (14 §5). Cosmetic shells are shown with `shellPurchased: true` (§3.4). No money value, license, protection state, restricted cash or account data is ever in this payload (L11).
5. Register every view in `VIEWS_14A`.
