## Goal
Copy the 23 §4 tables of owner modules 12 (15 keys), 13 (21), 14 (42), 15 (22), 16 (49), 17 (37) and 18 (26) into `@tycoon/params` data files with the few overrides listed below.

## Imports
- T23-01: `RawRow`, `OwnerTable`, `ParamValue`, `ParamRange`, `buildParamSet`, `createParamsView`.

## Exports
```ts
// packages/params/src/registry/m12.ts … m18.ts
export const TABLE: OwnerTable;   // owner '12' … '18'
```

## Implementation steps
1. **Transcription rule**: as T23-02 step 1. Row counts: 12 = 15, 13 = 21, 14 = 42, 15 = 22, 16 = 49, 17 = 37, 18 = 26 (total 212).
2. **Overrides**:
   - 12 `session_max_lifetime_ticks`: value `{kind:'number', v:120960}` (7 real days × 17,280 ticks, the unit cell is `ticks`); `rangeOverrides` interval [51840, 172800] (3–10 real days in ticks).
   - 12 `zero_day_duration`: `{kind:'list', v:[3, 7]}` meaning [minRealDays, maxRealDays]; the range `1–10` applies to both elements.
   - 16 `memory_halflife_game_days`: struct `{base:90, offset:0.5, scaledBy:'patience'}` (half-life = base × (offset + patience)); `rangeOverrides` interval [30, 364] on `base`.
   - 17 `ui_quiet_end`: string `'08:00'`; 17 `ui_quiet_start`: string `'22:00'`.
   - Rows that now parse with T23-01's grammar and need no override: 14 `edition_max_price_multiple` (`3×` -> 3), 16 `trust_contract_gain_cap` (`+20` -> 20).
3. Every 17 row must carry `live = no (C)` and is transcribed as written; every other row as written.
4. Any other row that fails to parse: stop and report `SPEC QUESTION: <key> <cell>`.
