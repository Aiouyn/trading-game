## Goal
Copy the 23 §4 tables of owner modules 02 (17 keys), 03 (24), 04 (57) and 05 (97) into typed data files of `@tycoon/params`, one `OwnerTable` per module, so the engine's parameter set contains every number of these modules. Cells are copied verbatim (the parsers of T23-01 turn them into typed values); this card fixes every composite default (overrides) and every family expansion, so nothing is left to judgement.

## Imports
- T23-01: `RawRow`, `OwnerTable`, `ParamValue`, `FamilyMember`, `parseRow`, `buildParamSet`.

## Exports
```ts
// packages/params/src/registry/m02.ts … m05.ts (same shape in every owner file of the unit)
import type { OwnerTable } from '../types';
export const TABLE: OwnerTable;   // owner '02' | '03' | '04' | '05'
```

## Implementation steps
1. **Transcription rule (applies to every row of the four tables).** For each markdown row, in table order, write `{ key, default, range, unit, ownerRef, affects, live }` with the cell text exactly as written: keep `†` at the end of the key cell (`'stab_lever_ranges †'`), keep `‡` in range cells, keep Unicode minus `−`, en dash `–`, `×`, `≥`, `±`, `$`, `%`, thousands commas. Remove only the backticks around the key. Do not reorder, merge or skip rows. Row counts must equal the headings: 02 = 17, 03 = 24, 04 = 57, 05 = 97.
2. **Overrides** (`TABLE.overrides[key]`, keys without `†`). Field names are binding for the owner modules.
   - 03 `stab_lever_ranges`: `{kind:'table', columns:['start','min','max','step'], rows:[['L1',[1.00,0.90,1.10,0.005]],['L2',[1.00,0.90,1.25,0.005]],['L3',[0.5,0,3.0,0.1]],['L4',[1.00,0.95,1.15,0.003]]]}` (L3 values in bp).
   - 04 `macro_capital_controls_duration`: `{kind:'struct', fields:{L2:3, L3:72}}` (game days).
   - 04 `macro_cb_meeting_day_of_quarter`: `{kind:'struct', fields:{NA:15, SC:27, FU:39, EC:51, PL:63}}`.
   - 04 `macro_fear_index_half_life`: `{kind:'number', v:2}` (unit cell says game hours).
   - 04 `macro_ripple_rate`: `{kind:'number', v:1/7}`; 04 `macro_storm_rate`: `{kind:'number', v:1/91}` (per game day).
   - 04 `macro_sovereign_base_hazard`: `{kind:'struct', fields:{FU:0.0005, EC:0.003, PL:0.002, NA:0.0003, SC:0.02}}`.
   - 04 `macro_ycc_bloc`: `{kind:'string', v:'PL'}`.
   - 04 family rows `macro_cb_haircut_*`, `macro_issue_mix_*`, `macro_rev_base_*`, `macro_rr_*`, `macro_x_*`, `macro_xreg_*`: `{kind:'text', v:<default cell>}` (their numbers live in the members below).
   - 05 `mkt_block_min_notional`: `{kind:'struct', fields:{advShare:0.25, floorUsd:1000000}}`.
   - 05 `mkt_fee_*`: `{kind:'text', v:'per table in the owner section'}`.
   - 05 `mkt_fee_eq`: `{kind:'struct', fields:{takerBp:3, makerBp:1, auctionBp:1}}`; `mkt_fee_crypto`: `{kind:'struct', fields:{takerBp:10, makerBp:5}}` (no auction fills on crypto). `mkt_fee_bond` (0.5) and `mkt_fee_fx` (0.3) parse as numbers: taker = maker = auction.
   - 05 `mkt_fee_volume_tiers`: `{kind:'table', columns:['fromUsd','mult'], rows:[['T1',[0,1.0]],['T2',[10000000,0.8]],['T3',[100000000,0.6]],['T4',[1000000000,0.5]]]}`.
   - 05 `mkt_guard_gap`: `{kind:'struct', fields:{equities:0.25, crypto:'none'}}` (`'none'` = no guard).
3. **Family members** (`TABLE.members[familyKey]`), member keys exact:
   - `macro_x_*` (04 §3.4.1 channel coefficients): `macro_x_a_r`=0.5, `macro_x_m`=0.8, `macro_x_a_c`=0.012, `macro_x_a_e`=0.4, `macro_x_a_q`=0.10, `macro_x_a_o`=0.03, `macro_x_a_f`=0.010, `macro_x_a_w`=0.05, `macro_x_a_h`=0.08, `macro_x_a_t`=0.2, `macro_x_a_k`=0.010.
   - `macro_xreg_*` (attractors, fractions): `macro_xreg_expansion`=0.005, `macro_xreg_overheating`=0.025, `macro_xreg_contraction`=−0.04, `macro_xreg_recovery`=−0.01.
   - `macro_rr_*` (04 §3.8.2): `macro_rr_fu`=0.01, `macro_rr_ec`=0.01, `macro_rr_pl`=0.05, `macro_rr_na`=0.01, `macro_rr_sc`=0.10.
   - `macro_cb_haircut_*` (04 §3.8.3; ineligible cells have no member): `_own_gov_aaa_aa` 0.01, `_own_gov_a` 0.02, `_own_gov_bbb` 0.04, `_own_gov_bb` 0.15, `_other_gov_aaa_aa` 0.03, `_other_gov_a` 0.05, `_other_gov_bbb` 0.10, `_corp_aaa_aa` 0.05, `_corp_a` 0.07, `_corp_bbb` 0.12, `_abs_aaa_aa` 0.08, `_abs_a` 0.12, `_abs_bbb` 0.20, `_credit_claims_ela` 0.30, `_equities_ela` 0.40, `_maturity_addon_per_year_over_5` 0.005 (prefix every name with `macro_cb_haircut`).
   - `macro_rev_base_*` (04 §3.9.1): `macro_rev_base_fu` 0.30, `_ec` 0.42, `_pl` 0.25, `_na` 0.40, `_sc` 0.27.
   - `macro_issue_mix_*` (04 §3.10.1, shares of GFN; `std` = FU, EC, PL, NA; `sc` = SC): `macro_issue_mix_std` = table columns `['share']` rows `B3M 0.12, B6M 0.12, B1Y 0.06, N2Y 0.15, N5Y 0.20, N10Y 0.22, N30Y 0.08, L10Y 0.05`; `macro_issue_mix_sc` = rows `B3M 0.16, B6M 0.16, B1Y 0.08, N2Y 0.15, N5Y 0.15, N10Y 0.10, N10Y_FDL 0.20, N30Y 0, L10Y 0`. Each table's shares sum to 1.00 (assert in tests).
   - `mkt_fee_*` (05 §3.15.1, new members only; rows above stay): `mkt_fee_commodity` struct `{takerBp:2, makerBp:1, auctionBp:1}`, `mkt_fee_fut` struct `{takerUsd:0.50, makerUsd:0.30, auctionUsd:0.30}`, `mkt_fee_opt` struct `{takerUsd:0.40, makerUsd:0.25, auctionUsd:0.25}`, money members `mkt_fee_min_eq` $0.10, `mkt_fee_min_bond` $0.10, `mkt_fee_min_fx` $0.10, `mkt_fee_min_crypto` $0.01, `mkt_fee_min_commodity` $0.10 (`{kind:'money', micros:'100000', currency:'GAME'}` etc.).
4. **Live override** (23 §2.2 rule E: owner 02 keys are never live; 23 §8 test 9): `TABLE.liveOverrides = { holiday_fx_depth_mult: { live: false, liveCode: 'E', reason: '23 §2.2 rule E / 23 §8.9; the row text says yes' } }`. The raw cell stays `yes`.
5. Every other row must parse with T23-01's rules without override; if one does not, stop and report `SPEC QUESTION: <key> <cell>` (do not invent a value).
