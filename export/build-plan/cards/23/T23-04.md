## Goal
Copy the 23 §4 tables of owner modules 09 (51 keys) and 10 (69 keys) into `@tycoon/params` data files, with exact overrides for composite defaults and exact family expansions for the real-estate tables, so businesses and property code read every number from the registry.

## Imports
- T23-01: `RawRow`, `OwnerTable`, `ParamValue`, `FamilyMember`, `buildParamSet`, `createParamsView`.

## Exports
```ts
// packages/params/src/registry/m09.ts, m10.ts
export const TABLE: OwnerTable;   // owner '09' | '10'
// Content-sourced family (no members here): 'grid_mw_<district>' (see step 4)
export const CONTENT_SOURCED_FAMILIES: readonly string[];   // exported from m10.ts: ['grid_mw_<district>']
```

## Implementation steps
1. **Transcription rule**: as T23-02 step 1. Row counts: 09 = 51, 10 = 69.
2. **09 override**: `startups_per_week` struct `{startups:3, perNa:4000, scope:'BLOC'}`.
3. **10 overrides**: `city_envelope_km` struct `{standardSideKm:6, capitalSideKm:9}`; `lease_deposit_months` struct `{RES:1, HOSP:6, other:3}`; `m2_per_household` struct `{working:55, mid:70, prime:110, trophy:260}` (10 §3.4.1 tier order); `max_concurrent_projects` struct `{base:2, perRankIndex:1}`; `permit_days_by_right` struct `{smallGd:2, smallMaxM2:5000, largeGd:5}`; `planning_capacity_per_GD` struct `{base:20, perPopulation:0.0001}`; every family row (`base_cost_<type>`, `base_rent_<use>_<tier>`, `cap_premium_<use>_<tier>`, `cityRentMult_<city>`, `dev_days_<type>`, `grid_mw_<district>`, `maint_rate_<use>`, `max_ltv_<product>`, `mortgage_base_spread_<product>`, `natural_vacancy_<use>`, `property_tax_rate_<city>`): text (cell verbatim).
