## Goal
Assemble the 20 owner tables into the launch parameter set (`paramsVersion = 1`), write it as `params/v1.json` (23 §2.3 rule 1), and add the checks that keep the registry, the spec and the code in agreement: the spec re-extraction (23 §7, test 1), one row per key (test 2), exact key set at load (test 3), no alias key in code (test 4), adopted conflict values (test 5), live rule (test 9), and the static invariant INV-STR-007 (every PARAM read in code exists in 23 with default and range; every key is read or reserved).

- T23-01: `buildParamSet`, `toJsonFile`, `fromJsonFile`, `createParamsView`, `ParamSet`, `OwnerTable`.
- T23-02 … T23-07: `TABLE` of `registry/m02.ts` … `m21.ts`; `CONTENT_SOURCED_FAMILIES` of `m10.ts`.
- T19A-05: `registerStaticCheck`.

## Implementation steps
1. `buildParamSet` gains an options argument `{ contentSourcedFamilies?: string[] }` (edit `set.ts` of T23-01): listed families may have zero members.
2. `registry/index.ts` imports the 20 tables; `launchParamSet` builds them; `build-set.ts` writes `params/v1.json` via `toJsonFile` and the test compares the committed file with a fresh build (stale file fails).
3. `aliases.ts`: every alias key of 23 §5.2 with its canonical key: `na_per_new_city`, `city_open_na_step` -> `new_city_na_step`; `major_min_gap_game_days` -> `macro_major_min_gap_days`; `storm_rate` -> `macro_storm_rate`; `ripple_rate` -> `macro_ripple_rate`; `push_max_per_real_day`, `ui_push_daily_cap` -> `push_cap_per_real_day`; `home_city_change_fee` -> `home_city_change_fee_real`; `du_per_tick_per_player` -> `du_hard_cap`; `du_per_tick_per_partition` -> `du_partition_cap`; `audit_retention_days` -> `audit_retention_years`; `timezone_change_cooldown_days` -> `tz_change_cooldown_days`; `client_tick_render_ms` -> `ui_perf_tick_render_ms`; `client_js_budget_kb` -> `ui_js_budget_kb`; `world_phase_budget_ms` -> `phase_budget_ms_P3`; `ins_min_deductible_pct` -> `insurance_deductible_pct`; `entropy_reveal_delay_ticks` -> `entropy_reveal_lag_ticks`; `onb_account_required_minutes` -> `guest_max_real_minutes`; `cross_bloc_setup_delay_game_days` -> `cross_bloc_settle_delay_ticks`; `ui_support_reports_per_day` -> `support_tickets_per_day`; `participation_rate` -> `lf_share`; `fx_uip_pass` -> `macro_fx_uip_share`; `stab_min_population` -> `stab_min_sample`; `stab_observe_only_real_days` -> `stab_observe_game_days`; `max_client_tick_lag` -> `intent_max_age_ticks`; `maintenance_max_minutes_per_real_week` -> `liveops_maintenance_max_minutes` (26 entries). Retired keys of 23 §5.5 (`biz_ltv_cap`, `fund_filing_aum`) are also treated as forbidden in code.
4. `extract-spec-keys.ts` (23 §7 step 1): read `docs/spec/00-*.md` … `docs/spec/21-*.md` and `docs/spec/_notes/02-notes.md` … `21-notes.md`; find every `PARAM\.[A-Za-z][A-Za-z0-9_]*`; expand brace lists `PARAM.x_{a,b}` into `x_a`, `x_b`; a match directly followed by `<`, `*` or ending with `_` is a family reference and is resolved by prefix against family rows; `PARAM.phase_budget_ms_P0 … PARAM.phase_budget_ms_P14` style ranges expand to every index in between. Each extracted key must be a registry row, a family member or family reference, or an alias; anything else is reported.
5. `scan-code.ts`: scan `apps/**`, `packages/**` (`.ts`, `.tsx`, `.mts`, excluding `node_modules`, `dist`, `.next`, `packages/params/src/registry/**`, `packages/params/src/aliases.ts`, `docs/**`) for (a) reads: string literal first arguments of calls `.num(`, `.int(`, `.bool(`, `.str(`, `.money(`, `.ticks(`, `.ms(`, `.list(`, `.uniform(`, `.struct(`, `.table(`, `.text(` whose receiver expression ends with `params`, plus string literals inside an exported `PARAM_KEYS` array of any `packages/engine/*/params.ts` (each engine module's `params.ts` exports `export const PARAM_KEYS = [...] as const` listing every key it reads; T19A-04's folder map tells which module owns the file); (b) alias hits: any alias or retired key as a whole word in code.
6. **INV-STR-007** static check (`packages/params/static-checks.ts`, `registerStaticCheck({ id: 'INV-STR-007', owner: '23', run })`): fail when (i) a read key is not in the launch set (row or member), or its row has no default or range (`range.kind === 'any'` is allowed only for kinds bool/string/text/table/struct); (ii) for every owner module whose engine folder contains `params.ts` (or, for owners without an engine folder, 17 -> `packages/ui`, 18 -> `apps/web/app/(game)/academy`, 19 -> `apps/world` or `apps/gateway`, 20 -> `apps/harness`, 21 -> `apps/admin`, existing as a folder with a `params.ts`), every key of that owner is read somewhere or listed in `RESERVED` with a reason. Owners whose code does not exist yet are skipped (their units are not built; 20 Rule 3.9.5 stage gates).
7. Register a second static check `PARAM-ALIAS` (owner 23) that fails on any alias hit (23 §2.3 rule 2, test 4).
