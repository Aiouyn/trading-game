## Goal
NPCs choose like motivated people under the same rules as players, and never see or punish a player's private state or success.

## Imports
- T16A-02 scheduler (deferral in (dueTick, actorId) order), T16B-01, T16B-02.
- Owner validation via each module's intent validators (ports).

## Exports
```ts
export function utility(actor, a: Candidate, obs: Observation): number;   // §3.3.3 (E-32, PROVISIONAL: κ 1.0, trust 0.3, memory 0.3 with term capped at −0.3 per counterparty, τ = 0.05 + 0.15·(1 − patience); choice = softmax P(a)=e^{U_a/τ}/Σe^{U/τ})
export function decide(ctx, actorId: Id, epoch: 'STRATEGIC'|'TACTICAL'|'REACTIVE'): Intent[];   // ≤ 2, margin 0.05
export function observation(read, actorId: Id): Observation;            // firewall: public + own + contracts + own facts
export function focusOf(read, actorId: Id): 'FOCUS'|'BACKGROUND'|'IDLE';
```

## Implementation steps
1. Candidates from the archetype catalog (T16B-05), filtered by the owner's validation exactly as a player intent; illegal candidates only when `integrity < 0.25` and the archetype allows it, routed through 12/13.
2. Cadence per §3.3.4 with `hash(actorId)` offsets; reactive ≤ 1 per 30 ticks.
3. Focus recomputed at day close; BACKGROUND uses the cached policy table; IDLE decides only on strategic epochs when goals are breached. Detail never creates money.
4. Firewall: `observation` is the only input; a static dependency allowlist forbids reads of player private state, rank, NW, boards or Prestige.
5. Fairness: judges never affect verdicts; regulator multipliers apply per category; NPC funds ≤ 0.5 × ADV per tick with seed-jittered parameters.
6. All utility coefficients are 'Quant'.

## Test plan
  - **16#6** static analysis: no decision function reads player private state, rank, NW, boards or Prestige.
  - **16#7** two worlds identical except one player's NW ×100 give identical NPC decisions.
  - **16#8** an actor acts only when `U(best) − U(NO_OP) > 0.05`, at most 2 actions per epoch, reactive ≤ 1 per 30 ticks.
  - **16#11** NPC funds never exceed 0.5 × ADV participation per tick (05 fixture until 05 lands).
  - **AC-16B-03-DEFER** with 3,000 due evaluations in one tick, 2,000 run and 1,000 defer in `(dueTick, actorId)` order; none are dropped.
  - **AC-16B-03-SOFTMAX** (E-32, PROVISIONAL) choice is the softmax with τ = 0.05 + 0.15·(1 − patience). Test vector: 5 candidates spaced by 0.1, patience 0.5 (τ 0.125) → P(best) = 0.561 ± 0.005 closed form; empirical over 10⁵ seeded draws within 3σ.
  - **AC-16B-03-MEMCAP** (E-32, PROVISIONAL) the memory term is clamped to ≥ −0.3 per counterparty (`actor_memory_term_cap`). Test: three bad memories at salience 0.8 give −0.30, not −0.72; trust term stays within ±0.30.
