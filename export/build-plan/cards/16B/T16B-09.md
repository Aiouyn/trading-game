## Goal
The priced, public ways players influence politics, with diminishing returns and no anonymous money.

## Imports
- T16B-08; T15A-02 `linkedAccounts` (pooling), T15A-04 escrow over 03 holds (petition commitments).
- Codes (E-30): `LOBBY_SPEND`→`WLD_LOBBYING_SPEND`, `POL_CONTRIBUTION`→`WLD_CAMPAIGN_DONATION` (aliases); `ISSUE_CAMPAIGN`, `PETITION_COMMIT` rows with amounts 'Quant'.

## Exports
```ts
export function lobbyIndex(read, caucusId: Id, billId: Id): number;   // clamp(0.25·(√(F_for/$1M) − √(F_against/$1M)), ±0.75)
```

## Implementation steps
1. All amounts real dollars; nominal at the tick paid (edge §8.16). Spend is public by name at the next day close.
2. Linked accounts pooled and capped as one entity; both sides from one link group cancel (edge §8.12).
3. Election utility β_inc 3.0 (E-32, PROVISIONAL), β_iss 2.0, β_camp 0.3, ε N(0, 0.15) (confirmed); voterMedian gets N(0, `pol_median_drift_sd` = 0.05) per axis per quarter on `rng('world.politics', quarter)`; elections never inside a finish window (edge §8.5).
4. Petitions: max 2 per bloc per quarter; banned backer's escrow released (edge §8.13).
5. `soc.pol.campaign` and `soc.pol.petition.open/back` stay rejected (`WORLD_AMOUNT_UNSET`) until Quant sets the amounts (E-30).
