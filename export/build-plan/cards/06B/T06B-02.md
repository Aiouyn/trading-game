## Goal
Price every option series deterministically from its underlying, the vol surface (T06B-03 supplies `σ(K,T)`), 04's `ois` zero rates and 09's projected dividends: European options by Black-Scholes on spot with a continuous dividend yield (equity, index, ETF), Black-76 on futures, Garman-Kohlhagen on FX; American options by a Cox-Ross-Rubinstein binomial tree with `opt_crr_steps = 128`, discrete dividends handled by the escrowed-dividend method and early exercise checked at each node. Greeks are computed only on demand and cached per series for 30 ticks (01 §13 budget rule). The near-expiry rule removes singularities. The result is registered as the OPTION `ModelValuer` used by 06A marks.

## Implementation steps
1. Black-Scholes: `d1 = (ln(S/K) + (r − q + σ²/2)T)/(σ√T)`, `d2 = d1 − σ√T`; call `S e^{−qT} N(d1) − K e^{−rT} N(d2)`, put `K e^{−rT} N(−d2) − S e^{−qT} N(−d1)`. Black-76 replaces `S e^{−qT}` by `F e^{−rT}`. Garman-Kohlhagen = BS with `r = ois(quote ccy)`, `q = ois(base ccy)` (pair base/quote from 06A ids). `N` is `dmath.normCdf` (deterministic polynomial, GLOBAL-CONTEXT dmath); all inputs are `number`; contract value is converted with `toMoney` (half-even) only when posted or marked.
2. Model choice from the series' rule (T06B-01): INDEX/ETF European → BS on spot with `q` (index: dividend-weighted constituent yields); SINGLE_STOCK American → CRR with discrete dividends; FUTURE options (American on the future) → CRR on F with `q = r` (futures-style, no carry) and no dividends; FX European → GK; CRYPTO European cash → BS with `q = 0`, `r = ois(FDL)`.
3. `r` for discounting = `ois` zero of the settlement currency at T; `T = (expiryTick − tick)/262,080` (game years).
4. CRR (§3.13.2): `steps = PARAM.opt_crr_steps` (128), `Δt = T/steps`, `u = e^{σ√Δt}`, `d = 1/u`, `p = (e^{(r−q)Δt} − d)/(u − d)`, clamp `p` into [0, 1] (assert in tests it is inside for the configured ranges). Escrowed-dividend method: `S* = S − Σ PV(D_i)` for dividends with ex-date before expiry (`PV = D e^{−r t_i}`); build the tree on `S*`; at node (i, j) the exercise value uses `S*_node + Σ_{t_k > t_i} PV_{t_i}(D_k)`; backward induction `V = max(exercise, e^{−rΔt}(pV_u + (1−p)V_d))`; count nodes where exercise wins (`earlyExerciseNodes`, used by 06#35's test in T06B-05).
5. Near-expiry rule (§3.13.2): if `expiryTick − tick ≤ 30`, value = `nearExpiryValue(intrinsic, vega, ΔIV, tickSize)` where vega is the analytic BS vega at the current σ, `ΔIV` = the change of σ(K,T) since the last game hour (from T06B-03's surface cache, 0 if none), and the floor is one price tick of the series (`MarketSpec.tickSize`). Intrinsic uses the live underlying price (cash series: the running settlement reference).
6. Greeks: BS analytic (European) or central finite differences on the CRR tree (American: bump S by ±0.5%, σ by ±1 vol point, T by −1 game day, r by ±1 bp); computed only when asked (a view, 07's margin call, the dealer hedge in T06B-03); cache row `{id: seriesId, tick}` reused while `tick − row.tick < 30`. The dealer hedge reads greeks through this cache so it does not recompute 128-step trees per tick for every series.
7. `registerOptionValuer`: registers `('OPTION', (store, id, tick) => optionValue(...) × multiplier)` with T06A-02 so `markPrice` of an option uses the model when no fresh clamped print exists (06 §3.3.3).
