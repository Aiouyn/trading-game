## Goal
Compute GXV, the published 30-game-day implied volatility of GX100 in vol points, by the variance-swap formula of 06 §3.5.3 over the full strike grid of the two GX100 option expiries bracketing 30 game days, from NPC OTM mids (which exist for every grid strike, materialized or not), interpolated in total variance, bounded [5, 150], computed in P6 after the option quotes update and published in P14 every tick (delta-compressed). Provide the single accessor `fear06` that every 06 formula uses (`F/100` of the previous game hour, D097) and a repository audit test that no 06 code reads fear any other way. GXV is an information product: a candidate input to 04 and to analytics, never a replacement for F.

## Implementation steps
1. Strikes: the full T06B-01 grid of each bracketing GX100 expiry (European, cash). `F` = GX100 forward for that expiry (`S e^{(r−q)T}`); `K0` = the first grid strike ≤ F. `Q(K)` = NPC mid of the OTM option at K (put for K < K0, call for K > K0, the average of call and put at K0), priced via T06B-02 with `sigmaOf` (no book required).
2. `ΔK_i = (K_{i+1} − K_{i−1})/2` (ends: one-sided difference). `σ²(T) = (2/T) Σ (ΔK_i/K_i²) e^{rT} Q(K_i) − (1/T)(F/K0 − 1)²`.
3. Bracket 30 game days: `T1 ≤ 30/364 < T2`; `σ²_30 = [σ²(T1)T1·(T2 − T)/(T2 − T1) + σ²(T2)T2·(T − T1)/(T2 − T1)] / T`; `GXV = 100·sqrt(max(σ²_30, 0))`, clamped to [5, 150] (23 owner-table row ast_gxv_bounds, read as a 06 constant).
4. Timing: P6 after `surfaceStep` (T06B-03) so the quotes of this tick are used; publication in P14 (`mkt.gxv.updated` PUBLIC, payload `{gxv, tick}`, emitted when it changed by ≥ 0.01 vol pt since the last emission, and at least every 30 ticks).
5. Fear: `fear06` reads 04's committed hourly F (the value committed at the previous game hour; 04 updates F each game hour), so option prices this hour cannot feed back into this hour's F: no circularity. 06B and 06C formulas call `fear06`; 06A reads `getGlobalMacro(store).fearIndex / 100` directly (same committed value). The audit test scans `packages/engine/assets/**` and fails if any fear read uses anything other than the committed `getGlobalMacro(store).fearIndex` (e.g. 04's working state or a GXV-derived value) or omits the `/100` scaling.
6. The ATM-vol floor `0.10 + 0.004·F` is applied by T06B-03; this task asserts it in tests.
