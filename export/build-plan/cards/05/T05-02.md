## Goal
Pure functions that tell every other 05 rule what the market clock is: whether a tick is a value-layer active tick, the scheduled trading state of an asset at a tick of day (before halts are overlaid), which auction (if any) clears this tick, when indicative auctions publish, the active-ticks-per-year `A` and days-per-year `Dy`, and the official daily price rule (closing auction price, fallback VWAP of the last 10 continuous ticks, crypto 530–540 VWAP).

## Imports
- T05-01: `SessionProfile`, `TradingState`, `AuctionResult`, `MarketSpec`, `MarketAux`, `SPEC_CONSTANTS`.

## Implementation steps
1. Trading day: `cal.weekday` 0..4 are Mon..Fri trading days; 5, 6 weekend. No holiday table at launch (D071); expose the function so a holiday table from 22 could be added later without changing callers.
2. `scheduledSlot` per 05 §3.2.2:
   - EXCHANGE_SESSION, trading day: t 0..59 `PRE_OPEN` (entry only, no matching); t=60 `OPENING_AUCTION` (auction 'OPEN', matching); 61..539 `CONTINUOUS` ('TICK'); t=540 `CLOSING_AUCTION` ('CLOSE'); 541..719 `CLOSED` (entry allowed, queued for next open). Weekend: `CLOSED` all day, entry allowed.
   - FX_24_5: trading days every tick `CONTINUOUS` with 'TICK', except t=540 'CLOSE' (the fix) and weekday 0 (Monday) t=0 'REOPEN' (weekly reopen). Weekend `CLOSED`. (00 states FX closes Sat 00:00 to Sun 22:00; 05 §3.2.2 owns the market profile and closes FX for the whole weekend; follow 05.)
   - FUT_24_5: trading days every tick except t 710..719 `CLOSED` (maintenance); t=540 'CLOSE' (settlement); t=0 'REOPEN' on every trading day. Weekend `CLOSED`.
   - CRYPTO_24_7: every tick `CONTINUOUS` 'TICK'; never an auction.
   - `indicativeWindow`: t 50..59 for EXCHANGE_SESSION opening (from t=50), t 530..539 for every closing/fix/settlement; reopen windows (10 ticks before a halt's reopen) are added by T05-07.
3. Active value clock (05 §3.2.3, D073): session profiles step on every tick of a trading day (including closed hours); weekend ticks do not diffuse (but shocks still apply, handled by T05-03). Crypto steps every tick. `A` = `PARAM.mkt_active_ticks_session` or `PARAM.mkt_active_ticks_crypto`.
4. `nightsSinceLastSession`: nights = number of game-day boundaries crossed since the previous trading day's session ended (Tue..Fri open = 1, Monday open = 3). For a REOPEN after an intraday halt it is 0. The opening band uses `√(nights + 1)` as 05 §3.9.1 states (T05-07 calls this).
5. `officialClose` (05 §3.10.2): if `l3Stopped` (market-wide L3, 05 §8 edge 4) return `lastPrice`. If profile has a closing auction and it printed (`qty > 0`) return its price; else if `last10.qty > 0` return `toPrice(last10.num / last10.qty)` (VWAP of the last 10 continuous ticks, 530..539); else `lastPrice`. Crypto: `mark540` VWAP of ticks 530..540 (D072), else `lastPrice`. VWAP numerators are Σ price(float of micro-units) × qty(float of lots); convert back with `toPrice`.
6. 05 §3.10.3: EXCHANGE_SESSION orders entered after 540 queue for the next opening auction (state CLOSED, `acceptsEntry: true`, `matching: false`); DAY orders entered after the close belong to the next session (T05-10 uses `dailyCloseTickOf` and entry tick to compute the DAY expiry).
7. Edge cases owned here (05 §8): edge 5 (weekend news: `isValueActiveTick` false on weekends yet T05-03 still applies shocks; crypto trades at once; equities gap at Monday's open); edge 20 (a daily close tick that coincides with a volatility interruption: `scheduledSlot` returns CLOSING_AUCTION and T05-07 must let the scheduled close override the interruption); edge 25 (year and chapter ends: no special behaviour, nothing in this file depends on year or chapter).
