## Goal
Lay down every type, table, constant, port interface and event schema of module 05 so every later 05 task imports one stable contract. 05 is built before 06, 07, 08, 09, 11, 12, 15, 16 and 18, yet consumes their data; this task defines **ports** (read-only provider interfaces over `StoreRead`) that those later modules implement against 05's types, with exact default behaviour when the provider is not loaded. It also resolves a `MarketSpec` from 06's partial instrument record plus 05's class defaults (05 §3.3.6, §3.4.6).

## Implementation steps
1. `schema.ts`: transcribe every type of 05 §2.1 to §2.8 verbatim (names, unions, field names and optionality). `Money`, `Qty`, `Price` are `bigint`. Add the extra types listed in Exports (they hold state the spec requires but §2 leaves implicit: aux per asset, daily bars for the 500-day history of §3.17, owner-group fee stats of §3.15.1, factor EWMA state of §3.17, bloc circuit-breaker state of §3.9.3, index state of §3.22, active world hooks of §6.4, claim state of §6.3, shock records of §3.12.5).
2. Declare every `TableDef` with `module: '05'` and the names and indexes above. `idOf`: spec/price/aux by `assetId`; order by `orderId`; algo by `algoId`; auction by `assetId` (latest result); fill by `fillId`; cause tables by `${assetId}:${gameDay}` or `${assetId}:${gameDay}:${hour}` with day zero-padded to 6 digits and hour to 2 so byte order is chronological; surv by `${ownerGroupId}:${gameDay6}`; hist by `${assetId}:${gameDay6}`; group by ownerGroupId; bloc by bloc code; block by crossId; mm by `${ownerGroupId}:${entityId}`.
3. `constants.ts`: stream keys use 02's registry format (02 §3.10.4) with colon subjects: `mkt.factor:<factorId>`, `mkt.idio:<assetId>`, `mkt.jump:<assetId>`, `mkt.npc_flow:<assetId>`, `mkt.lp_quote:<assetId>`. 05's text names streams `mkt/pool`, `mkt/bg`, `mkt/alloc` that the binding registry does not list; this unit maps pool noise and background volume to `mkt.npc_flow:<assetId>` (NPC order-flow noise) and allocation remainder ordering to `mkt.lp_quote:<assetId>` (NPC quote jitter). `mkt.earnings`, `mkt.corp_action`, `mkt.surveillance_sample` are registered as owned prefixes (02 §3.10.4) and are not drawn by 05 rules. Volume tiers per 05 §3.15.1: `[{min:0,mult:1.0},{min:$10M,0.8},{min:$100M,0.6},{min:$1B,0.5,highVolume:true}]` as `toMoney` FDL values.
4. `events.ts`: one zod schema per event kind of 05 §5 with the payload types of §2 (`mkt.fill` = `Fill`, `mkt.auction.result` = `AuctionResult`, `mkt.cause.*` = `CauseVector`, `mkt.surveillance.daily` = `SurveillanceFeatures`). Money/Price/Qty fields are decimal strings on the wire (`z.string().regex(/^-?\d+$/)`). Visibility: owner events PRIVATE; public ones PUBLIC; `mkt.surveillance.daily` SEALED; `mkt.ownership.thresholdCrossed` PARTIES; `mkt.block.done/failed` PARTIES; `mkt.block.print` PUBLIC; `mkt.bondDepthIndex` PUBLIC. `mkt.flag.belowMinPrice` (PUBLIC, `{assetId, tick}`) is the flag of 05 §8 edge 17 for 09. The `TapePrint` schema is `.strict()` and has exactly the fields of §2.5 (no account, owner, order or counterparty field), the L11 guarantee.
5. `classDefaults.ts`: transcribe the table of 05 §3.3.6 exactly. Session profile, halt rule and fee class per class from 05 §3.2.2, §3.9 and §3.15.1 (EQUITY/ETF/COMPUTE/DATA_CREDIT: EXCHANGE_SESSION, EQUITY_LULD (ETF: ETF_FOLLOW for halts that follow an index, else EQUITY_LULD), EQ or COMMODITY fee; GOV_BOND/CORP_BOND: EXCHANGE_SESSION, BOND, BOND; FX: FX_24_5, FX_NONE, FX; FUTURE/COMMODITY_SPOT/ENERGY_MWH: FUT_24_5, FUT_LIMITS, FUT (spot and MWh: COMMODITY); crypto classes and PERP: CRYPTO_24_7, CRYPTO_NONE, CRYPTO; OPTION: EXCHANGE_SESSION or FUT_24_5 by underlying, OPTION_FOLLOW, OPT). Pool weights per class are 05 §6.2's "Classes (default weight)" column. `resolveMarketSpec` fills unset fields from these tables and 06's `priceParams`; `impactY` falls back to `PARAM.mkt_impact_y_default`. `guardGap` and `openPrint` may be null (crypto). Reject at load (return issues list in a thrown-free way via `validateLoadings`) any spec with `Σ L² > 1` (05 §3.3.3 authoring check).
6. `ports.ts` defaults (used when the provider module is not loaded; they are empty inputs, never different rules): every `valueShocks/claims/resolutions/flows/orders` returns `[]`; `anchor` returns `{ lnF: current PriceState.lnF }` read from `mkt.price`; `priceParams` reads the resolved `MarketSpec` values; `hype` 0; `dealerNetGamma` 0; `packageQuote` null (the package is then rejected `SESSION_CLOSED_FOR_TYPE`, because no options maker is quoting); `credit: null` means no margin accounts exist and short sales reject `NO_LOCATE`; `ownerGroupOf` = last element of 03 `ownerChain` (the root `chr`/`npc`/`gov`/`sys`); `linkedGroups` []; `firstTradeCap` null; `prestigeReach` 0; `sourceRecord` {0,0}; `newsworthinessToday` 0; `subscriptionTier` 'NONE'; `navStrikeDay` false; `isPlayerCompany` false; `sizeOf` from the MarketSpec `floatShares` (else 0); `mandateClientsOf`/`managedFundsOf` [].
7. Rejections are `{ code: 'MKT_' + code }` (G6 `<MOD>_<REASON>`).
