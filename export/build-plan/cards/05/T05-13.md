## Goal
Private algo parents that generate at most one LIMIT IOC child per tick in sub-phase 6.0 following a TWAP, VWAP, POV or Almgren–Chriss IS schedule, capped per tick, pausing in halts and unconfigured auctions; plus the intents `mkt.algo.start/modify/pause/resume/cancel` (LIC2, D082) and the read-only `mkt.algo.schedulePreview` helper. Also used for auto-split POV parents (T05-11).

## Implementation steps
1. Schedules (05 §3.7) on active matching ticks between `startTick` and `endTick`:
   - TWAP: `target(N) = Q × elapsedActive/totalActive`, child = target − filled.
   - VWAP: `target(N) = Q × cumulativeProfile(start..N)/cumulativeProfile(start..end)`.
   - POV: child = `participation × vol_{N−1}` (default 0.10, max 0.30) where `vol_{N−1}` = previous tick's matched volume (orders + maker; background excluded, exploit #19); at least 1 lot when behind the participation schedule.
   - IS: `remaining(N) = Q sinh(κ(T−τ))/sinh(κT)`, `κ = urgency × 3 / T`, τ and T in active ticks; urgency default 0.5; urgency 0 degenerates to TWAP (use the limit `(T−τ)/T` to avoid 0/0).
2. Common rules: each child ≤ `maxChildPerTickAdv` (default `PARAM.mkt_algo_child_cap`) × ADV, rounded down to lots; child limit = `min(limitPrice, ref + (s + limitOffsetTicks × gridTick))` for buys (`max(limitPrice, ref − ...)` for sells), ref = last price of N−1, `s` the maker half-spread of N−1. One child per tick, LIMIT IOC, ordinary priority (priorityTick N). The parent is never visible to anyone else (no depth, no events to others).
3. Pause automatically during HALTED, VOL_INTERRUPTION, LIMIT_LOCKED and auctions the algo is not configured for, then resume. `AlgoParent.params` has no auction option, so every algo is configured for continuous ('TICK') matching only and pauses during OPEN, CLOSE and REOPEN auctions (24-hour assets' fix/settlement auction included). Asset suspended (edge 11): algos cancel and holds release. Held start for UI/API-started parents: PAUSED until Held ends (T05-11 step 1.3).
4. Intents (P1): `mkt.algo.start {accountId, assetId, side, kind, qty, startTick, endTick, limitPrice?, params}` requires LIC2 (`NO_LICENSE`) unless created by auto-split; validated like an order for buying power on the whole parent (hold for qty × limit or band hi); `modify` (qty, limit, endTick, params), `pause`, `resume`, `cancel` act in P1 (`ORDER_NOT_FOUND` for unknown ids). AI agents and operators use the same intents under the same license.
5. Each tick a working parent emits PRIVATE `mkt.algo.progress {algoId, filledQty, scheduleFilledTarget, childQty, avgPrice}`; status changes emit `mkt.algo.status`. Status DONE when filled or endTick passed (remaining hold released).
