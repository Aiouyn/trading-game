## Goal
Unverified statements about an asset (player Wire claims, short reports, 16's rumors and telegraph precursors, analyst notes, rebuttals, and value shocks with `uncertainty > 0`) move what the market believes without changing value: the belief overlay `b` enters the maker's reference price directly, credible well-evidenced wide-reach claims move prices a lot, weak ones fade, and on resolution a true claim hands off to the real value shock while a false one reverts with a 60-tick half-life.

- T05-03: `ValueStepOutput.beliefShocks`.
- T05-04: `PriceState.belief` is read by `referencePrice`.

## Implementation steps
1. Claim sources (05 §6.3): `ports.social.claims` (15 Wire structured claims, short reports), `ports.world.claims` (16 rumors and telegraph precursors; for telegraph items `cr_c = baseCredibility` carried in the claim), and value shocks with `uncertainty > 0` from T05-03 (converted to a claim with `assertedMove = logMove`, `cr = 1 − uncertainty`, reach 1, source = the shock's sourceRef). 05 reads the structured claim, never text.
2. Asserted move `a_c`: from 22's claim-kind table (`claimKindMove`), else the size the owner module gives the fact if true (`assertedMove` in the claim). Sign = `direction`.
3. Credibility (05 §6.3): `srcRecord` = Beta(2,2) mean of the source's public record (16 `RumorSource` or the player's claim history via `ports.world.sourceRecord`); NPCs never see hidden accuracy. `evidence` = share of evidenceRefs pointing to verifiable engine records (`verifiableEvidenceShare`); `prestigeReach` from `ports.prestige` (14); `rebuttal` 1 for a verifiable rebuttal by the target (12 M4), 0.5 for an unverifiable denial, else 0; recompute when a rebuttal claim about the same claimId arrives.
4. Overlay: `b_c(t) = a_c × cr_c × reach_c × (1 − e^{−(t − t0)/τ}) × decay(t)`, `τ = PARAM.mkt_belief_spread_ticks`; `decay` halves every `PARAM.mkt_belief_hl_days` **trading** days while unresolved (count trading-day ticks only). `b = clamp(Σ_c b_c, −PARAM.mkt_belief_cap, +PARAM.mkt_belief_cap)`. Write `ps.belief = b` each tick in P3 (it enters `lnRef`, 05 §3.4.1). Δb is tagged `BELIEF` with claim and news ids (T05-16).
5. The VALUE pool still sees `lnV` (claims do not change it), so it pushes back within its capacity (skeptics), handled naturally by T05-14.
6. Resolution (`ports.world.resolutions`, engine-revealed facts):
   - TRUE: the owner module delivers the real shock `X` (T05-03); `b_c` is released linearly to 0 over `PARAM.mkt_belief_handoff_ticks` starting at the resolution tick (`valueAtRelease` frozen). The cause vector's gap tracer hands BELIEF to the fact's source (T05-16), so there is no double count.
   - FALSE: `b_c` decays with half-life 60 ticks from `valueAtRelease`; the source's record updates (16 owns it); 12 flags knowingly false claims; surveillance F15 scores overlaps with positions (T05-17 reads `mkt.claim` rows with status RELEASING_FALSE and `ports.conflict.falseClaimFlags`). Exploit #15.
   - Rows reaching |b_c| < 1e−9 after release become DONE and are deleted after 28 game days.
7. Edge 22: a claim about a halted asset keeps accumulating (P3 runs regardless of trading state) and is visible at the reopen auction.

## Test plan
- `belief.test.ts`:
  - Credibility worked: srcRecord 0.5, evidence 1, prestigeReach 0.6, rebuttal 0 → 0.15 + 0.225 + 0.25 + 0.09 = 0.715; with verifiable rebuttal → 0.415; clamp at 0 and 1.

  - Cap: three claims of −0.3 each fully spread → b = −0.5.
  - **05#48 a credible, evidenced false claim moves the price then reverts with a 60-tick half-life after resolution**: TestWorld with 03, 04, 05 and a fixture WorldPort: claim a −0.25, cr 0.715, reach 1; run 300 ticks: lnP falls by at least 50% of the steady b (VALUE pool pushes back); resolve FALSE: b halves every 60 ticks (|b(t+60)/b(t)| = 0.5 ± 1e−9) and lnP recovers toward lnV (gap at +240 ticks ≤ 1/8 of the gap at resolution + flow noise tolerance 0.002).
  - TRUE hand-off: b releases linearly to 0 over 15 ticks while the true shock moves lnV by −0.25; `lnRef` path is continuous (no double jump: |Δ lnRef| on the resolution tick ≤ newsPrint × 0.25 + 0.001).
  - Edge 22: halted asset, claim accumulates; b at reopen equals the formula value.
