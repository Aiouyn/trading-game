## Goal
The single place where price impact exists in the game (T08, D076). One logical NPC maker per asset quotes an analytic square-root supply and demand curve around `lnRef = lnB + Π + T + b + skew`; after each auction its net fill updates the shared daily tally (permanent impact), transient impact (decaying with a 15-tick half-life), and inventory (skew, side depth, 12% layoff at close). Its base `lnB` follows the value layer partially (valuePrint, newsPrint, guard, opening print), which creates the price–value gap that pools trade.

## Implementation steps
1. Half-spread (05 §3.4.2): `s = baseHalfSpread × (1 + PARAM.mkt_spread_fear_k × F/100) × (1 + 0.5(√h − 1)) × m_spread,event × m_spread,time`; `m_spread,time = 1.5` in the first and last 10 continuous ticks (`isFirstOrLastContinuousTicks`), else 1; `m_spread,event = 1` (04's hook catalog, 04 §3.16.6, defines only depth withdrawals, so no current hook widens the spread; keep the factor as an input). Floor: `s ≥ ½ × ln(1 + gridTick/price)`.
2. Depth: `D = PARAM.mkt_depth_base × (1 − PARAM.mkt_depth_fear_k × F/100) × regimeDepth × m_depth,event × mmCrowding × invSide`, floored at `PARAM.mkt_depth_floor`; × `PARAM.mkt_auction_depth_mult` in OPEN, CLOSE, REOPEN and VOL_INTERRUPTION reopen auctions. `invSide` applies only to the side that increases `|inv|` (long maker: its bid side). `mmCrowding` is per level (05 §3.19.4), supplied by T05-18 as a function of log distance; default `() => 1`.
3. Ladder (05 §3.4.2): `Q_ask(δ) = D_ask × ADV × ((δ − s)/(Y σ_d))²` for δ ≥ s. Quantities in ADV units internally; convert to lots with `ADV_lots = advUnits × size / lotSize` as float and round down to whole lots with `toQty(x, lotScale, 'LOT_FLOOR')`. Evaluate analytically at grid prices only (no materialized orders, 05 §3.23). `makerBreakpoints` returns every grid price inside [lo, hi] at which the cumulative whole-lot quantity increases, capped at 512 points per side by stepping through quantity increments of one lot or one grid tick, whichever is coarser, so the candidate set stays bounded.
4. After the auction (called by T05-06 with the maker's net fill `q_N` in ADV units, + = maker sold):
   - Tally: `Qc += q_N`; `Π = sign(Qc) φ Y σ_d √(|Qc|/D_day)`, `φ = PARAM.mkt_perm_share`, `D_day` = running mean of D over today's ticks so far (`accumulateDayDepth` each matching tick). `ΔΠ = Π_new − Π_old`.
   - Transient: `I = sign(q_N)(δ(|q_N|) − s)` using the side's depth; `add = I − ΔΠ`, clamped to 0 if its sign is opposite to `I`; `T = ρT + add`, `ρ = 2^(−1/PARAM.mkt_transient_hl_ticks)`. With no fill, `T = ρT`.
   - Inventory: `inv −= q_N`.
5. Skew: `skew = −PARAM.mkt_maker_skew_k × s × clamp(inv/invCap, −1, 1)`, `invCap = PARAM.mkt_maker_inv_cap_adv`.
6. `followValue` (05 §3.4.7) each active tick (also when closed): `ΔlnB = valuePrint(A + D + S) + newsPrint(J + X) + guard`, `guard = −0.05 sign(G) max(0, |G| − guardGap)` with `G = lnRef_{N−1} − lnV_N` (only if guardGap not null). Return the parts so cause tagging (T05-16) can split them (A → FUNDAMENTAL, S per factor, J → COMPANY_NOISE, X per shock source).
7. Opening print at OPEN and every REOPEN (05 §3.4.7, §3.10.1): `lnB −= openPrint × G`, `G = lnRef − lnV`; skipped when `openPrint` is null.
8. Daily close (`dailyCloseTickOf`: 540 session, 719 for 24-hour profiles): `foldDailyTally`; then `layoff` (`inv ← (1 − PARAM.mkt_maker_layoff) inv`, no print, no posting, reference unchanged; 05 §3.4.5; edge 15 "the layoff at close resets 12%"). Reset `D_day` accumulators.
9. FX spot uses the same mechanism with `lnV` = 04 fair value (05 §3.4.7 FX paragraph); the CB edge orders are ordinary pool orders (T05-14). Crosses are implemented in T05-11.
10. Exploit counters owned (05 §9): #1 splitting (tally depends on net daily flow only), #3 pump-and-dump (lnB follows value not flow; permanent impact symmetric). Edge 15 (inventory beyond cap: depth 0.2 on the buying side). Edge 16 (opposing whales: only the net residual reaches `applyMakerFill`).
11. Maker PnL accumulates in a diagnostics field only (`MakerDiag`, not a ledger entity, not in state hash-relevant tables other than `mkt.aux`).
