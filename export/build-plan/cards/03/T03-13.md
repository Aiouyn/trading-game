## Goal
Marks are the prices at which the ledger values positions for net worth, statements, boards and day-close revaluation. This task builds the mark registry that market and model modules publish into (05 clearing and official close, 08 NAV, 04/06 curves and option models, 09/10/06 appraisals, 11 compute spot), the anti-ramping thin-print guard, stale and halted handling, the fallback chain of every row of the 03 §3.9.2 table, the function that values any account at a tick, expected credit loss (03 §3.9.3) and the revaluation-surplus routing rule (03 §3.9.4). Marks never come from a price a player declares, a P2P or related-party price, or a contract term.

## Implementation steps
1. Governance (03 §3.9.1 rule 1): `publishClearing`/`publishClose` accept calls only when `ctx.module` is '05' or '06' (else `ctx.fail('INV-LED-007', [], 'mark from module <m>', '05|06')`); `publishModelMark` rejects source CLEAR/CLOSE; 03 itself never derives a mark from a posting's price (P2P, related-party and contract prices never reach this API).
2. Thin-print guard (rule 2): `mark = (V·P + V_min·mark_prev) / (V + V_min)` with `V_min = PARAM.mark_min_volume_frac × ADV20` (ADV20 from fact `MARKET_STATS` of the asset, quantities as float via `Number(qty)/lotScale`); first print (no prev) → P. Result through `toPrice`. Store in `hourMarks` (reset when `tick % 30 === 0`), set `lastTradeTick`, `validUntilTick = tick + EXCHANGE_STALE_TICKS`, confidence LIQUID, source CLEAR.
3. Stale (rule 3): `effectiveMark` flags `STALE` when `tick > validUntilTick`; NW still uses it; boards apply the extra 10% haircut (T03-17). Equities/ETFs with no trade for 5 game days fall back to `fundamental` (source MODEL_FUND, confidence STALE so the board haircut applies, 03 §8 edge 14). Halted (rule 4): last mark flagged STALE until a new `publishClearing` after `setHalted(false)`.
4. `valueAccount` by code (03 §3.9.2; all in the account's ccy; translation is T03-17's):
   - 1001, 1002, 1003: face (balance). 1010: face; if the bank's status is IN_INSOLVENCY: insured part at face (fact `DEPOSIT_INSURED_LIMIT` of the bank's bloc, 07) and the uninsured part × fact `RESOLUTION_RECOVERY` of the bank (07), recovery 1.0 if absent.
   - 1050, 1060, 1070, 11xx, 1200, 13xx (net of 1309), 1830–1880 (net of 1839), 1700–1740, 1810, 1900, 2xxx: book balance (their values are maintained by postings: called losses, ECL, NRV writedowns, amortized cost, depreciation, amortization, impairment; T03-14 posts the periodic ones). Liabilities are never fair-valued (own credit), except 2600 derivative liabilities.
   - 1210: `qty × mark(commodity)` (06 publishes spot less location basis), fallback front future mark (id `${commodityId}:FRONT`).
   - 1220 OWNED/RESERVED: `qty/1000 × 10 × mark('compute_spot')` ($/GPUh, 11 publishes; RESOLVED C1). 1221: 0 (03 §3.10.2).
   - 1500, 1510: `qty × effectiveMark`. 1520: `qty × clean mark` (fallback `MODEL_CURVE` mark id `${assetId}:MODEL`; defaulted sovereign issuers at RECOVERY marks) plus the accrued interest receivable book (1110 sub assetId).
   - 1530: last NAV mark (08 publishes NAV at day close, intraday estimates as MODEL_FUND); gated funds: 08 publishes the gate-adjusted NAV.
   - 1540: clearing mark (depegged stablecoins at market, never at peg). 1541, 1542: LP or deposit token marks published by 06 (pool reserves × underlying marks).
   - 1560: clearing mark if traded within its validity, else last model mark.
   - 1570: if the installed `EquityMethodFn` returns a value for (holder, issuer of the stake), that value: associates are carried at equity-method value in the parent's solo books (03 §3.11.5 item 4); otherwise `peMark`: last arm's-length round price per share × (1 − `PARAM.pe_mark_decay_per_quarter`)^(whole game quarters since the round), then `min` with `modelValue` (09 valuation per share, preference-adjusted by 09's waterfall); no round → `modelValue × 0.75` (25% illiquidity). Rounds with `armsLength false` are ignored (arm's length = no related parties and ≥ 2 unrelated investors, decided by 09).
   - 1580: `LookThroughFn(holder, sub)` (installed by T03-16; default book balance).
   - 1600/2600: cleared positions book (VM already moved cash); uncleared `qty × MODEL_OPTION / swap / CDS mark` (06 publishes per position id).
   - 1800: latest APPRAISAL mark of the property (10; cadence `PARAM.prop_appraisal_cadence_game_days`, cap ±15% per cadence unless an event; T03-14 posts). 1860: book (14's resale curve applied by `LED_LIFESTYLE_DEPRECIATION`). 1870: INDEX mark × item multiple (06 publishes the item mark).
5. `closeMarkValue`: `notional(qty, closePrice, lotScale)` for the marketable codes of `MARKETABLE_CODES`; undefined if no close today.
6. ECL (03 §3.9.3): `eclAllowance` computes Σ in float then `toMoney` per loan (rounding per loan, then sum). PD and LGD are supplied by 07 (borrower rating or scorecard, collateral LGD); T03-14 posts the daily `LED_ECL_PROVISION` delta and `BNK_LOAN_CHARGEOFF` is 07's on default resolution.
7. `revaluationTarget` (03 §3.9.4): companies (`cmp`, `bnk`, `ins`, `exc`, `rat`) holding property for own use (`heldForUse`) or intangibles above cost → `OCI_3400` (recycled to P&L on disposal); characters and alliances always `PNL`; everything else `PNL` (D042: all characters' property through P&L).
