## Goal
One formula turns compute and data into capability (MCS), calibrated so each tier's typical run lands in its AP band, with legible risk: the planner shows cost, duration, pFail and the outcome quantiles before the player commits.

## Imports
- T11-04 allocation; T11-05 `dRun`, provenance; T11-06 ΔA, S_team; T02-06 stream `ai/<labId>/run/<runId>`.

## Exports
```ts
export function mcsFormula(aEff: number, C: number, D: number, p: ParamsView): number;   // A·k·C^α·D^β·balance
export function balance(rhoD: number): number;                 // clamp(1.15 − 0.55·max(0, |ln ρ| − ln1.25)/(ln4 − ln1.25), .6, 1.15)
export function specMult(focus: Focus, shares: Record<Domain, number>): Record<Domain, number>;
export function durationGD(minRunGD: number, C: number, alloc: number, hparam: Hparam): number;

export function drawOutcome(rng: Rng, i: OutcomeInputs): RunOutcome;   // FAILED / PARTIAL / SUCCEEDED; checkpoint second roll at pFail·0.5
export function fineTune(m: Model, cFt: number, dFt: number): { cCum: number; dCum: number };   // C + 0.5·Cft, 0.5·D + Dft
export function selfDistill(teacher: Model): { mcs: number; inferenceMult: number; compute: number };   // 0.90, 0.40, 0.05·C
export function plan(i: PlanInputs): { cost: CostSplit; durationGD: number; pFail: number; mcsQ: [number, number, number] };
export const startRunHandler: IntentHandler<StartRunReq>;      // quoteHash must match plan
```

## Implementation steps
1. `quoteHash` of `planRun` must match at `startRun` or the intent is refused.
2. Outcome draws on `streamKey11.run`; FAILED without checkpointing ends the run and grants insight; with checkpointing, one re-roll at pFail·0.5.
3. Planner refuses expected duration > `max_run_gd` at the current allocation.
