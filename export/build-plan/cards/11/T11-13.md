## Implementation steps
1. Student inherits teacher's specMult, dataEndTick, trainedRegime, lineage root, product unlocks only if the attacker's lab has the nodes, and poison if the teacher was a decoy; provenance 100% ILLICIT.
2. Walkout: studentMcs = teacher · min(0.85, retentionRaw), residueRaw = watermark (full).
3. Launder L ∈ [0, 1]: cost (0.25 + 0.35·L)·student compute + 0.5·L·D* clean data; residue = max(0.03, raw·(1 − 0.7·L)); retention *= (1 − 0.35·L).
4. Each clean FINETUNE halves poison.
