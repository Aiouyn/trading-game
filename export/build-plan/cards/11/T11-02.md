## Goal
Open the Lab exactly once when NW first reaches $100,000, size every limit from one tier table, and make DU (the decision budget) grow only with owned or reserved compute so spot, P2P-in and leeched compute never buy decision capacity.

## Imports
- T14A-08 peak NW (company labs use the controller's). T03-17 NW at day close. T15A-02 linked characters (starter grant once per character, X21).

## Implementation steps
1. Starter grant posts once (`AI_STARTER_COMPUTE`, FAUCET MINT, E-50 row) as a cloud credit; a second crossing does nothing; Fresh Start (14) does not re-grant.
2. `computeOwnedPerGD` = owned clusters after failures + RESERVED leases only.
3. DU_cap is per controlling character across all labs it controls (X4).
