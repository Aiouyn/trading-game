## Goal
Every margin model reads one volatility per risk factor. This task keeps an EWMA of tick log returns per risk factor, a one-game-year history of daily σ for the stressed floor, and returns `σ_IM` with the anti-procyclicality blend. It is the only place margin volatility is computed, so a crash raises margin quickly and calm periods cannot shrink it below the stressed floor.

## Implementation steps
1. `λ = 2^(−1/PARAM.margin_ewma_halflife_ticks)` (240 → 0.99711605). Returns `r = ln(P_t / P_{t−1})` on the 06A band-clamped mark, never the last print. A factor with no mark this tick is not updated.
2. Seed: a new factor starts with `s2` from the 22 authored σ of its asset class (05/06A genesis vol) or, when the world has the 364-day burn-in history (07 §3.15.5 interface), from that history.
3. `σ_stress` = nearest-rank 99th percentile of the stored daily σ values (sort ascending, index `ceil(0.99·n) − 1`); with fewer than 30 values use the authored class σ as the floor. `w = PARAM.apc_stress_weight`.
4. `scaleIm`: `imAtCompute × round_half_even(σ_now/σ_at · 1e6) / 1e6` with bigint math (03 `mulRate`).
5. Two-speed estimator (E-38, Quant on 07#40): keep a slow EWMA (`margin_ewma_halflife_ticks` 240) and a fast EWMA (`margin_ewma_fast_halflife_ticks` = 60 ticks variance half-life, PROVISIONAL [Quant]; Quant runs it against the engine once T07B-02 code exists); `σ_ewma = max(σ_slow, σ_fast)`, so margin rises fast and decays slowly. The anti-procyclicality blend and stressed floor apply unchanged on top: `σ_IM = sqrt((1 − w)·σ_ewma² + w·σ_stress²)`. `rollDaily` stores the combined σ_ewma.
6. Order: `updateVol` runs before any IM computation in P7, iterating factors in sorted key order (determinism).

  - **AC-07B-02-RESPONSE** (07#40 part b, E-38, PROVISIONAL [Quant]) response test: at t0 the true tick return σ doubles from 0.0005 (σ_stress 0.0006, w 0.25, both EWMAs at steady state); with the two-speed estimator, SCAN IM reaches ≥ 1.6× its t0 value within 240 ticks (expected-variance path: 1.6× at tick ≈ 128, 1.70× at 240; the slow EWMA alone gives 1.42× and fails).   - **AC-07B-02-DECAY** (E-38) after the shock ends, σ_ewma never falls faster than the slow EWMA (max rule) and σ_IM never falls below sqrt(w)·σ_stress (floor kept).
