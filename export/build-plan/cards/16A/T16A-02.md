## Goal
Run all of 16's per-tick and day-close work in a fixed, deterministic order inside the P3 budget, deferring (never dropping) overflow.

## Imports
- T02-12 phase runner (P3, day close t = 719 after P2), T02-17 replay.
- T16A-01 tables and streams.

## Exports
```ts
export function runP3(ctx: PhaseCtx): void;            // order: shocks view → scheduled announcements → rumor publication → consequence due list → reactive actors (16B hook, no-op) → news for tick−1 → history (16C hook, no-op)
export function runDayClose(ctx: PhaseCtx): void;      // aggregate step (T16A-03..05) → BACKGROUND actors (16B) → rumor resolution and next-day rumors (T16A-10) → politics (16C)
export function enqueue(ctx, item: { dueTick: Tick; key: Id; kind: string }): void;
```

## Implementation steps
1. Every queue is a SortedMap keyed `(dueTick, id)`; no Map iteration order is relied on.
2. Budget: at most `actor_full_evals_per_tick` full evaluations per tick world-wide; overflow defers to the next tick in `(dueTick, actorId)` order; a deferred reactive decision is never dropped (§3.1.2). Wall-clock budget `phase_budget_ms_P3` is 19's key; 16 only measures and reports it.
3. Edge §8.1: over-budget ticks defer reactive epochs; news is never deferred beyond 30 ticks; a due consequence is never skipped (fires late and records the actual tick).
4. 16 writes only its own tables and queues postings for P13 (§3.1.3); a lint rule forbids importing another module's table writers.

## Test plan
  - **16#1** replay from seed and input log reproduces every rumor, news item, consequence and shock view bit-identically (16A scope; votes and history added by 16B/16C).
  - **16#2** P3 within 200 ms on the reference core with 15 cities and 10,000 synthetic intents per tick; under overload every deferred item fires within 3 ticks (600 actors added when 16B exists; INERT until then with a fixture load).
  - **AC-16A-02-ORDER** two items with equal dueTick fire in id order regardless of insertion order.
  - **AC-16A-02-WRITE** a 16A module that writes a non-16 table fails the lint rule.
