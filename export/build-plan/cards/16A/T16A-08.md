## Goal
Every headline is a view of a committed engine event, published one tick later, explained by its recorded causal links, and never able to move prices by tone.

## Imports
- T16A-06 `chainTo` for 'because' clauses; T16A-07 shock events.
- 22 mapping table (event kind → NewsKind), base_kind table, ~400 templates, 15 outlets (port `content22`; fixture set until 22A).
- Owners' `impactHint` and `magnitude` (05, 09; ports).

## Exports
```ts
export function candidatesFor(read, events: EngineEvent[]): Candidate[];   // events of tick−1 only
export function newsworthiness(c: Candidate, read): number;                  // §3.6.2, coefficients 'Quant'
```

## Implementation steps
1. N1: `causeEventIds` non-empty and committed at or before `publishTick`. N2: every slot fact equals engine state at `publishTick` (rumors excepted, always labelled). Both checked at publish and in CI; registered as INV-WLD-001 / INV-WLD-002 (E-27).
2. `publishTick = eventTick + 1`; Terminal `tierEarlyTick = publishTick − 1` (T16A-09). Quota `40/720` per tick; items missing it within 30 ticks are dropped and logged, never published late out of order.
3. Candidate threshold `news_publish_threshold` = 0.05 (E-28 §4; was 0.15). Novelty uses fractional GD (ticks/720).
4. Floors: ≥ 4 per bloc, ≥ 1 per active city when candidates exist; always-publish kinds exactly as §3.6.2.
4. Outlet: highest `audience × outletFit` publishes the canonical item, ≤ 2 variants. Tone rules need actor trust and feuds (16B): until then tone is NEUTRAL (INERT). `credibility` never depends on tone.
5. 16 never sets prices; `impactHint` only from owners, display only (§3.6.5). Statements (§3.6.10): magnitude 0.2 / 0.5, no impactHint, no price effect.
6. Edge §8.2: no template → generic; none → no item and a content alert to 21.
7. Paraphrase layer (§3.6.11) is presentation-only; its output is checked against slots and engine logic never reads it.
