## Goal
Compute each bloc's firm sector at day close exactly as §3.2.2, with every coefficient read from params and marked Quant.

## Imports
- T04-04 nominal GDP `Y_b`, growth, unemployment, neutral rate; T04-05 inflation and credit conditions; T04-10 fiscal transfers.
- 22 tables: `b2bShare_k`, `domainShare_b,d` (port `content22`; fixture until 22A is carded).

## Exports
```ts
export function firmStep(read: Macro04Read, p: FirmParams, prev: FirmSector): FirmSector;   // pure
export interface FirmParams { laborShare: 'Quant'; intermediateShare: 'Quant'; investBase: 'Quant'; investClamp: [number, number] /*Quant*/; investToConstruction: 'Quant'; rndShare: 'Quant'; dividendPayout: 'Quant'; automationFloor: 'Quant' }
```

## Implementation steps
1. Formulas are copied from §3.2.2 without retuning: `Q_b = Y_b/364`; `W_b = labor_share·Q_b·automationFactor_b` (floor 0.85, AUTOMATION level from 16C, default 0 until it exists); `intermediate_b = 0.30·Q_b`; `I_b = Q_b·0.18·(1 + 0.5·(S−50)/50)·(1 − 5·(i − i_n))` (rate term 5, E-28) clamped to [0.08, 0.28]·Q_b; B2B by 22's shares plus `0.6·I_b` to CONSTRUCTION; R&D `rnd_share·domainShare`; dividends `0.5·max(0, Π_b)`. Every numeric coefficient is a param tagged `Quant` (open question Q1).
2. Money: integer micro with T02-04 `roundHalfEven`; category splits use `allocate` so Σ categories equals the total exactly.
3. Feedback into 04 is final demand only (C + I); intermediate is inside Q and never reported as demand (E-28 §1).
4. Pure function; 16A does not set any price or rate (no price math here).
