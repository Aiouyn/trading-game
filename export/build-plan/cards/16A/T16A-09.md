## Goal
Sell faster and deeper views of public information without ever selling the future or anyone's private state.

## Imports
- T16A-08 published items; 05 `explainMove(assetId, window)` (port, summary or full depth).
- T14A-05 rank (Research Desk R3+), 14 heir trait QUANT_RAISED (port), NW_real for fee scaling (03 read).
- Catalog: `INFO_ANALYST_FEE`, `INFO_RESEARCH_DESK_FEE`, `INFO_RESEARCH_QUERY` (SINK BURN, 5080; E-28/E-29); `INFO_TERMINAL_FEE` is an alias of 03 `ACCT_TERMINAL_SUBSCRIPTION` (E-29). Class confirmed; values PROVISIONAL per E-28.

```ts
export function terminalFeeReal(nwReal: bigint): bigint;   // max($20, 2e-6 × NW_real) — Quant
```

## Implementation steps
1. Fees in real dollars, charged at day close as `realToNominal(real, msiPpm)` at that tick (edge §8.16); the first day is pro rata. Terminal + Research Desk combined ≤ `info_fee_cap_pct_nw_per_game_day` of NW.
2. Postings: Terminal under `ACCT_TERMINAL_SUBSCRIPTION` (alias `INFO_TERMINAL_FEE`), others under `INFO_ANALYST_FEE` / `INFO_RESEARCH_DESK_FEE` / `INFO_RESEARCH_QUERY`; SINK BURN, account 5080 (E-28/E-29). Prices are billed **per game day while active**, real $ × MSI; queries $25,000 real each (E-28 §6, values PROVISIONAL). Analysts are outside the 0.05%/GD cap.
3. Head start is headline only, `publishTick − 1`, and never earlier than the event's commit tick.
4. 'Why it moved' groups flows by pool type only, never names a player (L11).
5. Research Desk queries and published notes need PUBLIC_MOSAIC facts (16C): queries answer from public registers only until 16C exists; a note citing a NON_PUBLIC fact is refused.
6. Analyst forecast error σ = 0.6 / 0.4 / 0.25 × the release's historical σ for T1 / T2 / T3. T1 does forecast, at σ 0.6: the lowest tier is the noisiest (Producer, E-29).

## Test plan
  - **16#31** a Terminal subscriber sees the headline exactly one tick before non-subscribers and never before the commit tick.
  - **16#32** 'Why it moved' never names a player; flows are grouped by pool type.
  - **AC-16A-09-CAP** at NW where Terminal + Desk would exceed 0.05% of NW per game day, the charge equals the cap.
  - **AC-16A-09-MSI** an MSI change between subscribe and day close charges the nominal at the day-close MSI.
  - **AC-16A-09-R3** Research Desk subscribe below R3 is rejected.
  - **Exploit notes** §9 X2 (Terminal-only bot ≤ 0 excess return at R3+, harness in 20).

  - **AC-16A-09-GD** an analyst hired for 3.5 GD is billed for 4 GD-days (pro rata first day) and none after `.fire`; two queries cost $50,000 real × MSI.
  - **AC-16A-09-T1** T1 notes carry a forecast whose error over 1,000 samples has σ 0.6 ± 0.03 of the release σ.
