## Goal
Give players uncertain, fair signals that are never insider information unless they come from a crime, and never a free money machine.

## Imports
- T16A-08 publishing; 05 `rumorImpulse` hook (port); 12 tip channels (port `ops12`); 13 lead intake (port); 14B Rep and circle membership.
- Rumor source actors are 16B; until then 20 sources are authored rows with `actorId: null`.

## Implementation steps
1. Subjects only from open real candidates (§3.6.7.1), never a player's private plans; a public player event only after it is public.
2. `isTrue = u < hiddenAccuracy`; horizon U(1, 5) game days, never past the real due time; false → FIZZLED 70% / DENIED 30%.
3. Edge §8.3: cancelled subject resolves FIZZLED if it claimed the event, CONFIRMED if it claimed 'no'.
4. 05 receives `rumorImpulse = 0.5 × (2·cred − 1) × expectedMove` (E-28 §7), zero at cred 0.5, negative for a source below 0.5; `cred = (hits + 5)/(n + 10)`; half-life 1 game day; NPC beliefs only. Values PROVISIONAL.
5. Tips: planted ones come from an NPC FUND_PRINCIPAL with integrity < 0.25 holding the opposite side (16B; INERT: stale only). REPORT within 3 game days: immunity for that tip, Rep +2 (14B), 13 lead. Every tip is tagged INSIDER. Edge §8.20 is 16B.
6. Whispers: 2 per game day, accuracy U(0.45, 0.75), PUBLIC-pending subjects only.
