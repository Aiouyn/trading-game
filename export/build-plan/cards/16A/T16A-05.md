## Goal
Hand the aggregate results to their owners through their hooks, keep the NPC economy's money closed, and emit the low-key activity that keeps the world moving between crises.

## Imports
- T16A-03, T16A-04.
- Owner hooks (ports): 09 `demandPool`, `b2bPool`; 10 `housingDemand`; 07 `depositFlow`, `creditDemand`; 04 realised demand.
- T03-02/T03-05 catalog and aliases.

## Exports
```ts
export function publishAggregates(ctx, firm: FirmSector[], hh: HouseholdSector[]): void;   // calls owner hooks, emits world.aggregate.day
export function closureCheck(read): { ok: boolean; cutTo?: Record<Id, bigint> };              // consumption cut to cash + credit
export function ordinaryActivity(ctx, blocId: Id, g: number): void;                            // λ = clamp(2 + 100·(g+0.02), 1, 9); count clamp [0,12] (E-28)
```

## Implementation steps
1. Outputs per §3.2.4; the housing index formula and its 30-day EMA are copied as written; the ×30 (day→30-GD rate) is intended (E-28 §2).
2. Money closure (§3.2.5): player-boundary spending is posted by 09 (`BIZ_SALES_HH` / `BIZ_SALES_FRM`, FAUCET). Flows wholly inside the ELASTIC perimeter (wages, NPC consumption, dividends, `ROW_NPC_INCOME`) are sector state in 16A and are **not** posted until Producer rules on CATALOG_GAPS_16A (conservative: nothing posts that 03 has no row for).
3. If a day's spending would take an hh or frm balance negative, consumption is cut to available cash plus credit drawn from 07 (port; without 07 the cut is to cash).
4. Ordinary activity: λ = clamp(2 + 100·(g + 0.02), 1, 9) (E-28 §3), count clamped to [0, 12]; draws use `rng('world.shock', day)`; each event goes to a named actor of the bloc when 16B exists (INERT: emitted as `world.activity` with `actorId: null`).

## Test plan

  - **AC-16A-05-1** activity count per bloc per day is within [0, 12] and matches the Poisson draw for a fixed seed; λ = 1 at g = −0.06 and −0.04, λ = 9 at g = +0.06 (E-28 §3).
  - **AC-16A-05-INERT** each null owner port drops its output with a logged `world.aggregate.day` note and no state change.
