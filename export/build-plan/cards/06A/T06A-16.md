## Goal
Implement 05's `InstrumentPort` (GLOBAL-CONTEXT G6.1) over 06's tables so 05 gets, every tick, the list of listed instruments with their market specs, the anchors, the price parameters, value shocks (earnings, defaults, rating and supply events), corporate actions, sizes for ADV, ETF iNAV and baskets, bond durations, and the extra P1 gates 05's order path must apply (short license, hub capacity, insider blackout, controls). The port is composable so 06B (derivatives: dealer gamma, package quotes, fair basis, underlyings) and 06C (crypto: hype, other-venue prices) add their members without editing this file. Also NPC index-fund rebalance flows (06 §6 item 8).

## Implementation steps
1. `listedSpecs`: iterate `ast.asset` (sorted) with status LISTED/HALTED/DISTRESSED and class tradeable on 05's books (EQUITY, ETF, GOVT_BOND, CORP_BOND, FX_SPOT, COMMODITY, and the 06B/06C classes when their extension says so); DISTRESSED/DEFAULTED rows are excluded (they trade on 06's DISTRESSED venue); return `toMarketSpecPartial`.
2. `anchor(store, assetId, tick)` → `readAnchor` (`{lnF, changedBy}`); missing anchor → `ln(lastPrice)` from 05 state (never invented). FX legs: return 04's `fairValueLn` passthrough is not needed (05 reads 04 directly for legs per 05 §3.3.6); for legs return the current 05 `lnF` unchanged.
3. `priceParams` → `toMktPriceParams(asset.priceParams)` (corporate bond jumpsPerYear scaled by `PD_P/0.02` clamp [0.5, 5] as the "PD-scaled" rule of 06 §3.21; FDLSRL uses the dynamic SRL intensity). `hype` → 0 unless the 06C extension provides it. `dealerNetGamma`, `packageQuote`, `fairBasisLn`, `hasListedOptions`, `underlyingOf`, `otherVenueLnP` → null/0/false unless extended.
4. `valueShocks(store, tick)` = earnings shocks (T06A-04) ∪ default shocks (a bond default is a FUNDAMENTAL shock on the bond `logMove = ln(recovery·100/clean)` and on the issuer's equity `ln(0.3)` only if 09 provides no recovery; otherwise the equity follows its anchor) ∪ rating cliffs from 08 (via `FundsPort06`, event fixtures) ∪ the 06C extension (depegs) ∪ commodity supply shocks (16 events already move the 06 target; no duplicate shock). Each shock appears exactly once, at its `publishTick`.
5. `corporateActions(store, tick)` = `exDateActions` ∪ `splitActionsForMarket` ∪ `corporateActionsForMarket`, sorted by assetId then kind.
6. `sizeOf`: equities free-float shares; bonds amountOutstanding/1,000; FX authored notional (22); commodities open interest proxy = 30 × base daily demand; ETFs unitsOutstanding.
7. `etfINavLn`, `etfBasket` from T06A-07; `durationOf` from `bondAnalytics(...).modDur`.
8. `preTradeGate`: act = BUY / SELL_LONG / SHORT from side and `opensShort`; `tradeGate`; for player-company equities `inBlackout` → `AST_BLACKOUT`; physical commodity buys `physicalCapacityCheck`; currency conversion is 05's own controls check. This member is not in 05's `InstrumentPort` today: reported to the reconciler (05 must call it in its P1 order validation).
9. Index funds (06 §6 item 8): `indexRebalanceFlows` returns MANDATE-pool `ExternalOrder`s for the rebalance closing auction (t = 540, `auctionOnly: true`) of each index with 16's index-fund AUM (`WorldPort06` extension `indexFundAum(indexId)`, default 0 → no orders) and, after a rating cliff (08 IG→HY), sell orders spread evenly over the next 5 game days. 08's `FundsPort.etfFlows` implementation is expected to concatenate these (reported).
