## Goal
Make every commodity price caused by physical state (06 §3.10.2): hourly supply, demand, inventory and days-cover per commodity drive the spot target that 05 pulls toward, and the convenience yield shapes the futures curve (backwardation when scarce, contango when glutted, seasonality for agri). Game-native markets: compute spot from utilization, data with grades, and power cleared by merit order per bloc (06 §3.10.6, D104). Publishes `mkt.commodity.state` hourly.

## Implementation steps
1. Definitions (§3.10.1): read every column from `PARAM.cmd_<id>_{unit,ref_price,normal_cover,elasticity,gamma,storage,perish,sigma}` with the 06 table as default; harvest months WHEAT 7, CORN 9, COFFEE 5, COCOA 10; seasonal amplitude 0.06 (log) for AGRI, 0 otherwise. `CommodityState` at genesis: inventory = normalCover × base daily demand (22 §4.6 base demand), so daysCover = normalCover.
2. `hourlyStep` (§3.10.2), per commodity at `t mod 30 == 0` in P2, all values per game hour: `demand = baseDemand·gdp·seasonality(month)·(P/P_ref)^(−elasticity) + extraDemand` (09 business demand via `ports.companies.businessDemand`); `supply = capacity·utilization(P) + shock` (16 `supplyShock`, 09 `producerSupply` added to capacity); `inventory += (supply − demand)·1` (one game hour), floored at 0; `daysCover = inventory / max(demand·24, 1e-9)`; `cost = marginalCost`; `V = spotTarget(cost, daysCover, normalCover, γ)`; write anchor for the benchmark line (05 pulls with the 20-game-day OU half-life of §3.21) and for hub lines `V + basis` (T06A-13 computes basis). Prices floor at one tick (edge 1: never negative; storage-full hubs reject purchases instead, T06A-13). Draw order: none (shocks come from 16; stream `ast.commodity:<id>` is used only by T06A-13 for shipment loss).
3. Curve (§3.10.3): `y_conv = storage + cmd_conv_eta·ln(normalCover/daysCover)`; `ln F(T) = ln S + (z_ois_FDL(T) + storage − y_conv)·T + seasonalAmp·cos(2π(m_T − h)/12) − seasonalAmp·cos(2π(m_now − h)/12)`; months are game months 1–12. Exported for 06B futures (V of each series, κ half-life 5 game days, and the NPC cash-and-carry bound).
4. Native (§3.10.6): compute spot from `ai.computeUtilization` (one spot unit = delivery during the next game hour; not storable; engine unit PFLOP-day = 10 GPUh, so the stored price per PFLOP-day = 10 × $/GPUh); data: standard-grade instrument anchored at `data_ref_price` ($2/DQU, D111) × `(1 − dataSupplyShock)` clamped ≥ 0.1×ref, grade multipliers applied at the trade/delivery layer (11 owns freshness); power per bloc each game hour: sort the merit stack (09 generators + NPC stack from 22) by cost ascending, ties by id, take the cost of the last unit needed to cover demand (04 aggregate + data centres + 09 businesses), add the scarcity adder `200·max(0, 0.10 − reserveMargin)/0.10` $/MWh; if the stack cannot cover demand, price = last cost + 200 (full scarcity). Write anchors for COMPUTE, DATA, POWER_<bloc>.
5. `mkt.commodity.state` PUBLIC hourly payload: `{commodityId, inventoryBand: 'LOW'|'NORMAL'|'HIGH' (daysCover <0.7 / >1.3 × normal), daysCover, curveShape, basis by hub}`.
