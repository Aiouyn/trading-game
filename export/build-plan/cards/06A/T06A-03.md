## Goal
Compute every listed equity's fundamental value `V` (06 §3.4.2) from 09's company financials and 04's curves and Fear Index, using the 12 sector parameter rows (06 §3.4.1), and publish it as the `lnF` anchor 05's value layer pulls toward. Player-listed companies use 09's sum-of-the-parts value (R10). Also provides the generic anchor-writing helper every other 06 class uses.

## Implementation steps
1. Inputs: `EPS_fwd` = `EquityState.epsFwd` (initialised from 09's `expectedEps4Q`; T06A-04 revises it); `R`, `N`, `B`, `g_f`, `q`, `mg`, `mo` from `CompanyPort06.financials`; `F` = 04 Fear Index committed at the previous game hour (D097: fear is 04's F); `y10_bloc = nsZero(govt, 10)`, `r_neutral_bloc = neutralRate`. Sector constants from `sectorParams` (06 §3.4.1). `rr` from `EquityState.rr` decayed to now with half-life 91 game days: `rr_now = rr · 2^(−Δdays/91)` (Δdays = (tick − rrTick)/720).
2. `equityValue` implements the formula block of §3.4.2 in this order: RA, PE_s, gp, qm, branch on `EPS_fwd > 0` (P/E branch) else the P/S branch × `eq_loss_maker_ps_haircut`; then `V = max(V, 0.3·B/N)` only if `B > 0`; then `V = max(V, tickSize)`. All math with `dmath.exp`.
3. Player-listed companies (`isPlayerCompany`): `V = fundamentalValue(cmpId) / N · sent` (09's SOTP value is for the whole company; divide by shares), then the same two floors (R10). If 09's port returns null, keep the last anchor.
4. Sentiment `sent`: 06 says it comes from 05 in [0.75, 1.25], but 05's spec and its read API expose no such output and 05's value layer already adds news and belief to `lnV`; multiplying the anchor would double-count. Use `SENTIMENT_MULT = 1.0` (clamped range kept in the function signature so a later 05 export can be wired without changing the formula). This is reported to the reconciler.
5. Cadence: `equityAnchorStep` runs in P2 each tick for equities whose hourly slot matches (`isAnchorDue`) plus dirty ones (`markEquityDirty` stores the id in a per-tick set table row `ast.counters` key `dirty:<tick>`); writes `ast.anchor` with `changedBy` = the shock id when a discrete change (earnings) caused it, so 05 does not double count (05 §3.3.6).
6. `peGuardActive`: expose for 05's InstrumentPort extension (assembly task).
7. Missing financials (09 absent): keep the genesis anchor (no invented fundamentals).
