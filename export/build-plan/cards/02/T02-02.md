## Goal
Implement the exponential and logarithm family of the deterministic math library `dmath` (02 §3.8) using only `+ - * /`, `Math.sqrt`, the allowed IEEE-exact `Math.*` functions and explicit bit manipulation, so results are bit-identical on every CPU and Node version. Also build the reference generator that produces the 10,000-vector test files (20 owns their use in gates) from an arbitrary-precision bigint implementation, so ULP bounds are measured against a correct value, never against `Math.exp`.

## Implementation steps
**Contract (E-53).** The ULP bounds of 02 §3.8, the fault codes, the domains and bit-identical determinism (golden hash) are the contract. The algorithms below are guidance: a deviation is allowed only if it uses the 02 §3.8 primitives, is fixed (no data-dependent iteration counts) and passes every AC below. The E-53 deviations (ratified from PR #25) are part of this card.
1. `bits.ts`: one module-level `Float64Array(1)` + `BigUint64Array` view over the same buffer is allowed (not shared across threads). Ordered bits: for negative numbers map to `-(bits & 0x7fff...)` so ulpDistance is monotone.
2. `exp(x)` (02 §3.8 table): NaN -> EngineFault('I0.nan'); x > 709.782712893384 -> EngineFault('I0.overflow') (domain is [-745, 709]); x < -745.1332191019411 -> 0. Reduce `k = roundHalfEvenLocal(x / LN2)` (implement locally: floor(x/LN2 + 0.5) with tie fix; do not import fixed.ts which is later), `r = (x - k*LN2_HI) - k*LN2_LO` with Cody-Waite constants LN2_HI = 0.6931471803691238 (0x3FE62E42FEE00000), LN2_LO = 1.9082149292705877e-10 (0x3DEA39EF35793C76). Degree-13 Taylor in Horner form on r (coefficients 1/n! as exact double literals listed in the file for n = 0..13); the final `1 + r·P(r)` is added with an exact Fast2Sum (compensated, E-53) so exp(1) is exactly 2.718281828459045. Scale by 2^k with `scalb` (exponent bit construction, two-step for k < -1022).
3. `expm1`: |x| < 1e-5 -> x + x²/2 + x³/6 (Horner); |x| < 0.5 -> Taylor to degree 17; else exp(x) - 1.
4. `ln(x)`: NaN -> EngineFault('I0.nan'); x ≤ 0 -> EngineFault('I0.domain'); x = +∞ -> EngineFault('I0.overflow') (E-53); subnormal handled by scaling by 2^54; split via bits into m·2^e with m in [√½, √2) (if m ≥ √2 halve and e+1); s = (m-1)/(m+1); odd series 2(s + s³/3 + ... + s²¹/21) Horner in s²; result = e·LN2_HI + (series + e·LN2_LO). Also export internally `lnDD(x): {hi, lo}`: the same reduction and series carried in double-double (the 1/3 term uses the pair 0.3333333333333333 + its low part, E-53), used by log2, log10 and pow.
5. `log1p`: |x| < 1e-4 -> Horner x - x²/2 + x³/3 - x⁴/4; else u = 1 + x, ln(u) - ((u - 1) - x)/u correction.
6. `log2 = lnDD(x) * (1/LN2)`, `log10 = lnDD(x) * (1/LN10)`, each constant as a hi/lo double pair (E-53): hi = LOG2E 1.4426950408889634 and 1/LN10 = 0.4342944819032518 (the nearest double; not `1/Math.LN10` = 0.43429448190325176), lo = the exact remainder 1/ln2 − hi, 1/ln10 − hi, derived in ≥ 80-digit decimal arithmetic and written as double literals.
7. `pow(x, y)`: y = 0 -> 1; x = 1 -> 1; x = 0 -> (y > 0 ? 0 : EngineFault('I0.domain')); compute `l = ln(x)` in extra precision as `lnDD(x) = lh + ll` (E-53; replaces the Newton tail `x·exp(-lh) - 1`, which inherits exp's rounding and reached 131 ULP), then Dekker two-product of y·lh (Veltkamp split with 134217729) plus y·ll; exp of the sum with the low part applied as `exp(hi) * (1 + lo)`. Integer y with |y| ≤ 64 uses exponentiation by squaring carried in double-double (E-53; negative n takes the reciprocal at the end): exact whenever x^n is representable, within the pow bound otherwise; document this branch.
8. `tanh(x)`: |x| > 22 -> sign(x); |x| < 0.55 -> expm1-based `e = expm1(2x); e/(e+2)`; else `1 - 2/(exp(2x)+1)`. `sigmoid(x)`: x ≥ 0 -> 1/(1+exp(-x)); x < 0 -> e/(1+e) with e = exp(x) (symmetric form).
9. `kahanSum`: Neumaier variant, iterating in the order given (callers pass sorted collections). `clamp(x,a,b)` = min(max(x,a),b); NaN -> EngineFault('I0.nan'). `lerp` = a + (b-a)·t.
10. Reference (`tools/dmath-ref`, Node script, not engine code, may use anything): BigFloat with 256-bit mantissa; exp via argument reduction by ln2 (computed by the AGM-free series ln2 = Σ 1/(k·2^k)) and Taylor until terms < 2^-300; ln via Newton on refExp; pow via refExp(y·refLn(x)). `roundToF64` rounds half-even. `generateVectors(fn, 10000, seed)`: inputs from a fixed xorshift sequence covering the domain (log-uniform magnitudes, both signs, plus edge points 0, ±tiny, ±1, near overflow); write `vectors/<fn>.vec` as canonical bytes `{fn, inputs: [[f64...]], expected: [f64]}` with float64 bit patterns. Commit vector files for exp, expm1, ln, log1p, log2, log10, pow, tanh, sigmoid.
11. Golden cross-platform file: `packages/engine/core/dmath/vectors/golden.sha256` = SHA-256 over the concatenated bit patterns of dmath outputs for all committed vectors. The test recomputes it; any platform difference fails (20B runs this on arm64).

## Test plan
`exp.test.ts`:
- For each committed vector file: max ULP error ≤ bound of 02 §3.8 (exp 2, ln 2, log2/log10 3, pow 4, tanh/sigmoid 3, expm1/log1p 2); report max.
- Worked examples (exact expected doubles asserted with `Object.is`): exp(0) = 1, exp(1) = 2.718281828459045, ln(1) = 0, ln(Math.E-like literal 2.718281828459045) within 1 ULP of 1, exp(-746) = 0, pow(2, 10) = 1024, pow(10, -2) = 0.01 within 1 ULP, sigmoid(0) = 0.5, tanh(0) = 0.
- exp(NaN), ln(-1), pow(-2, 0.5), exp(710), ln(+Infinity) each throw EngineFault with the listed code (ln(+∞) -> 'I0.overflow', E-53).
- kahanSum([1e16, 1, -1e16]) = 1 (naive sum gives 0).
- golden.sha256 equality.
- E-53 deviation ACs: pow(x, n) for integer |n| ≤ 64 is bit-exact whenever the reference x^n is representable (e.g. pow(3, 33), pow(2, -64), pow(1.5, 57)) and within 4 ULP otherwise; log10(x) and log2(x) within 3 ULP on their vectors using the hi/lo constants, with the literal 1/LN10 asserted `Object.is(..., 0.4342944819032518)`; exp(1) exact via the compensated 1 + r. All deviation paths are covered by the vector files and the golden hash (determinism).
- property (fcParams): ln(exp(x)) within 4 ULP of x for 1 ≤ |x| ≤ 700 (E-53: for |x| < 1 the bound cannot hold, since exp(x) rounds at ≈1e-16 absolute, far above ulp(x)); sigmoid(x) + sigmoid(-x) within 2 ULP of 1.
