## Implementation steps
1. `sin/cos`: Cody-Waite reduction by π/2 with a 3-part constant (PIO2_1 = 1.5707963267341256, PIO2_2 = 6.077100506506192e-11, PIO2_3 = 2.0222662487959506e-21; tails as in fdlibm), n = round(x·2/π), r in [-π/4, π/4]; minimax kernels __sin (degree 13 odd, fdlibm S1..S6) and __cos (degree 14 even, fdlibm C1..C6) with the coefficient literals copied from fdlibm `k_sin.c`/`k_cos.c`; select by n mod 4.
2. `atan`: reduce |x| > 1 via atan(x) = π/2 − atan(1/x); then to [0, tan(π/12)] via atan(x) = π/6 + atan((x√3 − 1)/(x + √3)); odd series to degree 23 on the reduced argument. `atan2` handles the quadrant table and signed zeros explicitly (atan2(±0, -0) = ±π, etc., per IEEE conventions).
3. `erf/erfc`: W. J. Cody's rational approximations (1969) in three ranges |x| ≤ 0.5, 0.5 < |x| ≤ 4, |x| > 4, with coefficients from Cody's CALERF tables (copy literals); exp(-x²) computed as exp(-xsq·xsq)·exp(-(x-xsq)(x+xsq)) with xsq = trunc(x·16)/16 for accuracy.
4. `normInv`: Wichura AS241 PPND16 (three regions: |q| ≤ 0.425, r ≤ 5, r > 5) with its published coefficients; r uses `sqrt(-ln(min(p,1-p)))`.
5. `lgamma`: Lanczos g = 7, n = 9 coefficients (0.99999999999980993, 676.5203681218851, -1259.1392167224028, 771.32342877765313, -176.61502916214059, 12.507343278686905, -0.13857109526572012, 9.9843695780195716e-6, 1.5056327351493116e-7); x < 0.5 not allowed (domain x > 0, use reflection only for 0 < x < 0.5 via lgamma(x) = ln(π/|sin(πx)|) − lgamma(1−x)).
6. `bsPrice`: d1 = (ln(S/K) + (r − q + σ²/2)T)/(σ√T), d2 = d1 − σ√T; call = S e^{-qT} N(d1) − K e^{-rT} N(d2); put by the symmetric formula. Edge: T ≤ 0 or σ ≤ 0 -> intrinsic value max(0, ±(S e^{-qT} − K e^{-rT})). Greeks by the standard closed forms (delta call e^{-qT}N(d1), gamma e^{-qT}φ(d1)/(Sσ√T), vega S e^{-qT}φ(d1)√T, theta and rho closed forms).
7. Solvers: fixed loops exactly `iters` times, no early exit (determinism of draw-free control flow). Bisection keeps the sign-change half; returns the midpoint of the final bracket.
8. Cholesky: classical row-by-row loops in fixed i, j, k order; diagonal ≤ 0 -> EngineFault('I0.not_pd').
9. References: BigFloat implementations (Taylor series for sin/cos/atan after exact reduction using a 300-bit π computed by Machin's formula; erf by its Maclaurin series for |x| < 3 and the asymptotic continued fraction for erfc beyond, evaluated at 256 bits; normInv by Newton on the reference normCdf; lgamma by Stirling with enough Bernoulli terms). Generate and commit vectors for sin, cos, atan, atan2, erf, erfc, normCdf, normInv, lgamma; extend golden.sha256 to cover them.
