## Implementation steps
1. `CORE_MODULE`: genesis creates the `core.world` row {tick: 0, status: 'RUNNING', epoch: 0, anchor: WorldClockAnchor with genesisUtcMs from GenesisConfig, frozen: []}; P14 `writeWorldRow` writes tick, status, epoch, lastWorldHash of N−1 (the only per-tick core write besides nonces and inbox). The module is always first in every ModuleSet (T02-11 step 3) and every unit's `dependsOn` implicitly contains it. All 10 INV-ENG impls are registered; the runner (T20A-01 `runInvariants`) runs only the scope it is asked for, so OFFLINE INV-ENG-008/009 are run by the harness and shadow verifier.
2. `coreParams` reads every key with the 23 accessor (`num`, `int`) once per tick (callers keep the object for the tick); `CORE_PARAM_KEYS` lists them. No defaults are hard-coded here: values come from `@tycoon/params`.
3. `createTestWorld` (G6):
   - modules = buildModuleSet([CORE_MODULE, ...opts.modules]); errors propagate as ModuleSetError.
   - registry = new InvariantRegistry(); register `impl` of every module's `invariants` with its module id (RegistryError aborts creation; this is how a unit's tests catch catalogue mistakes early).
   - params = withOverrides(defaultParams(), opts.params ?? {}); content = loadContent(opts.content ?? 'minimal').
   - seed: localSeed = SHA-256('TYC/test' ‖ (opts.seed ?? 'tycoon-test')); entropy e(N) = SHA-256(localSeed ‖ N) (02 §3.21 (b)-(d)); epoch roots `harnessEpochRoots(localSeed)`.
   - partitions: 1 (default) -> singlePartitionMap; 4, 6, 16 -> standardMap; any other count throws EngineFault('TEST_PARTITIONS').
   - ledger: the provider of the module with `services.ledger` (unit 03) when loaded; otherwise none, and `ctx.ledger` / `ctx.holds` throw `EngineFault('I0.no_ledger')` exactly as G6 states; `balance()` and `postings()` then throw the same fault.
   - genesisUtcMs = 1_767_290_400_000n (fixed test instant, 18:00 UTC); sealUtcMs(N) = scheduledUtcMs(anchor, N); no wall clock is read.
   - startTick: when given, the world is created at genesis and fast-forwarded with empty ticks to `startTick` (all hooks fire, so period state is consistent).
4. TestWorld members:
   - `submit(actorId, kind, payload, opts)`: builds a RawIntent (intentId = deterministic `int_` id from a per-world counter via T02-07 base32, nonce = last + 1 per actor, channel 'UI' unless given, createdTick = current tick, testMode envelope without signature) and queues it for the next `step`; returns intentId.
   - `step()`: seals the queue as tick `tick` through `stepWorld` (T02-17); collects committed events, postings (through `testHooks`), intent results and invariant results; returns TickOutcome with `stateHash = logicalStateHash` (independent of partition count, 02 §3.6.3) and `failedInvariants` from the record (or from the ladder outcome when not committed).
   - `runTicks(n)`, `runUntil(pred, maxTicks)` (throws EngineFault('TEST_RUN_UNTIL') after maxTicks), `runToTickOfDay(t)` (steps until the next tick to run has tickOfDay t; no step when already there), `runGameDays(d)` = d × 720 steps.
   - `events(filter)` committed events in (tick, seq) order; `intentResult(id)`; `postings(filter)` and `balance(entityId, code, ccy, sub)` through `provider.testHooks` over a merged StoreRead of all partitions.
   - `view(viewId, args, viewer)`: finds the ViewHandler across modules (unknown id throws), parses args with its zod schema, runs it on the merged StoreRead with ViewerContext {viewerId: viewer ?? null, isAdmin: false, partyOf}.
   - `setParam(key, value)`: test override applied from the next tick (not a PARAM_CUTOVER; header.paramsVersion unchanged).
   - `stateHash()`; `snapshot()` = canonEncode of every partition's `encodeSnapshot` sorted by partitionId.
   - `spawnCharacter(opts)`: delegates to the loaded module that provides `services.spawnCharacter` (unit 14A; superset field on ModuleServices) inside `asSystem`; when 14A is not loaded it throws EngineFault('TEST_NO_14A').
   - `asSystem(fn)`: runs fn between ticks with a PhaseCtx bound to phase 'P2', module 'sys', `store` = the merged testMode store whose writes route to the owning partition (`asSystem()` of T02-09) and skip ownership checks; never available from the production barrel.
5. Package exports: `@tycoon/engine/core` -> index.ts; `@tycoon/engine/core/testing` -> testing.ts; a lint rule (T02-01 config) forbids importing `/testing` or `fixture-ledger` from non-test files outside packages/engine/*/testing*.

## Test plan
testing.test.ts:
- G6 conformance (type-level with `expectTypeOf`): TestWorld has exactly the G6 members; createTestWorld's parameter type equals the G6 one.
- without unit 03: a fake module calling ctx.ledger in P5 makes the tick fail with I0 naming 'I0.no_ledger'; `balance()` throws the same fault.
- with `createEngineTestWorld({ ledger: createFixtureLedger() })` and two fake modules: submit -> step -> intentResult ACCEPTED; balance moves; postings filter by entityId; events filtered by kind and since.
- a fake module with a broken invariant id (not in LAUNCH_CATALOGUE) makes createTestWorld throw RegistryError (registry wiring).
- setParam changes a fake module's read value from the next tick; view() rejects bad args through the schema; spawnCharacter without 14A throws TEST_NO_14A; asSystem writes are visible in the next tick and change stateHash.
- same seed and inputs at partitions 1 and 4 give identical stateHash sequences over 2,000 ticks.
empty-world.test.ts:
- an empty world (only CORE_MODULE) runs 30 game days (21,600 ticks): every tick committed, no failed invariant, every boundary hook of the period fired (INV-ENG-007), two runs give identical stateHash and identical event digests, and the run with partitions 16 gives the same logical hashes.
