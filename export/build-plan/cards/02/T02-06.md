## Goal
Every random draw in the world comes from a named, keyed xoshiro128** stream (02 §3.10) seeded from an epoch root, mixed lazily with the tick's entropy, and consumed through variates with fixed draw counts. This task implements the generator, the `Rng` interface of G6, the full stream registry of 02 §3.10.4 (the CI source of truth for allowed keys), a per-partition stream manager with an RNG ledger (draw counts per stream per tick, hashed into metrics), the INV-ENG-002 check, and the CI scan proving every key used in code is registered.

## Implementation steps
1. `xoNext`/`rotl` exactly as 02 §3.10.1 (with `>>> 0` normalization; `s` is a Uint32Array so assignments wrap).
2. `seedStream`: seedBytes = sha256Concat('TYC/rng', epochRoot, key); s[i] = little-endian uint32 of bytes 4i..4i+3; all-zero -> s[0] = 0x9E3779B9; discard 8 outputs; keyHash = first 16 bytes of sha256(utf8(key)) as 4 LE uint32; draws = 0n; lastMixedTick = -1.
3. `mixEntropy` exactly as 02 §3.10.3 (xor words 0..3 of entropy and keyHash, all-zero fix, discard 4 outputs, set lastMixedTick). Discarded outputs do not count in `draws` (they are not draws by the module) but are deterministic.
4. Variates exactly per 02 §3.10.5 table: u53 = (a·67108864 + b)/2^53 with a = next()>>>5, b = next()>>>6; uOpen = (u53·(2^53 − 1) + 0.5)/2^53; int(n) = floor(u53·n) with n integer 1..2^32 else EngineFault; normal = normInv(uOpen()); studentT(nu) with integer 1 ≤ nu ≤ 8: z = normal(), chi2 = Σ_{k=1..nu} normal()², z/sqrt(chi2/nu) (2(nu+1) draws); exponential = −ln(uOpen())/lambda; poisson(λ ≤ 30): one u = u53(), walk the CDF from k = 0 with p0 = exp(−λ), p_{k+1} = p_k·λ/(k+1), return the first k with cumulative > u, capped at 60 (2 draws always); λ > 30 -> EngineFault('I0.rng_poisson'); kouJump: sign from u53() < pUp (2 draws), size = exponential(sign ? etaUp : etaDown) (2 draws), returns +size or −size; categorical: weights must be sorted by key (cmpStr) else EngineFault, one u53 against cumulative normalized weights; shuffle: Fisher–Yates from the end, j = int(i+1) for i = n−1..1 (2(n−1) draws), in place, returns the array. beta/gamma are forbidden (not exported).
5. Registry: transcribe every row of 02 §3.10.4 (module, key pattern, root P/S, use) plus `sim.bot:<botId>` with root 'HARNESS' (never in the live world). The CI rule "a module that needs a new stream adds a row here" means this file is the registry.
6. `RngManager.stream(module, ownedPrefixes, key)`: `matchStream(key)` must exist (else 'I0.rng_unregistered'); its `streamPrefix` must be in the calling module's `ModuleDef.streams` and its spec.module must equal the caller module number (else 'I0.rng_foreign', 02 §3.10.4 "may not draw from another module's stream"). Create lazily with the current epoch root (SECRET streams use `secretEpochRoot(epoch)`, PUBLIC `publicRoot(epoch)`); mix on first draw of the tick (lazy per §3.10.3, edge case 8: no mixing while unused). Each `next()` increments `draws` and the tick ledger count.
7. Epoch rotation (02 §3.11.4): `beginTick` with a new epoch re-seeds every stream already in state, before any draw of that tick; then mixing applies on first draw as usual.
8. INV-ENG-002 (TICK, FATAL): every key in the ledger is registered; for every stream, `after − before == ledger draws` (counters advanced only by recorded draws). The engine supplies both facts (T02-12 wires them).
9. CI scan: parse `packages/engine/**/*.ts` (not tests) with the TypeScript compiler API; collect string literal or template-literal-head first arguments of `ctx.rng(...)` calls and every `streams: [...]` array in ModuleDefs; template keys like `` `mkt.idio:${id}` `` are checked by their static prefix ('mkt.idio:'). Report unknown keys/prefixes; CLI exits 1 when non-empty. Add script `ci:streams` to the root package.json (edit).

## Test plan

- xoshiro reference: with s = [1,2,3,4] the first outputs are 11520, 0, 5927040, 70819200, 2031721883, 1637235492 (xoshiro128** reference sequence; also cross-check by an independent straight-line implementation in the test).
- `02#18 creating a new RNG stream for a new asset does not change any draw of any existing stream`: manager A with stream 'mkt.idio:ast_A'; manager B with 'mkt.idio:ast_A' and also 'mkt.idio:ast_NEW' drawn interleaved; over 1,000 ticks (fake entropy words from sha256(tick)) the 1,000 draws of ast_A are identical.
- 02 §8 edge 8: a stream unused for 50 ticks then drawn equals a fresh computation of "state after last use + mix of the current tick".
- epoch change re-seeds: draws at the first tick of epoch 2 equal seedStream(epoch 2) + mix, independent of epoch-1 history.
- foreign and unregistered keys throw EngineFault codes; 'sim.bot:x' is rejected for live modules.
- INV-ENG-002 negative test: a fact with counter delta 5 but ledger 4 -> check fails.
variates.test.ts:
- `02#19 studentT(4) consumes exactly 10 uint32 draws per call; poisson(λ) consumes exactly 2 for any λ ≤ 30` (count via a wrapped draw function; λ in {0.001, 1, 7.5, 30}).
- draw counts for every variate equal `DRAWS` (shuffle of 10 = 18).
- property: u53 in [0,1); uOpen in (0,1); int(n) in [0,n).
- worked example: uOpen with draws (0, 0) = 0.5/2^53 = 5.551115123125783e-17; u53 with a-draw 0xFFFFFFFF and b-draw 0xFFFFFFFF = (134217727·67108864 + 67108863)/2^53 = 0.9999999999999999.

- `02#42 every stream key used by any module appears in the 02 §3.10.4 registry (CI scan)`: fixture repo with one registered key and one `ctx.rng('mkt.foo:x')` -> reported unknown; running on the real repo returns no unknown keys.
