## Goal
Properties are 03 entities with their own books; 10A keeps their values marked, taxed and held correctly.

## Imports
- T03-13 marks registry; T03-14 day-close valuation postings; T03-21 property tax. 13A freezes (`heldByCourt`).

## Exports
```ts
export function registerProp(ctx, p: PropertyRow): void;   // 03 registerEntity('prop_…')
export function appraisalDue(read, propId, tick): boolean;  // every 7 GD, staggered hash(propId) mod 7
export function dormancyStep(ctx): void;
```

## Implementation steps
1. Every prop is registered with 03 (entity id `prop_…`) and has exactly one holder.
2. Appraisals every 7 GD, staggered, plus event triggers; they feed the 03 marks.
3. Property tax per city rate (03 owns the computation and posting).
4. Unique and civic assets: islands and crown parcels per §2.10/§3.18.
5. Dormancy (§3.27): after 30 days, manager-run; after 90 days, unique assets go to estate sale (via 14/15 ports).

## Test plan
  - **AC-10A-07-1** a new prop is registered with 03 and its id passes `assertEntityId`.
  - **AC-10A-07-2** appraisal stagger: over 7 GD each prop is appraised exactly once.
  - **AC-10A-07-3** a court-held prop cannot be listed or used as collateral (13A gate).
  - **AC-10A-07-4** after 30 real days dormant, a SELF prop gets an NPC agency at 8%.
