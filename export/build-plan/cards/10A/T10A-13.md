## Goal
STUB, follow-up from the T10A-12 Producer review. T10A-12 derives a `DistrictRole` from tier, terrain role and plan, but 22 §3.3 has no port or station flag for each district. This card adds that content data for every district of the other 14 launch cities and Isla Serena, so the derivation is total. Systems writes the rules column; Designer authors the content (22). No code logic: data plus a schema and consistency test.

## Exports
```jsonc
// district-flags.json
{ "catalogVersion": "district-flags.v1",
  "districts": [ { "distId": "dst_<city>_<slug>", "port": false, "station": false, "cbd": false, "riverOrCanal": false, "role": "<DistrictRole>" } ] }
```

## Implementation steps
1. Designer fills one row per district in 10 §3.2.2 / 22 §3.3, using ids exactly as in 22 (no new names).
2. Systems checks each `role` against the T10A-12 `districtRole` derivation and resolves disagreements in 22, not in code.
3. Port Avalon rows restate T10A-12's role table (AC-10A-12-ROLE-PA) so there is one source.

### Designer notes and open questions
- **Q1 (Systems): "waterfront terrain role" for AC-10A-13-RULES.** Six port districts (Arsenal Yards, Harbor Freight, Delta Wharf, Harbor Works, Rig Yards, Ore Docks) have terrain `industrial_shore`, not `waterfront`. The table treats `waterfront`, `industrial_shore` and `island` as waterfront roles. If the test means `waterfront` only, the test must widen or 22 must change; port hubs must not lose their PORT role.
- **Q2 (Producer/Systems): Sundara port.** 22 says Sundara has a port concession, but its only waterfront working district, Sunset Strip, has a boardwalk landmark. I set `port: true` there (design choice). Alternative: no Sundara port and both working districts INDUSTRIAL.
- **Q3: Isla Serena.** Marinas only, so `port: false` (a port flag would derive PORT ahead of TROPHY_RES and the island would host terminals). No station, no CBD, no river. Exempt from the INDUSTRIAL/PORT rule per the card.
- **Lakemont and Valcourt:** 22 says "lake port only" / "river port", both "no" port concession, so no `port: true`; their working districts are INDUSTRIAL.
- **River flags beyond 22 §3.2:** Mirako Riverside Arcades and Cobreval Riverside Colonia have terrain `riverside` but no R flag in 22 §3.2; Kaiyo Delta Markets and Vintra Old Mill likewise. I set `riverOrCanal: true` from terrain. 22 §3.2 should add R flags for them (22 owner).
- **Station on CBDs:** Loop Central and Station Center carry `station: true` from their landmarks but derive CBD (cbd wins).
- Design choices for variety: TRANSIT_HUB in Lakemont, Redmesa, Meridia, Valcourt, Kaiyo, Nordhaven, Alta Verde; none in Tessan, Mirako (station is in its CBD), Skarvik, Vintra, Sundara, Cobreval.
