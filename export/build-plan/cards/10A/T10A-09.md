## Goal
Deliver the city to clients without ever leaking private state, and in exactly the shape City Dev's renderer consumes.

## Implementation steps
1. The allowlist of §3.24 is enforced in one place (`filterPublic`). Owner names only with `publicOwnership = true`; homes are never shown by default; positions, balances and presence never.
2. At day close: mark dirty parcels and regions and queue the job. A worker builds the delta and immutable chunks addressed by content hash, then atomically advances `stateVersion`. The tick carries only `{ [cityId]: stateVersion }`.
3. Publication may lag by up to 1,440 ticks; nothing runs inside the tick.
4. Seam (PR #4 types above):
   - `chunk-encode.ts` writes `CTY1` v1 byte-exact from fixed-point cm geometry; each part is owned by `chunkKeyOf(centre)`, others reference it. Chunk bytes are content-hashed and immutable at `hashedUrl`.
   - The manifest is written after every hashed file it names exists; the client never builds versioned URLs.
   - Topology is never computed on the client; only stage-10 cosmetics are. Ephemeral render indices stay inside the renderer and are never persisted; chunk ids JSON holds persistent entity ids only.
5. The private overlay is computed client-side from the user's own `me` data; it is never in public artifacts.
