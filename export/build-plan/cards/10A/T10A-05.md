## Goal
The day-close engine that turns macro conditions into rents, vacancies and values per district and use.

## Imports
- T04-05 inflation; T04-07 curves (`y10_b`); 09/16 demand ports.

## Exports
```ts
export function cityMacroStep(ctx): void;   // P2 day close after 04
export function districtMarketStep(ctx): void;
export function capRate(read, districtId, use): Rate;
export function appraise(read, propId, tick): AppraisalRec;   // V_inc, V_comp, blend
```

## Implementation steps
1. Demand, supply, vacancy and an EWMA pressure per §3.4; desirability per §3.5.
2. Rent index drift `exp(0.8·(pressure − 1))` per GY plus inflation, with daily moves clamped to 0.5%.
3. Cap rates move with `y10_b` one for one, within clamps.
4. Price index from comps (arm's-length only; forced sales excluded) plus the model term.
5. RNG streams `re/<cityId>/<purpose>/<entityId>`.

## Test plan
  - **10#8** pressure 1.2 for 364 GD with π = 0 → rent index +17.4% (±0.5%); no daily move > 0.5%.
  - **10#9** +100 bp on `y10_b` → every cap rate in the bloc +100 bp (unless clamped), and appraisals fall by the formula at the next appraisal.
  - **10#16** 100 forced sales in a district move the PI only through the model term.
