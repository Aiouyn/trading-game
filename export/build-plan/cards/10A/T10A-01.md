## Implementation steps
1. Ids (E-26, accepted by Producer). One regex-compliant scheme everywhere: `cty_`, `dst_`, `pcl_`, `bld_`, `unt_`, `lse_`, `prop_`, unique plots `unq_` (E-27), 07's loan id `lon_`, and 16B's `dyn_` (dynasty), `pty_` (party), `cau_` (caucus), `bil_` (bill), `ele_` (election), `lob_` (lobby registration) (E-30), and 16C's `hst_` (history entry), `fct_` (fact), `sec_` (secret), `brf_` (brief), `brk_` (breakthrough) (E-33); 07B's `mac_`, `mcl_`, `dfe_`, `lot_`, `csa_`, `esc_`, `clm_` and the fixed `ccp_*` ids (`ccp_TCH`, `ccp_LD`, `ccp_OTC`, `ccp_CDS`, `ccp_REPO`, `ccp_CRY`, `ccp_ESC`, `ccp_TCH_RETAIL_IF`, `ccp_CRY_IF_<product>`) (E-38); 10B's `lst_`, `dev_`, `ofr_`, `prm_`, `psl_`, `lau_`, `mqt_`, `obj_` (E-39); 04's release id kind `mrl_` (E-40); 09B's `pln_`, `rdp_`, `tof_`, `mrg_`, `vrd_`, `rst_`, `mot_`, `lbo_`, `ipo_` (E-44); 12's ids (E-46); 11's ids (E-50); 15B's `chn_`, `wir_`, `brd_`, `lgr_`, `chp_`, `chl_`, `riv_`, `itp_`, `ics_` (E-52). Spec 10 §2 and 22 §3 now use it.
   - Cities, districts, parcels and units are world records, not ledger entities, but every id still satisfies `^(?:[a-z]{3}|hh|prop)_[A-Za-z0-9_]+$` (≤ 64), so any can appear in a posting reference or event without migration.
   - `assertEntityId` runs at creation; the 64-character cap holds for the longest authored slug (`dst_port_avalon_summit_estates_on_gilt_hill`, 43).
   - The shipped client still uses `city_port_avalon` / `dist_port_avalon_*` (E-26 list); Front Dev switches it. Not a 10A task.
2. `rendererKey` is the renderer's city key (`avalon`, `nordhaven`…, the `^[a-z][a-z0-9-]*$` grammar of `prototypes/cities/src/parcel-id.js`). It is mapped 1:1 from the city row.
3. Geometry in integer centimetres; floats are only allowed in continuous fields and are quantised before storage.
4. Reason codes: 10 §3.7.2/§3.17/§3.25 names (`RE_COSMETIC`, rent, upkeep, property tax) bound to catalog rows via aliases (E-26): `RE_RENT_IN`→`PROP_RENT_ELASTIC|PROP_RENT_CORE`, `RE_PROPERTY_TAX`→`TAX_PROPERTY`, `RE_STAMP_DUTY`→`TAX_STAMP_DUTY`, `RE_MAINTENANCE`→`PROP_UPKEEP|PROP_UPKEEP_B2B`, `RE_MGMT_FEE`→`PROP_MANAGEMENT_FEE_NPC|_B2B`, `RE_VACANT_COST`→`PROP_VACANT_UTILITIES` (new), `RE_COSMETIC`→`CITY_COSMETIC` (BURN, 5200 chr / 5050 company), naming rights → `CITY_NAMING_RIGHT` (TRANSFER to gov; E-29); `PROP_VACANT_UTILITIES` on 5030 (E-28). `CATALOG_GAPS_10A = []` (empty). 10B codes (`RE_TXN_COST`, `RE_LAND_SALE`, `RE_PERMIT_FEE`, `RE_CONSTRUCTION_PAY`, `RE_UNIQUE_SALE`, `RE_MORTGAGE_*`, `RE_PREPAY_FEE`) are out of scope.
5. Ports: `content22` (names, personalities; 22A not yet carded), `macro04` (y10, inflation, city allocation), `biz09` (premises demand), `hh16` (household demand).
