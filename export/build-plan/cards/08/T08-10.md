## Goal
Every fund's public reputation is computed from its own net NAV: the track-record statistics of 08 §3.1.14 (daily at the strike), fund-board eligibility and ranking keys, and the weekly style-drift score of 08 §3.1.13, which reveals no positions (aggregate regression only, L11). NPC allocators (T08-11) and the fund pages (T08-30) read these numbers.

## Implementation steps
1. `NavHistory` (written by T08-03) holds the lead-series net NAV per unit per game day; daily net return `r_d = net_d / net_{d−1} − 1` (flows do not change NAV per unit, so no flow adjustment is needed). Days before launch are absent.
2. `trackStats` per 08 §3.1.14: `annualizedReturn = (Π(1+r_d))^(364/n) − 1` with `dmath.pow`; `annualizedVol = stdev(r_d) × √364` (sample stdev, n − 1); `sharpe = (mean(r_d) − mean(rf_d)) / stdev(r_d) × √364` with `rf_d` = 04 FDL 3-month bill yield of that day / 364; `maxDrawdown` = max over days of `1 − nav_d / max(nav_0..d)`; `currentDrawdown = 1 − nav_last / max(nav)`; `returnSinceInception = nav_last / nav_first − 1`; `benchmarkExcess` = fund return minus `mandate.benchmarkId` index return over the same days (0 without benchmark); `aumAvg90d` = mean AUM of the last 91 days (Money via `toMoney`); `quartersReported` = completed game quarters since launch; `daysOfHistory = n`. Use `dmath.kahanSum` for sums.
3. `updateTrackRecord` writes `Fund.trackRecord` (keeps `publicIncidents` from `fundState.incidents`), and sets a derived `boardEligible` flag on `FundState` (add `boardEligible: boolean` when writing; listed in `_unit.md` as a FundState field) per `boardEligible`. Board ranking itself is 15's rendering: 08 exposes the keys (Sharpe; 1-quarter return = return over the last 91 days; since-inception return) through the T08-30 views. Public fields are exactly those of 08 §3.1.14 bullet 2; positions are never part of them.
4. `factorReturns` (unit decision: 05 publishes no factor return series, so the 05 factor set is proxied by public index returns, which keeps the regression L11-safe): market = GX100 daily return; sector = (equal-weighted mean of the 12 sector index returns) − market, or the return of the single sector index when `mandate` restricts to one sector; region = return of the regional index of the fund's `homeBloc` − market; rates = −Δ(FDL 10-year government yield) × 8 (duration 8 proxy); riskAppetite = −Δfear (04); fx = mean of the four FDL-quoted FX leg returns (FDL strength, sign so that FDL up is positive); crypto = CRX10 return (0 if the index does not exist).
5. `weeklyStyleDrift` at WEEK_CLOSE (P8): for each ACTIVE/FROZEN/GATED fund with ≥ 91 days of history, regress the last 91 daily returns on the 7 factors plus an intercept (`olsBetas`, X with a leading column of ones; if the normal matrix is singular, drop the factors with zero variance and retry once; still singular → score unchanged). `styleDriftScore = min(100, 100 × Σ_k max(0, |β_k − clamp(β_k, lo_k, hi_k)|) / Σ_k (hi_k − lo_k))` over the factors present in the 22 profile of the fund's declared strategy (factors absent from the profile are not scored). Stored in `trackRecord.styleDriftScore`; shown publicly only when `quartersReported ≥ 2` (the view hides it before).
6. Determinism: fixed factor order `STYLE_FACTORS`; all loops over funds in id order.
