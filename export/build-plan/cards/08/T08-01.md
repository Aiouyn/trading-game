## Goal
Lay down the shared data model of module 08 (funds, ETFs, securitization, rating agencies, insurance, reinsurance, cat bonds) that every later 08 task imports: the entity types of 08 §2 exactly as written, the runtime state rows the rules need beyond §2, the store tables, deterministic id helpers, the non-PARAM constant tables of the spec, and the port interfaces through which modules built after 08 (09B, 11, 12, 13B, 14B, 15, 16, 19) feed it (GLOBAL-CONTEXT G6.1). Nothing here has behaviour beyond pure helpers; it is the contract.

## Imports
- T02-21: `Tick, Money, Qty, Price, Ccy, Id, TableDef, StoreRead, SortedMap`.
- T03-08: `RegisterEntitySpec` (type only, used in comments of genesis callers).
- T05-01: `AssetClass` (05 §2.1 union, used as `AssetClass` in `Mandate.allowedAssetClasses`), `ExternalOrder`, `PoolKind`, `Side`.
- T06A-01: `AssetId`, `IndexDef as AstIndexDef` (06-owned NPC indices; 08's player `IndexDef` is a separate type).

Apply the representation choices in the Exports header. `Fund.unitsOutstanding`, `FundPosition.units`, `SidePocket.units` values, `FundSeries.units` are units ×1e6. Prices (`navPerUnit`, `hwmNavPerUnit`, `inav`) are `Price` micro-units per whole unit. Add the runtime rows exactly as exported; they are the only additions.
2. `RATING_GRADES` in the §2.1 order (20 grades, index 0 AAA, 19 D); `LINES`, `PERILS`, `FUND_KINDS` in §2.6 / §2.2 declaration order (that order is the deterministic iteration order everywhere in 08).
3. `tables.ts`: one `TableDef` per row of `FND` with `module: '08'`, `idOf` returning the `id` field (or the composite id), secondary indexes as listed (index keys are strings; numeric keys use `pad(n, 10)`). `ALL_08_TABLES` in the order listed.
4. `ids.ts`: helpers as exported. `nextSeq08` reads and increments `fnd.counters` row `counter`, starting at 1. Ids of entities (`fnd_`, `spv_`, `ins_`) are always from `ctx.newId(kind)`; requests, quotes, claims use `ctx.newId('freq'|'fcu'|'rrq'|'rtg'|'qrq'|'quo'|'pol'|'clm'|'trt'|'tqt'|'cbd'|'cev'|'cwn'|'bid'|'spk'|'idx'|'ccl'|'vot'|'eo')`. Authored ids (agencies `rat_SVR`, `rat_MCO`, `rat_ORS`; NPC insurers and reinsurers; PGS `pgs_<bloc>`; bridge insurers) come from 22 content and these helpers.
5. `constants.ts`: copy the values from the cited sections exactly (grade anchors 0.0001, 0.0003, 0.0008, 0.0025, 0.010, 0.040, 0.15, 0.30, 0.50; agency rows of §3.4.1; methodology coefficients of §3.4.3 as named fields, e.g. `corporate: { c0: -5.8, debtEbitda: 0.9, icr: -0.6, revenue: -0.25, revenueScale: 100_000_000, marginVol: 2.0, convictions: 0.15, fear: 1.5, securedNotches: 1, subordinatedNotches: -2 }`, `bank: { c0: -5.2, cet1Gap: 30, cet1Ref: 0.12, npl: 8, lcr: -4, depConc: 3, fear: 1.2, size: -0.3, sizeScale: 10_000_000_000 }`, `insurer: { c0: -5.0, lnSolv: -2.0, pml: 1.5, pmlRef: 0.3, cr: 2.0, reins: -0.5, fear: 1.0 }`; peril table of §3.5.6; OC/IC defaults; reservation spreads; buyer floors; settle days per line). Freeze with `as const`.
6. `ports.ts`: interfaces as exported; `defaultFundsPorts()` returns the documented defaults; `resolveFundsPorts(p)` merges member objects shallowly (a partially supplied port keeps defaults for missing functions).
7. Unit decision recorded here and in `_unit.md`: agency starting reputation 70 (the spec gives no starting value; 70 sits above the regulator review threshold 40 and leaves room to fall).
