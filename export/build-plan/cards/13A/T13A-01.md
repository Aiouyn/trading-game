## Goal
Fix the shapes every later 13A card and 13B write to. Every sanction is a row; Held, freezes, op bans and garnishment plans are rows keyed so that a P1 check is one indexed read. Every money code used by 13A is bound once and checked against the catalog.

## Imports
- T03-01: `Id`, `Money`, `Ccy`, entity id rules. T03-02: `getCatalog()`. T03-08: `HoldApi` types. T14A-01: character ids, `chapterOf` via T14A-02 ports. T02-09: `TableDef`, `defineTable`. T02-11: `ModuleEvent` types.

## Implementation steps
1. Tables with the indexes the gate needs: `heldTable` and `opBanTable` keyed by chrId; `freezeTable` by chrId; `defendantFlagTable` by chrId. Sorted iteration only (`cmpStr`).
2. `TIERS` from 13 §3.2 exactly: S1 0.1% $1,000 $5M; S2 0.5% $5,000 $50M; S3 2% $20,000 $500M; S4 5% $50,000 $2B; S5 8% $100,000 $5B; S6 15% $250,000 none. Floors and caps are real dollars, converted with T14A-02 `realToNominal`.
3. The fine split shares are read from params and asserted to sum to exactly 1,000,000 ppm at module load. If not, the module refuses to start.
4. Events (13 §10): `law.sanction_applied` (PUBLIC for HELD, LICENSE_SUSPEND, PUBLIC_RECORD and S5/S6; PARTIES otherwise), `law.held_started`/`law.held_ended` PUBLIC `{chrId, until}`, `law.freeze_applied` PARTIES, and `law.garnishment_updated` PRIVATE (13A addition; open question).
5. `DEFAULT_LAW_PORTS`: `worldKind` 'ONLINE'; `nwAt` from T03-17 solo NW history; `linkedCharactersOf` → [].
