## Goal
"P1 checks used by every module" (19 §12.2). One cheap, read-only function answers "may this actor do this now?" for every intent class, and one place holds frozen assets. Modules call the gate; they do not read 13A tables.

## Exports
```ts
export type GatedClass = 'MANUAL_TRADE'|'OP_LAUNCH'|'LAW_FILE'|'PURCHASE'|'LICENSED_TRADE'|'TRANSFER_OUT'|'OTHER';
export interface GateQuery { actorId: Id; onBehalfOf?: Id; viaMandate: boolean; standing: boolean; cls: GatedClass; licenseId?: LicenseId; targetId?: Id; closingOnly?: boolean }
export function sanctionGate(read: StoreRead, q: GateQuery, tick: Tick): Reject | null;
// rejects: LAW_HELD, LAW_OP_BANNED, LAW_LICENSE_SUSPENDED, LAW_OP_LOCK_ACCUSER
export function leverageCapFactorPpm(read: StoreRead, chrId: Id): number;   // 500_000 with an active S3+ defendant flag, else 1_000_000 (07 applies)
export function placeFreeze(ctx: PhaseCtx, caseId: Id, chrId: Id, amount: Money, bond: boolean): Id | Reject;  // 13B calls
export function releaseFreeze(ctx: PhaseCtx, freezeId: Id): void;
export const LAW_PORTS_FOR_14A: Pick<CharacterPorts, 'isHeld'|'handleChangeBlocked'|'licenseEligibility'>;
```

## Implementation steps
1. The subject is `onBehalfOf ?? actorId`, resolved to the controlling character through the owner chain (03 §5.3), so a company owned by a Held character is gated too.
2. Held (13 §3.10): MANUAL_TRADE, OP_LAUNCH, LAW_FILE and PURCHASE are rejected `LAW_HELD`, unless `viaMandate` (AI within mandate) or `standing` (standing orders stay live). Defence actions and chat reads are OTHER and pass.
3. Op ban: OP_LAUNCH → `LAW_OP_BANNED` while `tick < untilTick`.
4. Licence suspension: LICENSED_TRADE on a SUSPENDED licence is allowed only with `closingOnly` (T14A-07 owns the licence state; the gate reads it).
5. Op lock (13 §3.6): OP_LAUNCH with a `targetId` that is the accuser of an open case against the subject → `LAW_OP_LOCK_ACCUSER`.
6. Freeze: `placeFreeze` places T03-08 holds totalling `1.2 × claim` (amount from 13B), or 30% as bond when `bond`; held positions stay marked and cannot be sold. It refuses if the result would breach the floor (T13A-04 `floorRoom`) and freezes only what is above it.
7. 14A ports: `isHeld` = `isHeldAt(tick)`; `handleChangeBlocked` = open defendant flag, Held, or a conviction applied in the last 7 real days (120,960 ticks); `licenseEligibility` → `{eligible:false, reason}` for HELD, SUSPENDED, an active S5 conviction this chapter (CONVICTION_S5_ACTIVE) or UNDER_INVESTIGATION (flag written by 13B; always false until 13B exists).
8. Cost: O(1) indexed reads; the gate never writes and never posts.

## Test plan
  - **AC-13A-06-1** Held character: manual buy rejected `LAW_HELD`; the same buy through an AI mandate is accepted; a standing order fills; a defence action passes.
  - **AC-13A-06-2** a company controlled by a Held character is gated the same way.
  - **AC-13A-06-3** op ban: an op at untilTick − 1 is rejected, and accepted at untilTick.
  - **AC-13A-06-4** a suspended Derivatives licence allows a closing order and rejects an opening order.
  - **AC-13A-06-5** a freeze places holds of 1.2 × claim, or 0.3 × claim as bond; frozen positions cannot be sold; the floor is never frozen; `releaseFreeze` clears all holds.
  - **AC-13A-06-6** `leverageCapFactorPpm` is 500,000 with an S3+ defendant flag and 1,000,000 with an S2 flag or none.
  - **AC-13A-06-7** the 14A ports replace `DEFAULT_PORTS` in T14A-11 wiring, and 14A's handle-change and licence tests pass with them.
  - **AC-13A-06-INERT** until 13B exists, `defendantFlagTable` is only written by the fixture `fixtures/defendantFlag.ts`; the op lock, leverage cap and UNDER_INVESTIGATION paths are tested through it.
  - **Exploit notes** acting through an owned company or an alias actor to dodge Held: owner-chain resolution. Placing a freeze to bankrupt a rival: the floor is never frozen.
  - **AC-13A-06-HELD-LAW** (E-24): the gate classes `law.post_bond`, `law.offer_settlement`, `law.accept_settlement` and `law.appeal` as OTHER (allowed while Held). `law.file_case` is LAW_FILE (blocked).
