## Goal
Provide the shared HTTP layer every `/api/v1/**` route of 19 Rule 3.10.1 uses (authentication, `{code, params}` errors, money as decimal strings, per-IP and per-account rate limits, CSRF), the web hardening of Rule 3.9.7 in `proxy.ts` (Next 16), the public roll verification of Rule 3.12.4 with the identical function in `packages/sdk`, and the jobs task that publishes the signed daily integrity report of Rule 3.12.5 with its public route.

## Implementation steps
1. `route()` wraps every handler: authentication (Better Auth session cookie, native bearer, or the signed API `Authorization` header of T19D-03 later), zod args (unknown fields rejected), CSRF on state-changing methods (double submit + SameSite, Rule 3.9.7), `httpLimit` (`http_rps_per_ip` 20, `http_rps_per_account` 10; auth endpoints use T19C-02's limits), JSON response with bigint as decimal strings, errors `{code, params}` (i18n keys, Rule 3.17.7). Reads come from read models only, never partitions (Rule 3.10.1), except replay (T19D-05).
2. `proxy.ts`: generate a nonce per request, set the CSP and security headers above, pass the nonce to the app via a request header `x-nonce`; TLS 1.3 and HSTS preload are enforced at the edge (T19D-07) and the header here.
3. Roll verification (Rule 3.12.4): find the event by `(tick, seq)`; it must be a roll event (payload has `rollDomain`) and either PUBLIC or PRIVATE/PARTIES with the requester in `party_ids` (else 403, same body as not found for privacy: 404 NOT_FOUND for both missing and foreign, E22); the epoch `floor(tick / entropy_epoch_ticks)` must be revealed (`entropy_epoch.secret` not null) else 409 NOT_REVEALED (no foresight, E4); compute with the sdk functions and return; thresholds as the owning module recorded them (or the band where the module shows only bands).
4. SDK equality: `rollU` and `tickEntropy` must equal T02-07's `partyRollU` and `EntropyBuffer.eOf` byte for byte (02 owns the formula; R28).
5. Integrity report (Rule 3.12.5): every game day after the day close, jobs builds the report from read models (postings by reason class from 03's archive in ClickHouse, M0/M2 from 04's events, systemic indicators from 07/08 projections, invariant counts from `tick_record`, the day's entropy commits and reveals, the audit chain head of T19B-15, exploit-fix history released by 21), signs `canonJson(report)` with the INTEGRITY platform key, stores the row; the route serves it with the key id so anyone can verify. Sections whose producer module is not built yet are empty arrays (the producer fills them through its read model when it lands; no placeholder numbers are ever written).
