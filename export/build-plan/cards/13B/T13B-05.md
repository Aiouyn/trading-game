## Goal
A fair, replayable verdict where money shades a close case but cannot buy it, and Reputation never matters. Every judgment becomes a `SanctionOrder` for 13A.

## Imports
- T13B-04 cases. T13A-03 `applySanction`. T02-06 `streamHash(worldSeed,'law',tick)`. T02-02 `sigmoid`.

## Exports
```ts
export function pVerdict(E: number, bar: number, gradeC: Grade, gradeD: Grade): number;   // inputs exactly these four (INV-LAW-004)
export function decide(ctx, caseId): void;
export function damages(kind: 'MODEL'|'DATA', x: DamagesInput): Money;
export function settlementBand(read, caseId): { lo: Money; hi: Money };   // 50–80% of expected verdict value
export function chapterEndResolve(ctx): number;
```

## Implementation steps
1. `p = σ((E − bar)/8 + 0.15·(gC − gD))`; the counsel term is clamped to ±0.75.
2. The draw comes from the `law` stream, ordered by caseId, so it is replayable.
3. Damages per §6: max(replacement, lost licence revenue, thief gain); data = market value × copies + resale.
4. Attribution without quantum → statutory minimum (T13A-02).
5. Plea −30% and naming a co-conspirator gives +30 evidence against them and immunity from Held; consent decrees at 60–75% of the schedule (85% sink).
6. Chapter end: open cases resolve in the final 3 game days at expected value (§3.13), whichever of the parties' offers is closer to the evidence score.
7. Verdict events stay SEALED until decided, then go out per §10 visibility.
