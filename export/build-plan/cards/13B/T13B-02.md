## Goal
Evidence is only ever derived from the engine's own SEALED events and ledger postings, so it can never be forged; it decays, and repeated sources of the same type count for less.

## Imports
- T13B-01 tables and ports. T02-02 `dmath.exp` (deterministic). T02-12 P11 phase hook.

## Exports

export function evidenceAt(read, tripleKey: string, tick: Tick): { total: number; who: boolean; howMuch: boolean };
export function ingestSources(ctx: PhaseCtx): number;      // P11: from ports.sealedEvidence, rejects any source without sealedRefs
export function recomputeDaily(ctx: PhaseCtx): void;       // DAY_CLOSE: evidence_updated events

## Implementation steps
1. `evidence = Σ points · exp(−days/τ) · 0.5^(n−1)`, with n the order within the same sourceType; days in real days (ticks / 17,280). dmath exp; the result is rounded to 1e-6 for determinism.
2. `who` is true if any WHO or BOTH source exists; `howMuch` if any HOW_MUCH or BOTH. Watermark sources never set howMuch (§3.1).
3. A query-anomaly flag source is capped at 30 points (below the civil bar).
4. Reject a source with empty `sealedRefs` or refs not in the sealed log (anti-forgery). Whistle and bounty submissions are pointers to sealed refs, never points.
5. Obstruction (§5): deleting a student model after a notice adds a +20 source (IN_HOUSE_REVIEW type, sealed ref = the deletion event) and sets `fineMult 1.5` on the triple; residue on models trained from the student keeps resolving the triple (11 port).
