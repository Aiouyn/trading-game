## Goal
A real remedy for wrong verdicts that never delays a victim's money beyond a day.

## Imports
- T13B-05 decided cases. T13A-03 `liftSanction`. T03-08 holds (escrow).

## Exports
```ts
export function fileAppeal(ctx, caseId, grounds): Id | Reject;  // LAW_APPEAL_EXISTS, LAW_APPEAL_NO_GROUNDS
export function decideAppeal(ctx, appealId): void;             // ≤ 17,280 ticks after filing
```

## Implementation steps
1. One appeal per case; the fee is 2% of the judgment, refunded on a win.
2. Grounds: new evidence ≥ 10 since the verdict, or a procedural flag (wrong bar or stale evidence counted).
3. The judgment is escrowed (hold). The deadline is deterministic: `decisionTick = filedTick + 17,280` (24 real hours in ticks), stored on the appeal row at filing. At P11 of `decisionTick`, an appeal that is still undecided closes as `LAPSED`: the verdict stands and the escrow is released to the victim, in the same tick (Producer, E-24).
4. Reversal → `liftSanction(APPEAL_WON)`.
5. At chapter end, resolve at expected value (§14 #5).
