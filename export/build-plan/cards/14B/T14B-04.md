## Goal
Scarcity without randomness (L5). Each chapter every LIMITED def drops a sized batch; requests collected over one game day are served by category PP, then request tick, then id hash. NPC collectors take at most 30% of unsold units. UNIQUE items trade only at 06's auction house. Player luxury companies (09) publish their own editions, with caps that stop alt funnelling (§9 #2, #12).

## Implementation steps
1. Drops open at each chapter start (chapter from 14A port `chapterOf`) for every LIMITED def with `editionSizeBase`; window `drop_window_ticks` (720). Serial format "drop D, N of S" (§8 #8: serials continue across drops). Emit `life.drop.opened` PUBLIC (counts only).
2. `life.drop.request` validation: window open; one request per character per drop; `maxPrice >= list`; guests and accounts younger than 7 real days refused (`LIFE_DROP_NEW_ACCOUNT`, §9 #12); already holds a unit of this drop → `LIFE_DROP_MAX`.
3. `allocateDrop` (pure, no RNG): sort by (category PP of the requester at the last close desc, request tick asc, `fnv1a32(chrId)` asc, chrId asc); take `size` winners, at most `drop_max_per_char` each. Winners pay list via `placeCashFor` at request time (hold released for losers).
4. NPC take (§6 #3): `min(unsold, ceil(0.3 × size))` units to NPC collectors at list (no OwnedItem rows; recorded as `npcTaken`). Rest stays on sale at list until the next drop. Emit `life.drop.allocated`.
5. UNIQUE (§3.6.4): `life.item.consign` requires LIMITED/UNIQUE, CLEAN provenance, not pledged; creates a 06 lot via port. Summit members bid `summit_early_bid_ticks` early (T14B-08 sets the flag 06 reads).
6. Editions (§3.6.7): publish requires a controlled luxury business (09 port), size 2–500, unitPrice ≥ unitCost, moderated name. Sales: TRANSFER to the maker (`LIFE_EDITION_SALE`, catalog gap); `editionBuyCheck` refuses price > `edition_max_price_multiple × unitCost` to a buyer linked to the maker's controller (`LIFE_EDITION_LINKED_PRICE`) and a 4th unit to the same buyer (`LIFE_EDITION_BUYER_CAP`). §8 #10: unsold units move with the company; minted serials keep the maker name.

Inert linking. **AC-14B-04-INERT** (Producer ruling, E-22): with `DEFAULT_PORTS.linkedCharactersOf` (15 not present) no pair is linked, so the edition linked-price cap (3× cost to a linked buyer) and the drop alt check is inert; this is the intended state until 15 provides the port, and no 14B code changes when it does. Fixture `fixtures/linkPorts.ts` re-exports 14A's `NO_LINKS` and `linkedPair(a, b)`.
