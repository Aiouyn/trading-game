## Goal
Lifestyle is the economy's voluntary sink. At each day close every item pays upkeep (and homes and craft pay staff); unpaid items lose condition, never create debt and are never repossessed by 14. Restoration buys condition back. This task also posts the daily marks that keep net worth right, and exposes the collateral rates (07) and the theft target list (12).

## Implementation steps
1. `upkeepDue`: `upkeep = value × upkeepRate / 364`; staff via `staffNominalPerDay`. Modifiers: SPARTAN −10% upkeep, STEWARD −10% staff (one chapter, T14B-09).
2. `runUpkeep`: per item, if unrestricted + restricted cash ≥ due, post `LIFE_UPKEEP` and `LIFE_STAFF` (ELASTIC_OUT to `hh_LUX`), arrears 0. Else post nothing, arrears +1, condition −`condition_decay_unpaid` (0.02, floor 0) (14#15). Held does not block (§8 #17). Upkeep includes baseline NPC insurance; when `insuredBy` is a player insurer the baseline share is not charged (08 provides the share, default 0).
3. `life.item.upkeep.pay`: pays today's arrears only; no back-pay; lost condition stays lost.
4. `life.item.restore`: cost `(1 − condition) × value × 0.5` (`LIFE_RESTORATION`, gap), completes after `restore_game_days × 720`; condition 1 at completion.
5. `runMarks`: REVALUE the item asset to `itemValue` (one accrue per changed item).
6. Theft (§3.6.12): `physicalTargets` for 12; a stolen item can be fenced only via the Back Room at 40% (12 owns). Pledged items (§3.6.11) cannot be sold, gifted or swapped; §8 #7: during a Fresh Start 07 sells the pledged item and repays first.
