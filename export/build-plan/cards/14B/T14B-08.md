## Implementation steps
1. Clubs: eligibility by PP and R (Back Room by N ≥ 50); dues one quarter in advance at join (`LIFE_CLUB_DUES`); §8 #13 Prestige fade → GRACE one quarter. S4+ conviction suspends the three public clubs at the verdict tick, no refund. Back Room joins emit `life.club.joined` with visibility SEALED only. Summit sets the early-bid flag for 06; Glasshill sets the "Circle whispers" entitlement for 16 (7 game days after each Gala).
2. Hosting (§3.12.2): capacity 8/30/100, cost $50k/$500k/$5M real × MSI (`LIFE_HOSTING`), venue must host the kind (DINNER penthouse+, PARTY mansion+, GALA estate/island/skyline) else `LIFE_VENUE_KIND`; start 30 ticks to 51,840 ticks ahead; one event per `hosting_cooldown_real_hours`; invitees ≤ capacity × 2. At END, each attendee unlinked to the host, account ≥ 7 real days, host R ≥ 50 gets `HOSTED_EVENT_ATTENDED`. Venue sold before start → cancel with full refund (§8 #14). Held attendee: read-only, no bump (§8 #15).
3. CoS (§3.12.6): mansion or better; ≤ 3 intents of kinds `biz.upgrade`, `mkt.order.place` (limit only), `prop.upkeep.pay`, `biz.manager.hire`, plus 14's `life.item.upkeep.pay` and `life.hosting.rsvp`; submitted at t = 60 of the next trading day only if offline; each through normal P1.
4. Security grades (§3.12.9) with install sinks and 10%/yr upkeep; minimum home per grade.
5. Experiences: 100% sink (`LIFE_EXPERIENCE`), PP burst, title if any. Donations ≥ $10,000 real from unrestricted cash (`LIFE_CHARITY`), Rep via `philanthropyRep`; philanthropy items add Legacy (T14B-10 message) and plaques; one wing per hospital/museum per city.

Inert linking. **AC-14B-08-INERT** (Producer ruling, E-22): with `DEFAULT_PORTS.linkedCharactersOf` (15 not present) no pair is linked, so denying HOSTED_EVENT_ATTENDED to attendees linked to the host is inert; this is the intended state until 15 provides the port, and no 14B code changes when it does.
