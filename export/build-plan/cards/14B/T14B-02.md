## Goal
The 46 launch defs of 14 §3.7 as typed data (14 owns the numbers; 22 owns names and wins on counts) and the pure functions every later 14B task uses: today's nominal price, an item's value for net worth, and its PP. No state is written.

## Imports
- T14B-01: `LifestyleItemDef`, `OwnedItemRow`. T14A-02: `realToNominal`, `msiPpm`.
- Ports (declared here, wired in T14B-14): `wliValue(read)` from 03 Stabilizer lever L2 (default 1.0); `collectibleFairValue(itemId, tick)` from 06 (default: `pricePaidReal × MSI`).

## Exports
```ts
export const LIFESTYLE_DEFS: Readonly<Record<string, LifestyleItemDef>>;   // 46 defs, keys 'lid_*'
export function nominalListPrice(read: StoreRead, def: LifestyleItemDef): Money;   // listPriceReal × MSI × WLI, half even
export function staffNominalPerDay(read: StoreRead, def: LifestyleItemDef): Money; // staffReal × MSI × WLI / 364
export function itemValue(read: StoreRead, it: OwnedItemRow, def: LifestyleItemDef, tick: Tick): Money;   // §3.6.8
export function ppItem(it: OwnedItemRow, def: LifestyleItemDef, tick: Tick, heirloomCap?: number): number; // §3.8.1, integer
export function ageFactor(def: LifestyleItemDef, it: OwnedItemRow, tick: Tick, cap?: number): number;
export function rarityMult(def: LifestyleItemDef): 1 | 2 | 4;
```

## Implementation steps
1. Transcribe §3.7.1–§3.7.6 into `LIFESTYLE_DEFS`. Percentages become rateE6. `catalog.test.ts` checks the count is 46 and spot rows (Furia $1.2M, hit 15%, dep 10%, upkeep 6%, PP 35; Kessler Field $1,200, hit 30%).
2. `nominalListPrice`: `toMoney(listPriceReal_dollars × msi × wli)` once (G3); WLI clamped [0.90, 1.25].
3. `itemValue` (§3.6.8): MASS `pricePaid × (1−hit) × (1−dep)^(ageGameYears) × (0.5 + 0.5·condition)` with `ageGameYears = (tick − acquiredTick)/262,080` and `dmath.pow`; LIMITED/UNIQUE `collectibleFairValue × (0.5 + 0.5·condition)`; HOME: 10's property fair value (port `propertyFairValue`, default pricePaid); CONSUMED 0.
4. `ppItem` (§3.8.1): `round(sqrt(pricePaidReal/1,000 dollars) × rarity × condition × ageFactor)` with `roundHalfEven`. Age factor: MASS 1 → 0.5 linear over 1 game year then 0.5; LIMITED/UNIQUE 1 → 1.25 over 2 game years from `heritageStartTick` (cap 1.30 with the COLLECTOR heir trait on heirlooms, passed in by T14B-09); HOME 1. EXPERIENCE and PHILANTHROPY items return 0 (bursts and Reputation are separate). §8 #4: PP uses `pricePaidReal` fixed at purchase, never today's MSI.
