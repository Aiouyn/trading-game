## G4. Time (00 §5.1)

5 real seconds per tick; 720 ticks per game day (= 1 real hour); 30 ticks per game hour; one tick = 2 game minutes. Week = 7 game days (Mon–Fri trading, Sat–Sun weekend). Quarter = 13 weeks = 91 game days, months 28/28/35 days. Year = 364 game days = 262,080 ticks. Chapter = 8 real weeks = 1,344 game days. Real day = 24 game days.
Trading day tick-of-day `t`: pre-market 0–59; opening auction t=60; continuous 61–539; closing auction t=540; after-hours 541–719. Accruals (interest, rent, wages, fees) post at day close t=719. Business operations run once per game hour, staggered: an entity runs when `tickOfDay mod 30 == fnv1a32(id) mod 30`.

## G5. Tick pipeline (00 §5.2)

```
P0 ingest  P1 validate  P2 calendar  P3 world(16)  P4 npc(05,16)  P5 ai(11)  P6 match(05,06)
P7 clear(07)  P8 finance(07,08)  P9 real(09,10)  P10 conflict(12)  P11 law(13)  P12 social(14,15)
P13 ledger(03: commit postings atomically, settle/release holds, assert invariants)  P14 emit
```
A phase may read any committed state and the outputs of earlier phases of this tick; it writes only its own module's tables and queues postings for P13. Postings never commit before P13. A failed invariant rolls the tick back and replays it in safe mode. Consequences of tick N that other modules react to land in tick N+1 (via `ctx.send(..., 'NEXT')` or events).

### G6.1 Ports for later modules (dependency inversion)

A module may never import a module built after it. When its rules need data from a later module (for example 05 needs fundamental values from 09 or index weights from 08), it declares a **port**: a TypeScript interface in its own `ports.ts` (e.g. `MarketPorts`), and its factory takes the implementations: `createMarketsModule(ports: Partial<MarketPorts>)`. The later module exports an implementation of that port, and `packages/engine/index.ts` wires them when building the world. A missing port uses the default the spec gives for "module not present" (stated in the card), never an invented rule.

## G8. Determinism rules (02 §3.7, 19 Rule 3.6.2) — lint-enforced in packages/engine

Forbidden in engine code: `Date`, `performance`, `Math.random`, `crypto` randomness, timers, `process`, `globalThis`, `Intl`, `toLocaleString`, `localeCompare`, `async/await`/Promises, `for…in`, iterating `Object.keys/values/entries` of map-like objects, `Map`/`Set` iteration where order matters (use `SortedMap`/`SortedSet`), `Array.sort` without a total comparator (use `sortBy`), `JSON.stringify` for hashing/persistence (use `canonEncode`), `WeakMap/WeakRef`, `Math.exp/log/pow/sin/cos/tan/atan2/cbrt/hypot/...` (use `dmath`), `Math.round` (use `roundHalfEven`), `Number` for money or quantities. Allowed raw math: `+ - * /`, `Math.sqrt/abs/floor/ceil/trunc/min/max/sign/fround/imul/clz32`.
NaN/Infinity are illegal in state. Ties are broken by entity id then intent id. Iterate collections only in sorted order. Rejection sampling is forbidden; each variate uses a fixed number of draws. A module may draw only from its own streams. Split money into parts only with `allocate`. No exceptions for control flow: report impossible states with `ctx.fail`.

2. `acct.exam.submit` (common validate): `examKey(examId)`; `lastAttemptTick + exam_retake_game_days × 720 > tick` → `ACCT_EXAM_RETAKE_WAIT`; score = count of equal answers; pass when `score >= passMark` → `passedTick = tick`. 3. `examValid`: the character holds the license, or `passedTick != null && chapterOf(tick) − chapterOf(passedTick) < exam_valid_chapters`.
4. `acct.license.buy`, P1 order of checks (first failure wins):
   1. common validate (`ACCT_NOT_SELF`, `ACCT_ANONYMIZED`, `ACCT_ACCOUNT_BLOCKED`, `ACCT_HELD`);
   2. already ACTIVE, SUSPENDED or LAPSED for that id → `ACCT_ALREADY_HELD` (LAPSED uses `acct.license.renew`, T14A-07); REVOKED may buy again;
   3. ladder order: LIC(n) requires LIC(n−1) ACTIVE (conservative; spec implies a ladder, open question 5) → `ACCT_RANK_GATE` with `params.missing`;
   4. `rankAtLeast(rankOf(chr), rankGate)` else `ACCT_RANK_GATE`;
   5. exam required and not `examValid` → `ACCT_EXAM_REQUIRED`;
   6. `licenseEligibility(chr, lic).eligible` else `ACCT_NOT_ELIGIBLE` with `params.reason`;
   7. fee: `ledger.available(chr,'FDL') >= fee` (G7 `available` excludes restricted lots, 14 §4 "restricted cash not allowed") else `ACCT_INSUFFICIENT_FUNDS`; place `placeCashFor(chr,'FDL',fee,tick+1,intentId,'ACCT_LICENSE_FEE')`.

   - Restricted cash: ledger errata E-21 sets `ACCT_LICENSE_FEE` restrictedOk = N, so the rail never draws a restricted lot for the fee and the hold fails with `LED_RESTRICTED_FUNDS` when only restricted cash would cover it. 5. `grantOnboardingLic1` (18 sends `acct.onboard.lic1` during onboarding, 00 §5.9): if `onboardGrantPaid` → return `ACCT_ALREADY_HELD` and post nothing. Else one entry pair: `mint(chr, realToNominal(250e6), 'FDL', 'ACCT_ONBOARD_GRANT')` then `burn(chr, same, 'FDL', 'ACCT_LICENSE_FEE')` in the same tick (net cash 0), LIC1 ACTIVE with `renewalDueTick null`, `onboardGrantPaid = true`. No exam, no eligibility call (R0).
6. `INV-CHR-003` (TICK, FATAL): every ACTIVE LIC2–LIC4 row had at grant time `reachedTick[rankGate] <= grantedTick` and an exam pass with `passedTick <= grantedTick`; every ACTIVE charter row satisfies the charter rank gate (T14A-07 table).
7. `INV-CHR-004` (TICK, FATAL): per character, the count of committed `ACCT_ONBOARD_GRANT` postings ever is ≤ 1 (kept as a counter in CharacterRow `onboardGrantPaid` plus a check of this tick's postings: a second posting for a character with the flag already true fails); LIC1 rows never have state LAPSED.

# SPEC EXCERPTS (verbatim; binding game rules)

**[14 §1 Purpose]** (context)

## §1 Purpose

1. **Make money feel like something.** Rank, home, shell, possessions and titles turn net worth into a place and an identity. A player should feel the jump from $50k to $5M without reading a number (old 04 §0.1).
2. **Drain money in a way players want.** Lifestyle is the economy's most voluntary sink. Mass luxury loses value on purchase and fades in Prestige, so it must be refreshed; collectibles hold value but carry upkeep (old 04 §5.1).
3. **Give small, real, capped advantages** for spending (access, convenience, talent, collateral, reach, physical security) so spending is a decision, never a cash faucet (old 04 §0.4).
4. **Keep three separate social axes**: Prestige (status from what you own and display), Reputation (trust from clean conduct), Notoriety (fame from crime). A player can be high on all three (old 04 §7.1, bible decision 5).
5. **Remember.** The world never resets (L1), so Legacy, Houses and succession give a permanent public history: founding plaques, generations, heirlooms, chapter portraits (V3 Part 9).
6. **Respect the player.** No demotion, no punishing streaks, no real-money path to any of this (L7), quiet money stays a valid strategy (old 04 §7.8).

### §3.3 License ladder

**§3.3.1 Ladder.** `DEFAULT (Mathis may override)` fees and exams (old 01 §3 "licenses cost money and have a background check"; no numbers existed):

| License | Unlocks (owned by 06/07) | Rank gate | Fee (real, sink `ACCT_LICENSE_FEE`) | Exam (18 Academy) | Renewal per game year |
|---|---|---|---|---|---|
| LIC0 Cash | cash account, spot buys of nothing but businesses and lifestyle | — | 0 | — | — |
| LIC1 Retail | stocks, ETFs, major crypto, unlevered | R0 (granted in onboarding) | $250, paid by the onboarding grant (`ACCT_ONBOARD_GRANT`, FAUCET $250, once; 00 §5.9) | none | 0 |
| LIC2 Pro | FX, commodities, bonds, margin 2×, shorting, execution algos | R2 | $15,000 | Pro exam (10 questions, 8 to pass) | 10% of fee |
| LIC3 Derivatives | options, futures, perps, swaps, CDS protection buying, up to the 06/07 caps (10×) (06 §3.2 is authoritative) | R3 | $250,000 | Derivatives exam (payoff diagrams, margin) | 10% of fee |
| LIC4 Institutional | private deals, underwriting, structured products, OTC blocks, CDS protection selling, prime brokerage access (06 §3.2 is authoritative) | R4 | $5,000,000 | Institutional exam | 10% of fee |

Fees are stated in real dollars and charged as `fee × MSI(tick)`. Exams are free, retakable after `PARAM.exam_retake_game_days = 1` game day, and teach rather than gate experts (18 lets a player who passes the Academy track's final quiz skip the exam).

**§3.3.2 Eligibility interface (13).** Before granting or renewing, 14 calls `law.licenseEligibility(characterId, licenseId) → { eligible: boolean; reason?: 'CONVICTION_S5_ACTIVE' | 'SUSPENDED' | 'HELD' | 'UNDER_INVESTIGATION' | 'OTHER' }` (13 owns the rule, e.g. convicted players lose licenses). A license can be suspended or revoked only by a 13 sanction event; 14 applies it (`state`, `suspendedUntilTick`). While suspended, positions of the unlocked classes can only be closed (13 §sanctions, old 03 §9.6).

**§3.3.3 Renewal.** At `renewalDueTick` the renewal fee is charged. If cash is insufficient, the license enters `LAPSED` after a grace of `PARAM.license_grace_game_days = 7` game days; while LAPSED, only closing orders are allowed for that class, and paying the fee restores `ACTIVE` immediately. LIC1 never lapses.

**§3.3.4 Charters.** Charter applications (`acct.charter.apply`) check the rank gate in §3.2.2 and forward to 13, which owns capital, record, fee and approval. 14 stores the resulting `LicenseHolding` with the `CharterId`.
