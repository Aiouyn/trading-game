## G4. Time (00 §5.1)

5 real seconds per tick; 720 ticks per game day (= 1 real hour); 30 ticks per game hour; one tick = 2 game minutes. Week = 7 game days (Mon–Fri trading, Sat–Sun weekend). Quarter = 13 weeks = 91 game days, months 28/28/35 days. Year = 364 game days = 262,080 ticks. Chapter = 8 real weeks = 1,344 game days. Real day = 24 game days.
Trading day tick-of-day `t`: pre-market 0–59; opening auction t=60; continuous 61–539; closing auction t=540; after-hours 541–719. Accruals (interest, rent, wages, fees) post at day close t=719. Business operations run once per game hour, staggered: an entity runs when `tickOfDay mod 30 == fnv1a32(id) mod 30`.

## G5. Tick pipeline (00 §5.2)

```
P0 ingest  P1 validate  P2 calendar  P3 world(16)  P4 npc(05,16)  P5 ai(11)  P6 match(05,06)
P7 clear(07)  P8 finance(07,08)  P9 real(09,10)  P10 conflict(12)  P11 law(13)  P12 social(14,15)
P13 ledger(03: commit postings atomically, settle/release holds, assert invariants)  P14 emit
```
A phase may read any committed state and the outputs of earlier phases of this tick; it writes only its own module's tables and queues postings for P13. Postings never commit before P13. A failed invariant rolls the tick back and replays it in safe mode. Consequences of tick N that other modules react to land in tick N+1 (via `ctx.send(..., 'NEXT')` or events).

### G6.1 Ports for later modules (dependency inversion)

A module may never import a module built after it. When its rules need data from a later module (for example 05 needs fundamental values from 09 or index weights from 08), it declares a **port**: a TypeScript interface in its own `ports.ts` (e.g. `MarketPorts`), and its factory takes the implementations: `createMarketsModule(ports: Partial<MarketPorts>)`. The later module exports an implementation of that port, and `packages/engine/index.ts` wires them when building the world. A missing port uses the default the spec gives for "module not present" (stated in the card), never an invented rule.

## G8. Determinism rules (02 §3.7, 19 Rule 3.6.2) — lint-enforced in packages/engine

Forbidden in engine code: `Date`, `performance`, `Math.random`, `crypto` randomness, timers, `process`, `globalThis`, `Intl`, `toLocaleString`, `localeCompare`, `async/await`/Promises, `for…in`, iterating `Object.keys/values/entries` of map-like objects, `Map`/`Set` iteration where order matters (use `SortedMap`/`SortedSet`), `Array.sort` without a total comparator (use `sortBy`), `JSON.stringify` for hashing/persistence (use `canonEncode`), `WeakMap/WeakRef`, `Math.exp/log/pow/sin/cos/tan/atan2/cbrt/hypot/...` (use `dmath`), `Math.round` (use `roundHalfEven`), `Number` for money or quantities. Allowed raw math: `+ - * /`, `Math.sqrt/abs/floor/ceil/trunc/min/max/sign/fround/imul/clz32`.
NaN/Infinity are illegal in state. Ties are broken by entity id then intent id. Iterate collections only in sorted order. Rejection sampling is forbidden; each variate uses a fixed number of draws. A module may draw only from its own streams. Split money into parts only with `allocate`. No exceptions for control flow: report impossible states with `ctx.fail`.

## Implementation steps
1. `sin/cos`: Cody-Waite reduction by π/2 with a 3-part constant (PIO2_1 = 1.5707963267341256, PIO2_2 = 6.077100506506192e-11, PIO2_3 = 2.0222662487959506e-21; tails as in fdlibm), n = round(x·2/π), r in [-π/4, π/4]; minimax kernels __sin (degree 13 odd, fdlibm S1..S6) and __cos (degree 14 even, fdlibm C1..C6) with the coefficient literals copied from fdlibm `k_sin.c`/`k_cos.c`; select by n mod 4.
2. `atan`: reduce |x| > 1 via atan(x) = π/2 − atan(1/x); then to [0, tan(π/12)] via atan(x) = π/6 + atan((x√3 − 1)/(x + √3)); odd series to degree 23 on the reduced argument. `atan2` handles the quadrant table and signed zeros explicitly (atan2(±0, -0) = ±π, etc., per IEEE conventions).
3. `erf/erfc`: W. J. Cody's rational approximations (1969) in three ranges |x| ≤ 0.5, 0.5 < |x| ≤ 4, |x| > 4, with coefficients from Cody's CALERF tables (copy literals); exp(-x²) computed as exp(-xsq·xsq)·exp(-(x-xsq)(x+xsq)) with xsq = trunc(x·16)/16 for accuracy.
4. `normInv`: Wichura AS241 PPND16 (three regions: |q| ≤ 0.425, r ≤ 5, r > 5) with its published coefficients; r uses `sqrt(-ln(min(p,1-p)))`.
5. `lgamma`: Lanczos g = 7, n = 9 coefficients (0.99999999999980993, 676.5203681218851, -1259.1392167224028, 771.32342877765313, -176.61502916214059, 12.507343278686905, -0.13857109526572012, 9.9843695780195716e-6, 1.5056327351493116e-7); x < 0.5 not allowed (domain x > 0, use reflection only for 0 < x < 0.5 via lgamma(x) = ln(π/|sin(πx)|) − lgamma(1−x)).
6. `bsPrice`: d1 = (ln(S/K) + (r − q + σ²/2)T)/(σ√T), d2 = d1 − σ√T; call = S e^{-qT} N(d1) − K e^{-rT} N(d2); put by the symmetric formula. Edge (E-63, per Quant 2026-10-21): τ = max(T, 0) (T < 0 clamps to 0, not a fault); σ < 0 faults (EngineFault('I0.domain')); when τ == 0 or σ == 0 the price is intrinsic on the forward, with F = S·e^{−qτ} and Kd = K·e^{−rτ}: call max(F − Kd, 0), put max(Kd − F, 0); greeks per AC-02-03-GREEK-LIMITS. Greeks by the standard closed forms (delta call e^{-qT}N(d1), gamma e^{-qT}φ(d1)/(Sσ√T), vega S e^{-qT}φ(d1)√T, theta and rho closed forms).
7. Solvers: fixed loops exactly `iters` times, no early exit (determinism of draw-free control flow). Bisection keeps the sign-change half; returns the midpoint of the final bracket.
8. Cholesky: classical row-by-row loops in fixed i, j, k order; diagonal ≤ 0 -> EngineFault('I0.not_pd').
9. References: BigFloat implementations (Taylor series for sin/cos/atan after exact reduction using a 300-bit π computed by Machin's formula; erf by its Maclaurin series for |x| < 3 and the asymptotic continued fraction for erfc beyond, evaluated at 256 bits; normInv by Newton on the reference normCdf; lgamma by Stirling with enough Bernoulli terms). Generate and commit vectors for sin, cos, atan, atan2, erf, erfc, normCdf, normInv, lgamma; extend golden.sha256 to cover them.

# SPEC EXCERPTS (verbatim; binding game rules)

**[02 §1 Purpose]** (context)

## §1 Purpose

The world of TYCOON is one persistent, deterministic simulation that advances in discrete **ticks** of 5 real seconds. This module defines:

1. **The clock and calendar**: how a tick maps to a game date, time of day, trading phase, week, month, quarter, year and chapter, plus the holiday calendar of each bloc and what happens at every boundary.
2. **The tick pipeline**: the 15 phases P0 to P14 of 00 §5.2, how they run across invisible partitions, their time budgets, and what happens when a tick fails (rollback, safe mode).
3. **The pure `step()` contract**: the world advances only through a pure function of (state, sealed intents, entropy). No module may read the wall clock, a random source, the network or the disk inside `step()`.
4. **Determinism**: the coding rules, the deterministic math library, the fixed-point conversions (`toMoney` and friends), and the RNG streams (xoshiro128**, one stream per purpose and subject).
5. **Provable fairness**: commit-reveal entropy and fair intra-tick ordering, so the operator can prove it never rigged an outcome and no player can predict one.
6. **Persistence of time**: snapshots, event sourcing, replay, audit, versioning, catch-up when the server lags, clock drift, and maintenance in a world that never resets.

Design goals, in priority order: (a) the same inputs always give bit-identical outputs on any machine running the same engine version; (b) no player can gain anything from latency, device, timing or knowledge of the server; (c) a tick never commits partially; (d) the 5-second rhythm holds at 100k concurrent players and 750k AI agents (00 §5.7, 02-multiplayer §1).

### §3.8 Deterministic math library (`dmath`)

`dmath` implements every transcendental function from `+ - * /` and `Math.sqrt` only, with fixed argument reduction and fixed polynomial or rational approximations, so results are bit-identical everywhere. Required functions and accuracy targets (max error in ULPs over the stated domain; test vectors in 20):

| Function | Domain | Method (fixed) | Max error |
|---|---|---|---|
| `exp(x)` | [-745, 709] | reduce `x = k ln2 + r`, `|r| <= ln2/2`, degree-13 Taylor/Horner on r, scale by `2^k` via exponent bit construction | 2 ULP |
| `ln(x)` | (0, +inf) | split mantissa/exponent from bits, `m` in [sqrt(1/2), sqrt(2)), `s = (m-1)/(m+1)`, odd series to s^21 | 2 ULP |
| `log2(x)`, `log10(x)` | (0, +inf) | `ln(x) * const` | 3 ULP |
| `pow(x, y)` | x > 0 | `exp(y * ln(x))` with extra-precision product (Dekker two-product) | 4 ULP |
| `sin, cos` | [-1e6, 1e6] | Cody-Waite reduction by pi/2 (3-part constant), minimax polynomials | 2 ULP |
| `atan2, atan` | all | reduction to [0, tan(pi/12)] + series | 3 ULP |
| `tanh, sigmoid` | all | from `exp`; `sigmoid(x) = 1/(1+exp(-x))`, symmetric form for x < 0 | 3 ULP |
| `erf, erfc` | all | W. J. Cody rational approximations | 4 ULP |
| `normCdf(x)` | all | `0.5 * erfc(-x / sqrt2)` | 4 ULP |
| `normInv(p)` | (0,1) | Wichura AS241 (PPND16) | 1e-15 relative |
| `lgamma(x)` | x > 0 | Lanczos g=7, n=9 | 1e-14 relative (except [0.5, 3.0]: see exception 3) |
| `expm1, log1p` | all | dedicated series near 0 | 2 ULP |

**Named exceptions to the table (E-63, Quant 2026-10-21; E-63.7 adds the third):** (1) `normCdf(x)` for x < 0: relative error ≤ 5e-13. Rounding of −x/√2 is amplified by about 850 ULP in the tail, an inherent cost of the `0.5·erfc(−x/√2)` form. (2) `erfc(x) = 0` exactly for x > 26.543 (Cody XBIG; the true value is subnormal), and likewise `normCdf(x) = 0` for x < −26.543·√2. (3) `lgamma(x)` (E-63.7): ≤ 1e-14 **absolute** on [0.5, 3.0] and ≤ 1e-14 relative elsewhere for x > 0; `lgamma(1) == lgamma(2) == 0` exactly. Absolute error is used near the zeros at 1 and 2 because relative error is unbounded there. This supersedes the row's "1e-14 relative" on [0.5, 3.0]. Everything else, including erf/erfc at the 0.5 region split, is held to the table.

Note (errata E-53): the accuracy bounds and the domains in this table are the contract; the algorithm column is guidance. The ratified deviations (double-double ln for pow, log2 and log10, double-double squaring for integer powers, compensated 1 + r in exp, hi/lo constants) and `ln(+inf)` → `I0.overflow` are in E-53 and T02-02.

Additional fixed algorithms in `dmath`: `kahanSum`, `clamp`, `lerp`, Black–Scholes price and greeks (06 uses them; implemented on `dmath.normCdf`), `solveBisection(f, a, b, iters)` with a **fixed iteration count** (never "until converged"), `newton(f, df, x0, iters)` with fixed iteration count, matrix ops for small dense matrices (Cholesky for correlation, fixed loop order). Any new math function must be added to `dmath` with test vectors before a module uses it.
