## G4. Time (00 §5.1)

5 real seconds per tick; 720 ticks per game day (= 1 real hour); 30 ticks per game hour; one tick = 2 game minutes. Week = 7 game days (Mon–Fri trading, Sat–Sun weekend). Quarter = 13 weeks = 91 game days, months 28/28/35 days. Year = 364 game days = 262,080 ticks. Chapter = 8 real weeks = 1,344 game days. Real day = 24 game days.
Trading day tick-of-day `t`: pre-market 0–59; opening auction t=60; continuous 61–539; closing auction t=540; after-hours 541–719. Accruals (interest, rent, wages, fees) post at day close t=719. Business operations run once per game hour, staggered: an entity runs when `tickOfDay mod 30 == fnv1a32(id) mod 30`.

## G5. Tick pipeline (00 §5.2)

```
P0 ingest  P1 validate  P2 calendar  P3 world(16)  P4 npc(05,16)  P5 ai(11)  P6 match(05,06)
P7 clear(07)  P8 finance(07,08)  P9 real(09,10)  P10 conflict(12)  P11 law(13)  P12 social(14,15)
P13 ledger(03: commit postings atomically, settle/release holds, assert invariants)  P14 emit
```
A phase may read any committed state and the outputs of earlier phases of this tick; it writes only its own module's tables and queues postings for P13. Postings never commit before P13. A failed invariant rolls the tick back and replays it in safe mode. Consequences of tick N that other modules react to land in tick N+1 (via `ctx.send(..., 'NEXT')` or events).

### G6.1 Ports for later modules (dependency inversion)

A module may never import a module built after it. When its rules need data from a later module (for example 05 needs fundamental values from 09 or index weights from 08), it declares a **port**: a TypeScript interface in its own `ports.ts` (e.g. `MarketPorts`), and its factory takes the implementations: `createMarketsModule(ports: Partial<MarketPorts>)`. The later module exports an implementation of that port, and `packages/engine/index.ts` wires them when building the world. A missing port uses the default the spec gives for "module not present" (stated in the card), never an invented rule.

## G8. Determinism rules (02 §3.7, 19 Rule 3.6.2) — lint-enforced in packages/engine

Forbidden in engine code: `Date`, `performance`, `Math.random`, `crypto` randomness, timers, `process`, `globalThis`, `Intl`, `toLocaleString`, `localeCompare`, `async/await`/Promises, `for…in`, iterating `Object.keys/values/entries` of map-like objects, `Map`/`Set` iteration where order matters (use `SortedMap`/`SortedSet`), `Array.sort` without a total comparator (use `sortBy`), `JSON.stringify` for hashing/persistence (use `canonEncode`), `WeakMap/WeakRef`, `Math.exp/log/pow/sin/cos/tan/atan2/cbrt/hypot/...` (use `dmath`), `Math.round` (use `roundHalfEven`), `Number` for money or quantities. Allowed raw math: `+ - * /`, `Math.sqrt/abs/floor/ceil/trunc/min/max/sign/fround/imul/clz32`.
NaN/Infinity are illegal in state. Ties are broken by entity id then intent id. Iterate collections only in sorted order. Rejection sampling is forbidden; each variate uses a fixed number of draws. A module may draw only from its own streams. Split money into parts only with `allocate`. No exceptions for control flow: report impossible states with `ctx.fail`.

## Goal
The central bank's balance-sheet tools beyond the corridor. QE starts at the lower bound or in market dysfunction, buys bonds through 05 as real orders under holdings caps, tapers to HOLD and runs off in QT; its stock lowers the term premium. PYN's yield curve control defends a 10y cap with a real resting bid that breaks visibly when capacity runs out. FDL provides swap lines that floor the cross-currency basis. An LTRO window opens in emergencies. Macroprudential settings (countercyclical buffer, LTV and DTI caps) that 07 and 10 apply. All CB, treasury and Concord orders go to 05 as `NpcPoolOrder` rows each tick (§6.3); foreign reserve managers rebalance quarterly (§6.4); CB profits are remitted to the treasury each quarter.

## Implementation steps
1. **QE start (§3.8.5)**, evaluated in `runMeeting` (scheduled and emergency): ELB mode when `i = elb` and `i* < elb − 0.005`; DYSFUNCTION mode when `FSI > 0.6` and `cb.lowDepthDays ≥ 3` (`lowDepthDays` = consecutive trading days with `ports.markets.bondDepthIndex(store, b, false) < 0.5`, updated at day close). Size `purchasesSize`; eligible mix `{ govBonds: 1 }`, or `{ govBonds: 0.8, corpIG: 0.2 }` when FSI > 0.5, and during an active SECURITIZATION_CRISIS (T04-18 active major kind) `abs: 0.1` taken from corpIG. Emit `macro.cb.tool` `QE_START` with the size. Edge 1: ELB plus a rule asking for more easing means QE; the rate stays at `elb`.
2. **Taper, hold, QT.** At a meeting with state QE and `i* > elb + 0.0025` → HOLD (`QE_HOLD`): maturing face is reinvested, no net purchases. QT when `i ≥ r*_cb + π* − 0.005` and holdings > 0 (`QT_START`): maturing face runs off up to `qtRunoffCapPerMonth = 0.015` of holdings (excess maturing face reinvested); active sales only for PYN, up to 0.005 of holdings per month (FDL, EUN, NKR, SRL none).
3. **Holdings and caps.** Holdings per line = `ctx.ledger.position(cbkId(b), line)` (authoritative; 06 pays coupons and principal to the CB as holder). Value at 05 fair price (`fairPriceOf`, fallback 03 mark). `gdpShare = total / nominalGdp`, feeds T04-07's `qeHoldingsGdp`. Caps: total ≤ `holdingsCapGdp = 0.35` of GDP; per line ≤ 50% of outstanding face (`lineCapRoom`). `dailyProgram`: gov lines = `ports.assets.sovereignLines(govId)` with remaining maturity 2 to 30 years, pro rata to outstanding face; corporate and ABS lines from `ports.assets.qeEligibleLines`; daily amount = (monthly target − bought so far this month) ÷ trading days left in the game month (FDL-free, local currency face converted with the line price). Clip each line to its cap room and the total cap. 
4. **Pool orders (§6.3), P4 every tick.** `writePoolOrders` writes `mac.pool_order` rows for this tick (05 reads them with T04-20 `npcPoolOrders(store, tick)`): QE/QT slices per line on each continuous session tick (`sessionState` of the bond family for the bloc; t = 61..539 on trading days), `qty = sliceOfDay(remaining face of the day, session ticks left)`, also ≤ 10% of the line's ADV per tick (`ports.markets.lineAdv`), `tif: 'TICK'` (IOC), `limitPrice = iocLimit(fair, makerHalfSpread, side)`; unfilled face rolls into the next tick's remaining and into the month's remaining (never chases price). Rows are deleted the next tick after `applyPoolFills` has read the fills. Purposes `QE`, `QT`, `YCC`, plus FX and CSF orders T04-14 passes in (`FX_BAND`, `FX_LEAN`, `FX_COORD`, `FX_PEG`, `BACKSTOP`) and `RESERVE_REBAL`. Fills post through 05 as `MKT_TRADE` (TRANSFER); 04 posts nothing for QE trades.
5. **YCC (§3.8.6),** bloc `macro_ycc_bloc` (default PYN, the 04 alias PL). Start at day close of a trading day when `i = elb` and `y10 − i > 0.01` for 10 consecutive trading days (`cb.ycc10Streak`): `capYield = i + 0.005`, `YCC_START`. Each tick while active: `yccBid` = resting BUY on the on-the-run 10y at `priceFromYield(line, capYield)`, size `2 × lineAdv` replenished each tick, bounded by `capacityFace` = min(total-cap room, line-cap room). Edge 20: when capacity is below the size, the bid shrinks to it; at zero capacity no bid is posted, the yield can exceed the cap, and 04 writes a `HookCall { owner: '16', hook: 'WIRE_ITEM', args: { key: 'ycc_under_pressure', bloc } }` once per episode (E-105: through T04-18 `writeHook`, worldEventId `ycp_<B>_<⌊tick / 720⌋>`). Exit: `π_core > π* + 0.005` for 63 trading days (`yccHighInflDays`) → at each following meeting raise the cap 0.0025 (`YCC_RAISE`); after two raises remove it (`YCC_END`); if removed while holdings are at a cap, `credibilityOneOff('YCC_ABANDON')` (−0.10).
6. **Swap lines (§3.8.7).** `cb_FDL.swapLinesOut` to EUN, NKR, PYN with limit `0.03 × nominalGdp_X × spot_X` (FDL); SRL only while a Concord program is ACTIVE. Activation at day close when `basis_X < −0.004` or `FSI > 0.6` (`SWAPLINE_ON`); deactivation (unit decision, 04 gives none) when neither holds for 10 consecutive trading days and `drawn = 0` (`SWAPLINE_OFF`). Rate = FDL `oisZero(1/364)` + 0.0025; banks pay +0.0010 when 07 on-lends. 07 sends `mac.swap.draw { bloc, amount }` / `mac.swap.repay` to `cbkId(X)` (NEXT); `handleSwapDraws` checks the limit and posts `ledger.fx(cbk_FDL, cbk_X, 'FDL', amt, ccy_X, amt × spot, 'CBK_SWAP_LINE_DRAW')` (TRANSFER, registered here; repay `CBK_SWAP_LINE_REPAY`), and interest daily `CBK_SWAP_LINE_INTEREST` (TRANSFER) X → FDL. While active, T04-07's basis is floored at −0.0025.
7. **LTRO window.** `openLtro` from an emergency meeting (T04-06, 28 game days, unit decision) or for the length of a major crisis POLICY phase (T04-18), sets `cb.ltroOpenUntilTick`; emits `LTRO_OPEN`. T04-08's `bank.cb.repo` accepts 91-day terms only while open.
8. **Macroprudential (§3.8.8).** At scheduled meetings: `ccyb` target; an increase is stored as `ccybPending { value, effectiveTick = now + 91 × 720 }` and applies at that tick; decreases at meetings apply immediately. Releases to 0 at any day close when the bloc's regime is CONTRACTION or `FSI > 0.5` (`macroprudentialRelease`), cancelling a pending increase. LTV: residential 0.80, −0.05 when housePriceGap > 0.15, −0.10 when > 0.30; commercial 0.65, −0.05 when creditGap > 0.06; DTI 0.40. Emits `CCYB_CHANGE`, `LTV_CHANGE` (PUBLIC). 07 and 10 read them through T04-20 (`ccyb(store, bloc)`, `macroprudential(store, bloc)`). Crisis lending standards (CREDIT_CRUNCH −20 LTV points) are 07's, not here.
9. **Reserve managers (§6.4).** Each CB's FX reserves (`cb.reserves`) target: FDL bonds 0.60, EUN 0.20, gold 0.10, NKR 0.05, PYN 0.05 of reserve value; the bucket of the CB's own currency is dropped and the rest renormalized (FDL's own CB therefore holds 0.5 EUN, 0.25 gold, 0.125 NKR, 0.125 PYN). The FDL bucket holds FDL cash and FDL government bonds of 2 to 10 years; FX intervention (T04-14) spends the FDL cash first. At the first trading day of each quarter `reserveRebalanceOrders` computes the gap per bucket at fair value and writes `RESERVE_REBAL` orders spread evenly over 5 trading days (IOC at the §6.3 limit). These are what give FDL its reserve-currency bid; they are public in aggregate through `macro.fx.intervention.daily` (T04-14).
10. **Profit remittance (§3.8.5 last bullet).** At QUARTER close, `remitProfit`: CB net income = −Σ `periodNet` over the cbk's income (4xxx) and expense (5xxx) accounts for the quarter (coupons received, facility interest, IOR paid, deposit interest paid); if positive, `ledger.pay(cbkId, govId, amount, ccy, 'CBK_PROFIT_REMITTANCE')` (03 canonical; 04 §3.18's `CBK_PROFIT_REMIT` is its alias); losses are retained.
11. **Codes registered by this card:** `CBK_SWAP_LINE_DRAW`, `CBK_SWAP_LINE_REPAY`, `CBK_SWAP_LINE_INTEREST`, all TRANSFER (world-internal, cbk to cbk), template FX for draw/repay and PAY for interest.
12. `testing/marketStub.ts`: a deterministic stub of 05 for 04's tests: one line, an exogenous NPC sell flow per tick, a single-price clearing of the resting and IOC pool orders against it, yield from the clearing price via a supplied price/yield function; exposes `poolFills` and `lineYield` for the ports.

**[04 §1 Purpose]** (context)

## §1 Purpose

The macro layer is the one shared state every price, business, loan and property in the world reads (V3 Part 2.4). It exists so that:

1. **Prices have reasons.** A rate hike, a CPI surprise, a downgrade or a currency defence hits bonds, mortgages, growth stocks, bank margins, cap rates, carry trades and leveraged funds on the same tick, through named transmission channels that the "Why it moved" ladder (05 §3.12) can cite.
2. **Recessions are caused, not random** (old 01 §5.3). Imbalances (credit growth, valuation stretch, an inverted curve, tight real rates, oil shocks) raise the hazard of a downturn, so a careful player can see one building.
3. **Central banks, treasuries and sovereign bond markets are real machinery** (V3 Part 3.2): policy rates with a corridor, reserves, standing facilities, asset purchases, forward guidance, deficits that are financed by auctions, debt that can be downgraded and restructured, currencies that can be defended and can break.
4. **Crises emerge from rules** (V3 T2) and also arrive on a calibrated schedule so the world has rhythm (one major crisis in about 35% of chapters, storms every game quarter, ripples every game week).
5. **The money stays honest.** The Stabilizer controller keeps the player economy on its designed path, and the Money Supply Index deflates rankings so inflation cannot pump rank (old 01 §8.2–8.3).

#### §3.8.5 Asset purchases (QE) and runoff (QT)
- **Start QE** at a meeting (or emergency meeting) when `i = elb` and `i* < elb − 0.005`, or when `FSI > 0.6` and 05's bond market depth index for the bloc stays below 0.5 for 3 trading days ("market dysfunction" purchases).
- Size: `purchasesPerMonth = clamp(0.0025 × (elb − i*)/0.01, 0.0025, 0.015) × nominalGdp_b`, with a 0.005 × GDP floor in dysfunction mode. Eligible mix: govBonds 0.8, corpIG 0.2 when FSI > 0.5 (else govBonds 1.0); ABS only during a SECURITIZATION_CRISIS (0.1, taken from corpIG).
- Execution (05 §6.2, CB pool): daily amount = monthly ÷ trading days in the game month; split across bond lines pro rata to outstanding with maturity 2–30 years; executed as patient buy orders across the session at participation ≤ 10% of each line's ADV per tick. Caps: total holdings ≤ `holdingsCapGdp = 0.35` of GDP; ≤ 50% of any one line's outstanding face.
- Stock effect on the term premium (§3.7.4): −2.5 bp per 1% of GDP held.
- **Taper and hold:** when `i* > elb + 0.0025`, state → HOLD (maturities reinvested, no net purchases).
- **QT:** when `i ≥ r*_cb + π_target − 0.005` and holdings > 0: no reinvestment of maturing bonds, capped at `qtRunoffCapPerMonth = 0.015` of holdings; active sales none (FU, EC, NA, SC) or up to 0.5% of holdings per month (PL).
- QE trades are ordinary trades at market prices (TRANSFER); the CB pays with new reserves. Coupons on CB holdings go to the CB, which remits its profit to its treasury at each quarter end (world-internal TRANSFER).

#### §3.8.6 Yield curve control (PL by default, `PARAM.macro_ycc_bloc = 'PL'`)
- Start when PL's policy rate is at ELB and `y10 − i > 0.01` for 10 consecutive trading days: cap `capYield = i + 0.005`.

#### §3.6.4 Decision at a scheduled meeting
1. Recompute `i*` at the meeting tick.
2. `Δraw = ρ × (i* − i)`.
3. If `|Δraw| < 0.00125` (12.5 bp): hold.
4. Else `Δ = 0.0025 × roundHalfEven(Δraw / 0.0025)`, clamped to ±0.0050, or ±0.0075 when `|i* − i| ≥ 0.02` (`PARAM.macro_cb_max_step = 0.005`, `PARAM.macro_cb_max_step_wide = 0.0075`).
5. `i_new = max(elb_b, i + Δ)`.
6. QE/QT and YCC decisions (§3.8.5, §3.8.6) are taken at the same meeting.
7. Votes: 9 members, each with a fixed offset `o_j ~ N(0, 0.15)` drawn at appointment. Member preference = the rule rate computed with `hawk + o_j`, smoothed the same way. A member votes FOR if `|pref_j − i_new| ≤ 0.0025`, else AGAINST. The tally is in the decision; the direction of dissent ("two members preferred a larger hike") appears in the minutes. This is the main public clue to hidden hawkishness.
8. Emit `macro.cb.decision` (PUBLIC) with the new corridor rates, statement key (chosen from 16's template library by: direction, size, guidance match, dominant `ruleTerms` component) and reasons.

## §8 Edge cases

1. **Policy at the ELB and the rule wants more easing:** rate stays at `elb`; QE logic (§3.8.5) takes over; guidance score is clamped at −1.
2. **Negative rates:** only EC and NA; the deposit facility rate can go negative, reversing the `CBK_DEPOSIT_INTEREST` direction (a charge, class SINK for player banks). 07 passes negative rates to deposits only for corporate deposits above 10M (DEFAULT).
3. **Hyperinflation guard:** `π_core` clamps at 60%; at > 25% for 91 days the hard-peg option opens (§3.13.5); CPI levels are floats (no overflow).
4. **Deflation:** `π_core` floors at −5%; real rates rise mechanically; the rule cuts toward ELB.
5. **A release day with a market-wide halt:** the release still publishes; 05 queues orders; the reopening auction absorbs it.
6. **Weekends:** macro day steps still run (state evolves); releases, meetings and auctions are on trading days only; FX regime breaks happen at the next `t = 45` of a trading day, except SC capital controls, which can start on a weekend day close if a weekend crisis trigger fires (crypto-driven contagion).
7. **Meeting on a day with an emergency already held that week:** the scheduled meeting still occurs; the emergency count resets each quarter.
8. **Two triggers on the same day close:** process in the fixed order of §3.1; only one major can be active; an emergent label during an active major is attached to it as a sub-phase rather than a second major.
9. **Chapter boundary inside a crisis:** crises continue; the chapter counters reset; the scheduler's "final 48 game days" rule applies only to new triggers.
10. **Auction with no player bids:** NPC ladder alone clears it; results are still published.
11. **Auction award rounding:** pro-rata remainders in lots go in hash order; the sum of awards never exceeds offered.
12. **A bidder's cash hold fails at settlement** (cannot happen because the hold is taken at submission; if a hold is released by 13 for a Held character, the bid is cancelled at P1 of the auction tick and the auction clears without it).
13. **Capital controls while a player holds SRL cash and an FDL margin call (07):** margin calls in another currency are met from that currency first; if impossible, 07 liquidates FDL positions; SRL cannot be converted at level ≥ 2. This is intended crisis risk and shown on the margin forecast (RSK-03).
14. **Restructuring vote by a holder whose bonds are lent out (07 securities lending):** the vote belongs to the borrower holding the bonds at the snapshot (as in real markets); lenders can recall before the snapshot.
15. **Bonds pledged as CB repo collateral when the line is restructured:** the CB revalues the new bonds; if collateral is short, 07 calls for top-up within 1 game day.
16. **Default of a bloc whose bonds are CCP collateral:** 07 haircut tables react through grades; no special rule.
17. **N_a collapses (world empties):** scale shrinks at most 0.5% per game day and floors at 0.2; nominal quantities shrink smoothly; outstanding debts are not rescaled (only flows and pools scale), so debt/GDP rises if the world shrinks fast, which is reported but capped in hazard z1 by the clamp.
18. **No 07 yet (early builds and unit tests):** the §3.14.4 fallback provides credit inputs; facility intents return `CBK_NOT_ELIGIBLE`.
19. **Release measurement noise moves a print across a threshold** (e.g. the Cycle Committee condition): the committee reads published prints, so noise can delay or hasten a declaration; this is intended.
20. **YCC and QE caps both binding:** the YCC bid shrinks to the remaining capacity; the cap can break; Wire item "YCC under pressure".
21. **Peg break while players hold FX forwards (06):** forwards settle at market; no special rule.
22. **Two blocs meet within the same tick** (cannot happen by calendar; meetings are on distinct trading days of the quarter).
23. **Missing input from another module this day:** last value holds; the event log records `macro.input.stale` (internal) for 20.
24. **Stabilizer with a tiny population:** OBSERVE mode below 03's `PARAM.stab_min_sample` engaged characters (03 §3.7.5); MSI per 03 §3.8.
25. **Stabilizer lever at a bound for more than 14 real days:** emits an internal alert to 21's admin console and 20; no automatic widening (Mathis or live-ops decide).
