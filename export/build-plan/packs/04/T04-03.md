## G4. Time (00 §5.1)

5 real seconds per tick; 720 ticks per game day (= 1 real hour); 30 ticks per game hour; one tick = 2 game minutes. Week = 7 game days (Mon–Fri trading, Sat–Sun weekend). Quarter = 13 weeks = 91 game days, months 28/28/35 days. Year = 364 game days = 262,080 ticks. Chapter = 8 real weeks = 1,344 game days. Real day = 24 game days.
Trading day tick-of-day `t`: pre-market 0–59; opening auction t=60; continuous 61–539; closing auction t=540; after-hours 541–719. Accruals (interest, rent, wages, fees) post at day close t=719. Business operations run once per game hour, staggered: an entity runs when `tickOfDay mod 30 == fnv1a32(id) mod 30`.

## G5. Tick pipeline (00 §5.2)

```
P0 ingest  P1 validate  P2 calendar  P3 world(16)  P4 npc(05,16)  P5 ai(11)  P6 match(05,06)
P7 clear(07)  P8 finance(07,08)  P9 real(09,10)  P10 conflict(12)  P11 law(13)  P12 social(14,15)
P13 ledger(03: commit postings atomically, settle/release holds, assert invariants)  P14 emit
```
A phase may read any committed state and the outputs of earlier phases of this tick; it writes only its own module's tables and queues postings for P13. Postings never commit before P13. A failed invariant rolls the tick back and replays it in safe mode. Consequences of tick N that other modules react to land in tick N+1 (via `ctx.send(..., 'NEXT')` or events).

### G6.1 Ports for later modules (dependency inversion)

A module may never import a module built after it. When its rules need data from a later module (for example 05 needs fundamental values from 09 or index weights from 08), it declares a **port**: a TypeScript interface in its own `ports.ts` (e.g. `MarketPorts`), and its factory takes the implementations: `createMarketsModule(ports: Partial<MarketPorts>)`. The later module exports an implementation of that port, and `packages/engine/index.ts` wires them when building the world. A missing port uses the default the spec gives for "module not present" (stated in the card), never an invented rule.

## G8. Determinism rules (02 §3.7, 19 Rule 3.6.2) — lint-enforced in packages/engine

Forbidden in engine code: `Date`, `performance`, `Math.random`, `crypto` randomness, timers, `process`, `globalThis`, `Intl`, `toLocaleString`, `localeCompare`, `async/await`/Promises, `for…in`, iterating `Object.keys/values/entries` of map-like objects, `Map`/`Set` iteration where order matters (use `SortedMap`/`SortedSet`), `Array.sort` without a total comparator (use `sortBy`), `JSON.stringify` for hashing/persistence (use `canonEncode`), `WeakMap/WeakRef`, `Math.exp/log/pow/sin/cos/tan/atan2/cbrt/hypot/...` (use `dmath`), `Math.round` (use `roundHalfEven`), `Number` for money or quantities. Allowed raw math: `+ - * /`, `Math.sqrt/abs/floor/ceil/trunc/min/max/sign/fround/imul/clz32`.
NaN/Infinity are illegal in state. Ties are broken by entity id then intent id. Iterate collections only in sorted order. Rejection sampling is forbidden; each variate uses a fixed number of draws. A module may draw only from its own streams. Split money into parts only with `allocate`. No exceptions for control flow: report impossible states with `ctx.fail`.

## Implementation steps
1. Regime step per bloc in `BLOC_ORDER`, global first (§3.19 draw order), at day close (T04-20 calls it as macro step 3):
   1. `daysIn = (cal.gameDay − floor(regimeSinceTick/720))`. If `daysIn < min_s` no transition, but still consume the 2 draws (G8 fixed draw count): `u1 = rng.next()`, `u2 = rng.next()`.
   2. `λ_s = 1/(mean_s − min_s)`; `M` from `transitionMultipliers(s, z)`; for blocs, `applyCoupling` with the global regime of today (global chain runs first): global CONTRACTION ⇒ `M[CONTRACTION] ×= exp(0.6·cycleCoupling_b)`; global RECOVERY or EXPANSION and bloc in CONTRACTION ⇒ `M[RECOVERY] ×= exp(0.4·cycleCoupling_b)`.
   3. `H = λ_s × Σ_{s'} P_base(s→s')·M(s→s')`; transition iff `u1 < 1 − exp(−H)` (`dmath.exp`).
   4. Target: cumulative weights `P_base·M` over `ALLOWED[s]` in that fixed order, pick the first with `u2·Σ < cum`.
   5. Streams: bloc `S.regime(b)`, global `S.globalRegime()`.
   6. On transition: `regime = s'`, `regimeSinceTick = ctx.tick`. Forced transitions (crisis hook "force CONTRACTION", T04-18) call `forceRegime` and log the crisis id in the WorldEvent cause chain.
2. Imbalances (§3.3.3) exactly per table: credit `creditGap/0.05`; valuation `ln(peAgg/peNorm)/0.25` (0 if peAgg missing); curve: if `y10 − y3m < 0`: `inversionDays/63 + (y3m − y10)/0.005` else −0.5; inflation `(core − target)/0.015`; house `gap/0.15`; oil `ln(E_t/E_{t−63})/0.30 × (1 − 2·max(0, commodityExporter))`; fiscal `stress/0.25`; fear `(F − 50)/20`; contagion `(share − 0.2)/0.2`; policy `R̃/0.015`; overheat `x/0.01`; trade `−ln(WTI_t/WTI_{t−182})/0.05`; stimulus `(−R̃ + FI)/0.01`. Clamp each to [−3, 4] at storage. `otherBlocsContractionGdpShare` = Σ gdp share (current nominal GDP in FDL) of the other four blocs whose true regime is CONTRACTION. `peNorm` = 5-game-year trailing mean of `peAgg` (T04-20 keeps it in history), genesis value from 22 (`peNorm0`).
   The global chain uses `globalZ` = GDP-weighted average of the five bloc z vectors.
3. Cycle Committee (§3.3.6), every day close per bloc after the regime step: if `trueRegime ≠ label` and `daysInTrue ≥ macro_cycle_label_lag_days` (21) and the data condition holds, set label = trueRegime and emit `macro.cycle.declared` (PUBLIC, bloc, regime, sinceDay). Data conditions use published prints only: CONTRACTION needs latest GDP_ADV/REV q/q annualized `< 0` (the most recent of GDP_ADV, GDP_REV1, GDP_REV2 by tick) or latest JOBS unemployment ≥ 12-month low + 0.005; EXPANSION or RECOVERY: latest growth print > 0; OVERHEATING: latest CPI core ≥ target + 0.01 and latest unemployment < NAIRU. Label is `UNDETERMINED` from genesis until the first declaration. Edge 19 (noise moves a print across a threshold) is intended: no smoothing.
4. Effects of the regime (§3.3.5): this task only exposes the regime; `x_reg` is consumed in T04-04, 05 reads `getBlocRegime` (T04-20 api), 07 reads it through the same api.

**[04 §1 Purpose]** (context)

## §1 Purpose

The macro layer is the one shared state every price, business, loan and property in the world reads (V3 Part 2.4). It exists so that:

1. **Prices have reasons.** A rate hike, a CPI surprise, a downgrade or a currency defence hits bonds, mortgages, growth stocks, bank margins, cap rates, carry trades and leveraged funds on the same tick, through named transmission channels that the "Why it moved" ladder (05 §3.12) can cite.
2. **Recessions are caused, not random** (old 01 §5.3). Imbalances (credit growth, valuation stretch, an inverted curve, tight real rates, oil shocks) raise the hazard of a downturn, so a careful player can see one building.
3. **Central banks, treasuries and sovereign bond markets are real machinery** (V3 Part 3.2): policy rates with a corridor, reserves, standing facilities, asset purchases, forward guidance, deficits that are financed by auctions, debt that can be downgraded and restructured, currencies that can be defended and can break.
4. **Crises emerge from rules** (V3 T2) and also arrive on a calibrated schedule so the world has rhythm (one major crisis in about 35% of chapters, storms every game quarter, ripples every game week).
5. **The money stays honest.** The Stabilizer controller keeps the player economy on its designed path, and the Money Supply Index deflates rankings so inflation cannot pump rank (old 01 §8.2–8.3).

### §3.3 Business cycle regimes

#### §3.3.1 Base chain (old 01 §5.3, docs/ENGINE.md, converted to the 364-day year)

| From | To (base probability) | Mean length (game days) | Minimum length |
|---|---|---|---|
| EXPANSION | OVERHEATING 0.80, CONTRACTION 0.20 | 819 (2.25 game years; band 1.5–3) | 182 |
| OVERHEATING | CONTRACTION 0.85, EXPANSION 0.15 (soft landing) | 273 | 63 |
| CONTRACTION | RECOVERY 1.00 | 273 | 91 |
| RECOVERY | EXPANSION 0.90, CONTRACTION 0.10 (double dip) | 273 | 91 |

Parameters: `PARAM.macro_regime_mean_days_{exp,ovh,con,rec}` and `PARAM.macro_regime_min_days_{…}` as in the table.

#### §3.3.2 Daily transition algorithm (per bloc, and once for the global chain)

1. If days in regime `< min_s`, no transition.
2. Base hazard `λ_s = 1 / (mean_s − min_s)` per game day.
3. For each allowed target `s'`: multiplier `M_{s→s'} = exp( Σ_k w_{s→s',k} · clamp(z_k, −2, 3) )` (weights §3.3.4).
4. For a bloc (not the global chain), coupling: if the global regime is CONTRACTION, `M_{s→CONTRACTION} ×= exp(0.6 × cycleCoupling_b)`; if the global regime is RECOVERY or EXPANSION and the bloc is in CONTRACTION, `M_{CONTRACTION→RECOVERY} ×= exp(0.4 × cycleCoupling_b)`.
5. Total hazard `H = λ_s × Σ_{s'} P_base(s→s') × M_{s→s'}`. Draw `u ~ U(0,1)` from `macro:<bloc>:regime`. Transition if `u < 1 − e^(−H)`.
6. If transitioning, choose `s'` with probability `P_base(s→s') × M_{s→s'} / Σ`. A second draw from the same stream picks it.
7. A crisis shock may force a regime (§3.16.6 "force CONTRACTION"); a forced transition ignores the minimum length and is logged with the crisis id.

#### §3.3.3 Imbalance z-scores (computed at day close, step 1 of the macro step)

| Key | Formula | Source |
|---|---|---|
| `credit` | `creditGap / 0.05` | 07 aggregates (§3.14.4) |
| `valuation` | `ln(PE_agg_b / PE_norm_b) / 0.25`, PE of the bloc's equity index | 05 prices, 06/09 earnings; `PE_norm_b` = 5-game-year trailing mean, genesis value from 22 |
| `curve` | if `y10 − y3m < 0`: `(inversionDays/63) + (y3m − y10)/0.005`, else `−0.5` | §3.7 |
| `inflation` | `(coreInflation − π_target)/0.015` | §3.5 |
| `house` | `housePriceGap / 0.15` | 10 |
| `oil` | `ln(energyIndex_t / energyIndex_{t−63})/0.30` (sign flipped for exporters: `× (1 − 2·max(0, commodityExporter))`) | 06 |
| `fiscal` | `sovereign.stressIndex / 0.25` | §3.11 |
| `fear` | `(F − 50)/20` | §3.14 |
| `contagion` | `(share of world GDP of other blocs in CONTRACTION − 0.2)/0.2` | §3.3 |
| `policy` | `realRateGapSmoothed / 0.015` (positive = tight) | §3.4.1 |
| `overheat` | `outputGap / 0.01` | §3.4 |
| `trade` | `−ln(WTI_t / WTI_{t−182})/0.05` | §3.14 |
| `stimulus` | `(−realRateGapSmoothed + fiscalImpulse)/0.01` | §3.4, §3.9 |

All z are clamped to [−3, 4] at storage. The global chain uses the GDP-weighted average of bloc z.

| REC→EXP | stimulus 0.2, fear −0.2 |
| REC→CON | fear 0.4, policy 0.4, contagion 0.5 |

#### §3.3.5 Effects of the regime
- **On the economy** (04): the attractor gap `x_reg` (§3.4.1).
- **On prices** (05 §3.3): volatility, jump intensity, jump skew, crisis correlation multipliers keyed by the bloc regime (05 owns the multiplier table).
- **On credit** (07): NPC bank lending standards drift looser in EXPANSION and OVERHEATING, tighter in CONTRACTION (V3 3.1 credit cycle; 07 owns the rule, 04 supplies the regime).

#### §3.3.6 Public cycle label (the Cycle Committee)
The true regime is hidden. Each bloc's statistics office has a Cycle Committee (name in 22). At each day close, the label changes to the true regime `s` when all hold: (a) the true regime has lasted ≥ `PARAM.macro_cycle_label_lag_days = 21` game days; (b) for CONTRACTION: the latest published GDP_ADV or GDP_REV q/q annualized growth is below 0, or published unemployment is ≥ 0.5 pp above its 12-month low; for EXPANSION or RECOVERY: the latest published growth is above 0; for OVERHEATING: published core CPI ≥ target + 1 pp and published unemployment below NAIRU. Until a regime is declared after genesis, the label is `UNDETERMINED`. Event `macro.cycle.declared` (PUBLIC). Reading the regime before the committee does is a research skill.
