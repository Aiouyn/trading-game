## G4. Time (00 §5.1)

5 real seconds per tick; 720 ticks per game day (= 1 real hour); 30 ticks per game hour; one tick = 2 game minutes. Week = 7 game days (Mon–Fri trading, Sat–Sun weekend). Quarter = 13 weeks = 91 game days, months 28/28/35 days. Year = 364 game days = 262,080 ticks. Chapter = 8 real weeks = 1,344 game days. Real day = 24 game days.
Trading day tick-of-day `t`: pre-market 0–59; opening auction t=60; continuous 61–539; closing auction t=540; after-hours 541–719. Accruals (interest, rent, wages, fees) post at day close t=719. Business operations run once per game hour, staggered: an entity runs when `tickOfDay mod 30 == fnv1a32(id) mod 30`.

## G5. Tick pipeline (00 §5.2)

```
P0 ingest  P1 validate  P2 calendar  P3 world(16)  P4 npc(05,16)  P5 ai(11)  P6 match(05,06)
P7 clear(07)  P8 finance(07,08)  P9 real(09,10)  P10 conflict(12)  P11 law(13)  P12 social(14,15)
P13 ledger(03: commit postings atomically, settle/release holds, assert invariants)  P14 emit
```
A phase may read any committed state and the outputs of earlier phases of this tick; it writes only its own module's tables and queues postings for P13. Postings never commit before P13. A failed invariant rolls the tick back and replays it in safe mode. Consequences of tick N that other modules react to land in tick N+1 (via `ctx.send(..., 'NEXT')` or events).

### G6.1 Ports for later modules (dependency inversion)

A module may never import a module built after it. When its rules need data from a later module (for example 05 needs fundamental values from 09 or index weights from 08), it declares a **port**: a TypeScript interface in its own `ports.ts` (e.g. `MarketPorts`), and its factory takes the implementations: `createMarketsModule(ports: Partial<MarketPorts>)`. The later module exports an implementation of that port, and `packages/engine/index.ts` wires them when building the world. A missing port uses the default the spec gives for "module not present" (stated in the card), never an invented rule.

## G8. Determinism rules (02 §3.7, 19 Rule 3.6.2) — lint-enforced in packages/engine

Forbidden in engine code: `Date`, `performance`, `Math.random`, `crypto` randomness, timers, `process`, `globalThis`, `Intl`, `toLocaleString`, `localeCompare`, `async/await`/Promises, `for…in`, iterating `Object.keys/values/entries` of map-like objects, `Map`/`Set` iteration where order matters (use `SortedMap`/`SortedSet`), `Array.sort` without a total comparator (use `sortBy`), `JSON.stringify` for hashing/persistence (use `canonEncode`), `WeakMap/WeakRef`, `Math.exp/log/pow/sin/cos/tan/atan2/cbrt/hypot/...` (use `dmath`), `Math.round` (use `roundHalfEven`), `Number` for money or quantities. Allowed raw math: `+ - * /`, `Math.sqrt/abs/floor/ceil/trunc/min/max/sign/fround/imul/clz32`.
NaN/Infinity are illegal in state. Ties are broken by entity id then intent id. Iterate collections only in sorted order. Rejection sampling is forbidden; each variate uses a fixed number of draws. A module may draw only from its own streams. Split money into parts only with `allocate`. No exceptions for control flow: report impossible states with `ctx.fail`.

## Implementation steps
1. **Corridor (§3.8.1).** `lendingRate = i + w`, `depositRate = i − w`, `w = macro_corridor_halfwidth`; if `negativeRatesAllowed = false` then `depositRate = max(0, i − w)`. `setCorridor` runs at genesis and after every decision (T04-06), updates `cb.facilities.lendingRate/depositRate`, `elaPenaltySpread = 0.015`, `maxTermDays = 7`, and calls `putFact(ctx, 'FACILITY_RATE_E6', ccy, roundHalfEven(lendingRate × 1e6))` (03 uses it for the automatic conversion). 07 keeps its interbank rate inside the corridor; 04 only publishes the rates (`macro.cb.decision.corridor`).
2. **Reserve requirement (§3.8.2).** `cb.reserveRequirement` from `macro_rr_<bloc>` (FU 1%, EC 1%, PL 5%, NA 1%, SC 10%; key names `macro_rr_fdl`, `macro_rr_eun`, `macro_rr_pyn`, `macro_rr_nkr`, `macro_rr_srl` of the `macro_rr_*` family). `adjustRr`: SRL only; `DEFENCE` (called by T04-14 in a currency defence) `+0.02`, cap 0.20; `EASING` (called by T04-06 after a cut) `−0.02` if no EASING change yet this quarter, floor at the default. Each change emits `macro.cb.tool` `RR_CHANGE` (PUBLIC). 07 measures eligible deposits and reads `rr` through T04-20's api (`rr(store, bloc)`).
3. **Interest on reserves (§3.8.2), day close (P8), per bank in sorted id order.** `ports.credit.bankReserves(store, bankId)` gives `balance` (current account, excluding the deposit facility earmark of step 8), `required`. `tierBase = min(balance, 3 × required)` (`iorTierMultiple = 3`), `excess = balance − tierBase`. `tierInterest = half-even(tierBase × i / 364)`, `excessInterest = half-even(excess × depositRate / 364)`. Each positive part: player-economy bank (`ports.players.ownerGroupOf` chain ends at a `chr`, i.e. 03 perimeter PLAYER) → `ledger.mint(bankId, amt, ccy, 'CBK_IOR_P')` (FAUCET, 24 §8); world bank → `ledger.pay(cbkId, bankId, amt, ccy, 'CBK_IOR_W')`. Each negative part (negative policy or deposit rate, EUN and NKR only, edge 2): player bank → `ledger.burn(bankId, |amt|, ccy, 'CBK_NEGATIVE_RATE_CHARGE_P')` (SINK, registered here), world bank → `ledger.pay(bankId, cbkId, |amt|, ccy, 'CBK_NEGATIVE_RATE_CHARGE_W')` (TRANSFER). `ports.credit = null` → nothing (no banks exist, edge 18). The FAUCET is counted by 03's flow accounting, which the Stabilizer sees (exploit 6).
4. **Reserve penalty.** 07 applies and posts it (04 §3.8.2 and 07 both say so): `reservePenalty = half-even(shortfall × (lendingRate + 0.02) / 364)` with codes `CBK_RESERVE_PENALTY_P` (SINK) and `CBK_RESERVE_PENALTY_W` (TRANSFER) registered here; 04 exports `reservePenaltyRate`. 04 posts no penalty itself.
5. **Collateral (§3.8.3).** `classifyCollateral`: `ports.assets.assetInfo` → `GOV` with `issuerBloc = b` → OWN_GOV, other bloc → OTHER_GOV, `CORP` → CORP, `ABS_SENIOR`/`COVERED` → ABS_COVERED, `EQUITY` → EQUITY; `ports.credit.isLoanClaim` non-null → CREDIT_CLAIM; else OTHER (ineligible). Grade: sovereigns `lowestOfTwoBest(ports.funds.sovereignGrades(govId))`, others `ports.funds.gradeOf(assetId)`; `gradeBucket`: AAA..AA- → AAA_AA, A+..A- → A, BBB+..BBB- → BBB, BB+..BB- → BB, lower → BELOW, null → unrated (ineligible except CREDIT_CLAIM/EQUITY under ELA). Haircuts (`macro_cb_haircut_*` family; keys `macro_cb_haircut_<kind>_<bucket>`, defaults the table): OWN_GOV 0.01/0.02/0.04/0.15 (BB only with crisis waiver = a CSF program ACTIVE for the bloc, T04-14 row), OTHER_GOV 0.03/0.05/0.10, CORP 0.05/0.07/0.12, ABS_COVERED 0.08/0.12/0.20; ELA adds CREDIT_CLAIM 0.30 and EQUITY 0.40 (ELA mode only). Add `0.005 × max(0, yearsToMaturity − 5)` where maturity is known. Value = `ports.markets.fairPriceOf` × qty, falling back to `effectiveMark` (03); a missing price makes the line ineligible. `postHaircut = Σ value × (1 − haircut)` (half-even per line).
6. **`bank.cb.repo` (§4).** Validate in P1: schema; `ports.credit` null → `CBK_NOT_ELIGIBLE` (edge 18); actor is Held (13, `ports.players.isHeld`) → `CBK_NOT_ELIGIBLE`; `isCounterparty` false → `CBK_NOT_ELIGIBLE`; `termDays ∈ 1..7`, or 91 only while `cb.ltroOpenUntilTick > tick` (T04-09 opens LTRO in an emergency or a crisis POLICY phase), else `CBK_NOT_ELIGIBLE`; any line ineligible → `CBK_COLLATERAL_INELIGIBLE`; qty above `availableQty − ports.credit.pledgedQty` → `CBK_COLLATERAL_INELIGIBLE`; `postHaircut < amount` → `CBK_HAIRCUT_SHORT`. On success place one `holds.placeQty` per line (expires at maturity + 1 day, ref = new facility id) so the collateral cannot be sold; 07 reads `mac.facility` for its pledge view and handles top-up calls (edge 15). Apply in P6: `openFacility` writes `FacilityLoan` (`kind` REPO, or LTRO for 91 days, `rate` = lendingRate, LTRO at `i`), `ledger.cbCredit(cbkId, bankId, amount, ccy, 'CBK_STANDING_FACILITY', { sub: loanId })` (03 canonical code; 04 §3.18's `CBK_REPO_OPEN` maps to it under R23), emits `macro.cb.repo` PARTIES (subject bankId; bank, amount, term, collateral summary).
7. **Accrual, maturity, repay.** `accrueFacilities` at day close: `accrued += half-even(amount × rate / 364)`. At the maturity day close (or `bank.cb.repoRepay`: own facility, `available(bankId) ≥ amount + accrued`, else `CBK_NOT_ELIGIBLE`; early repayment pays interest to date), `closeFacility`: `ledger.cbCreditUnwind(bankId, cbkId, amount, ccy, 'CBK_STANDING_FACILITY_REPAY' | 'CBK_EMERGENCY_LIQUIDITY_REPAY', { sub: loanId })`, `ledger.pay(bankId, cbkId, accrued, ccy, 'CBK_FACILITY_INTEREST')` (03 TRANSFER, R23 over 04 §3.18's SINK/TRANSFER split), release holds, status REPAID. A bank short of reserves at maturity goes negative and 03 converts it to an overnight facility at the close (T03-15); no special path.
8. **Deposit facility.** `bank.cb.deposit`: chartered in the bloc (`ports.credit.isChartered`), amount ≤ `available`; apply P8: `holds.placeCash(bankId, ccy, amount, MAX_TICK, depositRowId)` (the earmark), `DepositFacilityBalance.amount += amount`. `bank.cb.depositWithdraw`: amount ≤ balance; `holds.reduce`. Day close `postDepositFacilityInterest`: `half-even(amount × depositRate / 364)`; positive → `CBK_DEPOSIT_INTEREST_P` (mint, FAUCET per 24 §8) or `CBK_DEPOSIT_INTEREST_W` (pay); negative → the two charge codes of step 3 (edge 2).
9. **Automatic facilities (03 §3.3.4).** At DAY_OPEN (P2) `repayAutomaticFacilities`: for each account of `cbkId(b)` with chart code 1307 and sub starting `sf:` and non-zero balance dated the previous game day, `ledger.cbCreditUnwind(bank, cbk, amt, ccy, 'CBK_STANDING_FACILITY_REPAY', { sub })` and `ledger.pay(bank, cbk, half-even(amt × lendingRate / 364), ccy, 'CBK_FACILITY_INTEREST')`.
10. **ELA (§3.8.4).** `bank.cb.elaRequest` P1: `ports.credit` non-null, chartered bank, `ports.credit.solvencyOk` (capital ratio ≥ minimum) else `CBK_ELA_INSOLVENT`; collateral in ELA mode, short → `CBK_HAIRCUT_SHORT`; holds placed. Apply: `ctx.send(cbkId(b), 'mac.ela.request', {...}, 'NEXT')`. Next tick P8: re-check solvency; refused → release holds and emit `macro.cb.ela` PARTIES with `{ refused: 'CBK_ELA_INSOLVENT' }` (07's resolution procedure runs from its own solvency checks); granted → `FacilityLoan` kind ELA, rate `lendingRate + 0.015`, term 90 game days, `ledger.cbCredit(..., 'CBK_EMERGENCY_LIQUIDITY', { sub })`, emit `macro.cb.ela` PARTIES and a SEALED copy with subject `regId(b)` (bloc regulator, 13). ELA balance increases `cb.balanceSheet.elaOutstanding`.
11. **Disclosure (L11).** `facilityDaily` at day close emits `macro.cb.facility.daily` PUBLIC with bloc aggregates only: repo outstanding, LTRO outstanding, ELA outstanding, deposit facility total, count of counterparties bucketed (0, 1–3, 4+); no ids, no names. Repo and ELA events are PARTIES (never PUBLIC).
12. **Codes registered by this card (rows for T03-05 `registerReasonCodes`, called from T04-21):** `CBK_NEGATIVE_RATE_CHARGE_P` SINK (BURN), `CBK_NEGATIVE_RATE_CHARGE_W` TRANSFER (PAY), `CBK_RESERVE_PENALTY_P` SINK (BURN), `CBK_RESERVE_PENALTY_W` TRANSFER (PAY). Owner module 04 (07 may request the penalty codes; the rows list `mayRequest: [4, 7]`).

# SPEC EXCERPTS (verbatim; binding game rules)

**[04 §1 Purpose]** (context)

## §1 Purpose

The macro layer is the one shared state every price, business, loan and property in the world reads (V3 Part 2.4). It exists so that:

1. **Prices have reasons.** A rate hike, a CPI surprise, a downgrade or a currency defence hits bonds, mortgages, growth stocks, bank margins, cap rates, carry trades and leveraged funds on the same tick, through named transmission channels that the "Why it moved" ladder (05 §3.12) can cite.
2. **Recessions are caused, not random** (old 01 §5.3). Imbalances (credit growth, valuation stretch, an inverted curve, tight real rates, oil shocks) raise the hazard of a downturn, so a careful player can see one building.
3. **Central banks, treasuries and sovereign bond markets are real machinery** (V3 Part 3.2): policy rates with a corridor, reserves, standing facilities, asset purchases, forward guidance, deficits that are financed by auctions, debt that can be downgraded and restructured, currencies that can be defended and can break.
4. **Crises emerge from rules** (V3 T2) and also arrive on a calibrated schedule so the world has rhythm (one major crisis in about 35% of chapters, storms every game quarter, ripples every game week).
5. **The money stays honest.** The Stabilizer controller keeps the player economy on its designed path, and the Money Supply Index deflates rankings so inflation cannot pump rank (old 01 §8.2–8.3).

#### §3.8.1 Corridor
`lendingRate = i + w`, `depositRate = i − w`, `w = PARAM.macro_corridor_halfwidth = 0.0025`. If `negativeRatesAllowed = false`, `depositRate = max(0, i − w)`. 07 keeps the overnight interbank rate inside `[depositRate, lendingRate]` and reports it.

#### §3.8.2 Reserves and interest on reserves
- Requirement `rr` on eligible deposits of banks chartered in the bloc (07 measures): FU 1%, EC 1%, PL 5%, NA 1%, SC 10% (`PARAM.macro_rr_*`). SC raises `rr` by 2 pp (cap 20%) in a currency defence and lowers it by 2 pp at most once per quarter when easing.
- Interest on reserves at day close: balance up to `iorTierMultiple = 3 ×` required earns `i`; the excess earns `depositRate`. Posted as `CBK_IOR_P` (FAUCET) to player-economy banks, `CBK_IOR_W` (TRANSFER) to NPC banks.
- Shortfall below requirement at day close: penalty `(lendingRate + 0.02) × shortfall × Δ`, `CBK_RESERVE_PENALTY` (SINK for player banks, TRANSFER for NPC banks). 07 applies.

## §8 Edge cases

1. **Policy at the ELB and the rule wants more easing:** rate stays at `elb`; QE logic (§3.8.5) takes over; guidance score is clamped at −1.
2. **Negative rates:** only EC and NA; the deposit facility rate can go negative, reversing the `CBK_DEPOSIT_INTEREST` direction (a charge, class SINK for player banks). 07 passes negative rates to deposits only for corporate deposits above 10M (DEFAULT).
3. **Hyperinflation guard:** `π_core` clamps at 60%; at > 25% for 91 days the hard-peg option opens (§3.13.5); CPI levels are floats (no overflow).
4. **Deflation:** `π_core` floors at −5%; real rates rise mechanically; the rule cuts toward ELB.
5. **A release day with a market-wide halt:** the release still publishes; 05 queues orders; the reopening auction absorbs it.
6. **Weekends:** macro day steps still run (state evolves); releases, meetings and auctions are on trading days only; FX regime breaks happen at the next `t = 45` of a trading day, except SC capital controls, which can start on a weekend day close if a weekend crisis trigger fires (crypto-driven contagion).
7. **Meeting on a day with an emergency already held that week:** the scheduled meeting still occurs; the emergency count resets each quarter.
8. **Two triggers on the same day close:** process in the fixed order of §3.1; only one major can be active; an emergent label during an active major is attached to it as a sub-phase rather than a second major.
9. **Chapter boundary inside a crisis:** crises continue; the chapter counters reset; the scheduler's "final 48 game days" rule applies only to new triggers.
10. **Auction with no player bids:** NPC ladder alone clears it; results are still published.
11. **Auction award rounding:** pro-rata remainders in lots go in hash order; the sum of awards never exceeds offered.
12. **A bidder's cash hold fails at settlement** (cannot happen because the hold is taken at submission; if a hold is released by 13 for a Held character, the bid is cancelled at P1 of the auction tick and the auction clears without it).
13. **Capital controls while a player holds SRL cash and an FDL margin call (07):** margin calls in another currency are met from that currency first; if impossible, 07 liquidates FDL positions; SRL cannot be converted at level ≥ 2. This is intended crisis risk and shown on the margin forecast (RSK-03).
14. **Restructuring vote by a holder whose bonds are lent out (07 securities lending):** the vote belongs to the borrower holding the bonds at the snapshot (as in real markets); lenders can recall before the snapshot.
15. **Bonds pledged as CB repo collateral when the line is restructured:** the CB revalues the new bonds; if collateral is short, 07 calls for top-up within 1 game day.
16. **Default of a bloc whose bonds are CCP collateral:** 07 haircut tables react through grades; no special rule.
17. **N_a collapses (world empties):** scale shrinks at most 0.5% per game day and floors at 0.2; nominal quantities shrink smoothly; outstanding debts are not rescaled (only flows and pools scale), so debt/GDP rises if the world shrinks fast, which is reported but capped in hazard z1 by the clamp.
18. **No 07 yet (early builds and unit tests):** the §3.14.4 fallback provides credit inputs; facility intents return `CBK_NOT_ELIGIBLE`.
19. **Release measurement noise moves a print across a threshold** (e.g. the Cycle Committee condition): the committee reads published prints, so noise can delay or hasten a declaration; this is intended.
20. **YCC and QE caps both binding:** the YCC bid shrinks to the remaining capacity; the cap can break; Wire item "YCC under pressure".
21. **Peg break while players hold FX forwards (06):** forwards settle at market; no special rule.
22. **Two blocs meet within the same tick** (cannot happen by calendar; meetings are on distinct trading days of the quarter).
23. **Missing input from another module this day:** last value holds; the event log records `macro.input.stale` (internal) for 20.
24. **Stabilizer with a tiny population:** OBSERVE mode below 03's `PARAM.stab_min_sample` engaged characters (03 §3.7.5); MSI per 03 §3.8.
25. **Stabilizer lever at a bound for more than 14 real days:** emits an internal alert to 21's admin console and 20; no automatic widening (Mathis or live-ops decide).

## §9 Exploits and counters

| # | Exploit | Counter |
|---|---|---|
| 1 | Trading on a release before others see it | releases apply in P2 of the release tick; orders for that tick were sealed in P0 before publication; news and fills publish together at P14 (02, old 01 §9) |
| 2 | Predicting releases or meetings from the seed | world seed is server-secret, entropy commit-reveal (02); clients never run the macro step |
| 3 | Inferring planned crises from server behaviour | planned shocks and lengths are SEALED internal state; the public sees only real state changes (§2.4 rule), identical in shape for a 10-day or a 30-day event |
| 4 | Cornering an auction to squeeze shorts | 35% award cap per beneficial-owner group (15 links alts); ECA surveillance (05/13) on auction-plus-secondary patterns; NPC dealer ladder always bids |
| 5 | Alts splitting bids to dodge the cap | owner-group aggregation by 15's link graph; awards to flagged groups are reduced to the cap at settlement |
| 6 | Interest-on-reserves farming (park cash in a player bank to earn the policy rate) | tiered remuneration: only up to 3× required reserves earns the policy rate, the rest the deposit rate; IOR is a counted FAUCET the Stabilizer sees; banking charters cost and carry capital rules (07, 13) |
| 7 | Borrowing at the standing facility to lend at a profit | the facility rate is the corridor ceiling (penalty rate) and needs haircut collateral; profitable only when markets are stressed, which is the intended role |
| 8 | Pushing a sovereign into default to profit from CDS | a default requires deterministic triggers (§3.12.1) driven by fundamentals and auctions; market pressure alone moves the market PD, not the model hazard; coordinated false stories are S5 manipulation (05, 13); legitimate speculation against a weak sovereign is allowed (it is real finance) |
| 9 | Speculative attack on the SRL band | intended gameplay; the CB defends with real orders, rate hikes and controls; attackers face carry cost (high SRL rates), controls risk and the possibility the CB holds |
| 10 | Bribing a governor, a statistics office or an agency | crimes under 12/13 (bribery S5); the macro engine ignores bribes (no mechanical effect), so the only gain is information already in the public data or 12's insider-tip mechanics |
| 11 | Lobbying a stimulus to pump one's own businesses | lawful lobbying (16) is allowed and the program applies to every firm in the sector, including rivals; incentives have budgets; bribery is separate (13) |
| 12 | Gaming the Stabilizer (alts at the designed path to bias the median) | population is 03's engaged set weighted by activity (03 §3.7.2); the median is robust; 15's alt detection removes linked accounts from the population |
| 13 | Gaming MSI to change NWI ranks | MSI is a common divisor for everyone, so it cannot reorder players at one time; it affects only cross-time comparisons |
| 14 | Exploiting capital-control timing (convert just before controls) | controls start at the next tick after the break rule fires at `t = 45`, and the break is preceded by public pressure (reserves, EMP); this is intended "read the warning signs" play; a level-1 levy applies first in most paths |
| 15 | Voting a restructuring with borrowed bonds | allowed (real-world rule); 07 lenders can recall before the snapshot; collusion between linked accounts is voided by 15 |
| 16 | Forcing a CB emergency cut by crashing the bloc index | emergency triggers need broad stress (index −15% over 5 days, FSI, interbank), which a single whale cannot cheaply produce given 05's depth and the NPC economy size; market manipulation is surveilled |
