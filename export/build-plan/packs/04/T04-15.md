## G4. Time (00 §5.1)

5 real seconds per tick; 720 ticks per game day (= 1 real hour); 30 ticks per game hour; one tick = 2 game minutes. Week = 7 game days (Mon–Fri trading, Sat–Sun weekend). Quarter = 13 weeks = 91 game days, months 28/28/35 days. Year = 364 game days = 262,080 ticks. Chapter = 8 real weeks = 1,344 game days. Real day = 24 game days.
Trading day tick-of-day `t`: pre-market 0–59; opening auction t=60; continuous 61–539; closing auction t=540; after-hours 541–719. Accruals (interest, rent, wages, fees) post at day close t=719. Business operations run once per game hour, staggered: an entity runs when `tickOfDay mod 30 == fnv1a32(id) mod 30`.

## G5. Tick pipeline (00 §5.2)

```
P0 ingest  P1 validate  P2 calendar  P3 world(16)  P4 npc(05,16)  P5 ai(11)  P6 match(05,06)
P7 clear(07)  P8 finance(07,08)  P9 real(09,10)  P10 conflict(12)  P11 law(13)  P12 social(14,15)
P13 ledger(03: commit postings atomically, settle/release holds, assert invariants)  P14 emit
```
A phase may read any committed state and the outputs of earlier phases of this tick; it writes only its own module's tables and queues postings for P13. Postings never commit before P13. A failed invariant rolls the tick back and replays it in safe mode. Consequences of tick N that other modules react to land in tick N+1 (via `ctx.send(..., 'NEXT')` or events).

### G6.1 Ports for later modules (dependency inversion)

A module may never import a module built after it. When its rules need data from a later module (for example 05 needs fundamental values from 09 or index weights from 08), it declares a **port**: a TypeScript interface in its own `ports.ts` (e.g. `MarketPorts`), and its factory takes the implementations: `createMarketsModule(ports: Partial<MarketPorts>)`. The later module exports an implementation of that port, and `packages/engine/index.ts` wires them when building the world. A missing port uses the default the spec gives for "module not present" (stated in the card), never an invented rule.

## G8. Determinism rules (02 §3.7, 19 Rule 3.6.2) — lint-enforced in packages/engine

Forbidden in engine code: `Date`, `performance`, `Math.random`, `crypto` randomness, timers, `process`, `globalThis`, `Intl`, `toLocaleString`, `localeCompare`, `async/await`/Promises, `for…in`, iterating `Object.keys/values/entries` of map-like objects, `Map`/`Set` iteration where order matters (use `SortedMap`/`SortedSet`), `Array.sort` without a total comparator (use `sortBy`), `JSON.stringify` for hashing/persistence (use `canonEncode`), `WeakMap/WeakRef`, `Math.exp/log/pow/sin/cos/tan/atan2/cbrt/hypot/...` (use `dmath`), `Math.round` (use `roundHalfEven`), `Number` for money or quantities. Allowed raw math: `+ - * /`, `Math.sqrt/abs/floor/ceil/trunc/min/max/sign/fround/imul/clz32`.
NaN/Infinity are illegal in state. Ties are broken by entity id then intent id. Iterate collections only in sorted order. Rejection sampling is forbidden; each variate uses a fixed number of draws. A module may draw only from its own streams. Split money into parts only with `allocate`. No exceptions for control flow: report impossible states with `ctx.fail`.

## Implementation steps
1. **Order inside the hour.** At each game hour boundary (P2, `cal.boundaries` HOUR), `hourlyFsi` reads the components first, then `hourlyFear` uses the new FSI. Both use only state committed at the end of the previous tick.
2. **Fear (§3.14.1).** Inputs: `rv21Gx = ports.markets.rv21Gx` (annualized, 21 trading days), `gxReturnToday = ports.markets.gxReturnToday` (since the day open), `gxReturn63d` from the GX level history (`ports.markets.gxLevel` daily closes kept in `DailyHistoryRow.equityIndex` of the GLOBAL row; the lookback is 63 trading days on the FDL calendar, `gxLevelNow / equityIndex(d63) − 1`, and 0 until that row exists, E-93 (3)), `creditSpreadIdx = igCreditSpreadIndex / mean364(igCreditSpreadIndex)` (`ports.assets.igCreditSpreadIndex`, history kept daily), `FSI` this hour, `crisisTerm`, tension and hack rate from the input snapshot (genesis 30 and 0). Any null input → its last value (genesis neutral values: rv 0.16, csi 1, returns 0) and the key enters the day's stale list (edge 23). Held hourly values live in the `mac.inputs` row `HOURLY`, never in `INPUTS` (E-93 (2)). HOURLY keys added by E-103 (3), (4), both written and read only here, both in the hashed snapshot, neither ever in `staleKeys` except as stated: (a) `igClose.<d>`, `d` a game day as a base-10 integer ≥ 0 without leading zeros; value a finite number in the unit of `igCreditSpreadIndex`, the last non-null hourly read of day `d` (a null read leaves the key as it is). Retention: only `d` in `[today − 363, today]`; every call deletes every `igClose.<d>` with `d ≤ today − 364`, not only the key exactly 364 days back, so a day with no read leaves no orphan; at most 364 keys. `mean364` = the mean over the keys present in that window, csi 1 when none. (b) `gxReturn63d`: a number, the fraction `gxLevelNow / equityIndex(d63) − 1`, retained until overwritten. Hold rule: if the GLOBAL row of `d63` does not exist (warm-up), `r63 = 0` and nothing is held or listed. Otherwise, if `gxLevelNow` and the row's `equityIndex` are both non-null and `equityIndex > 0`, write `gxReturn63d` and use it; else (either is null) use the held `gxReturn63d`, or 0 when none is held, and list `gxReturn63d` in `staleKeys`. A null `gxLevelNow` lists `gxReturn63d` even in warm-up. A persistent null holds indefinitely and never faults (E-93 (5)); the daily `macro.input.stale` carries the key. `F ← stepFear(F, fearRaw)`; genesis `F = 22`; RA = `1 − F/50`. Emit `macro.fear` PUBLIC (F, RA) every hour. 06 reads `impliedVolAnchor` (DEFAULT; 06 owns the surface).
3. **FSI (§3.14.2).** Components: interbank spread over the policy rate (`ports.credit.creditAggregates(...).interbankSpread`, weighted by `gdpShare0`; with 07 present and any bloc's aggregates null the composite holds its last value and `fsi.interbank` is stale, with no renormalization; null without 07, edge 18, then 0 and never an emergency trigger; E-93 (3)), repo haircut index change vs its 1-year mean (`ports.credit.repoHaircutIndexChange`, points), CCP default fund usage share (`ports.credit.ccpDefaultFundUsage`), NPC bank equity drawdown from the 364-day high (`ports.markets.bankEquityDrawdown364(store, 'WORLD')`), IG credit spread level (`ports.assets.igCreditSpreadIndex`, decimal), largest stablecoin depeg (`ports.assets.maxStablecoinDepeg`), ETF discount index (`ports.funds.etfDiscountIndex`), largest sovereign `stressIndex` over the five blocs. Each normalized `clamp(value/divisor, 0, 1)`, then the weighted sum. Emit `macro.fsi` PUBLIC with FSI and the normalized components every hour; `GlobalMacroState.financialStressIndex` is the value T04-06, T04-07, T04-09 and T04-14 read.
4. **World trade (§3.14.3)**, day close: `GlobalMacroState` keeps two values (E-94 (a)). `tariffBase` is the policy tariff set by 16, genesis 0.03. `tariffLevel` is the tariff the world sees, genesis 0.03. Each close: `tariffBase ← stepTariff(tariffBase, [ports.world.tariffDelta(store, tick)])` (16), then `tariffLevel = effectiveTariff(tariffBase, activeShockSum('tariff_level'))` (TRADE_WAR, T04-18). A STEP shock lifts the level while it is active and drops out on its end day. The clamp never removes part of the base, so the level returns to the base exactly (this replaces the E-93 (3) day-over-day rule). Example 1: base 0.03, TRADE_WAR +0.10 active → level 0.13. Example 2: base 0.35, same shock → level 0.40 (capped), and 0.35 again when it ends; `WTI = 100 × (Σ gdpShare0_b × realGdpIndex_b/100)^1.5 × ((1 − tariff)/0.97)²`; history keeps it (T04-03 trade z, T04-04 trade channel).
5. Exploit 16 note: no single input can move FSI or F to an emergency level; the weights and divisors above are the only path.

# SPEC EXCERPTS (verbatim; binding game rules)

**[04 §1 Purpose]** (context)

## §1 Purpose

The macro layer is the one shared state every price, business, loan and property in the world reads (V3 Part 2.4). It exists so that:

1. **Prices have reasons.** A rate hike, a CPI surprise, a downgrade or a currency defence hits bonds, mortgages, growth stocks, bank margins, cap rates, carry trades and leveraged funds on the same tick, through named transmission channels that the "Why it moved" ladder (05 §3.12) can cite.
2. **Recessions are caused, not random** (old 01 §5.3). Imbalances (credit growth, valuation stretch, an inverted curve, tight real rates, oil shocks) raise the hazard of a downturn, so a careful player can see one building.
3. **Central banks, treasuries and sovereign bond markets are real machinery** (V3 Part 3.2): policy rates with a corridor, reserves, standing facilities, asset purchases, forward guidance, deficits that are financed by auctions, debt that can be downgraded and restructured, currencies that can be defended and can break.
4. **Crises emerge from rules** (V3 T2) and also arrive on a calibrated schedule so the world has rhythm (one major crisis in about 35% of chapters, storms every game quarter, ripples every game week).
5. **The money stays honest.** The Stabilizer controller keeps the player economy on its designed path, and the Money Supply Index deflates rankings so inflation cannot pump rank (old 01 §8.2–8.3).

#### §3.14.1 Fear Index F (0–100, every game hour)
`F_raw = 100 × σ( −1.2 + 3.0 × (rv21_GX − 0.16)/0.16 + 2.0 × (creditSpreadIdx − 1) + 2.5 × FSI + 1.0 × crisisTerm + 0.8 × (geopoliticalTension − 50)/50 + 0.5 × (worldHackRate − 50)/50 + 2.0 × max(0, −r_GX,today)/0.03 − 0.5 × r_GX,63d/0.10 )`

- `F ← F + (F_raw − F) × (1 − 2^(−1/2))` per game hour (2-hour half-life). Genesis `F = 22`.

- 06 derives the implied-volatility level from F (06 owns the surface; DEFAULT anchor `IV_ATM,GX ≈ 0.10 + 0.004 × F`).

## §8 Edge cases

1. **Policy at the ELB and the rule wants more easing:** rate stays at `elb`; QE logic (§3.8.5) takes over; guidance score is clamped at −1.
2. **Negative rates:** only EC and NA; the deposit facility rate can go negative, reversing the `CBK_DEPOSIT_INTEREST` direction (a charge, class SINK for player banks). 07 passes negative rates to deposits only for corporate deposits above 10M (DEFAULT).
3. **Hyperinflation guard:** `π_core` clamps at 60%; at > 25% for 91 days the hard-peg option opens (§3.13.5); CPI levels are floats (no overflow).
4. **Deflation:** `π_core` floors at −5%; real rates rise mechanically; the rule cuts toward ELB.
5. **A release day with a market-wide halt:** the release still publishes; 05 queues orders; the reopening auction absorbs it.
6. **Weekends:** macro day steps still run (state evolves); releases, meetings and auctions are on trading days only; FX regime breaks happen at the next `t = 45` of a trading day, except SC capital controls, which can start on a weekend day close if a weekend crisis trigger fires (crypto-driven contagion).
7. **Meeting on a day with an emergency already held that week:** the scheduled meeting still occurs; the emergency count resets each quarter.
8. **Two triggers on the same day close:** process in the fixed order of §3.1; only one major can be active; an emergent label during an active major is attached to it as a sub-phase rather than a second major.
9. **Chapter boundary inside a crisis:** crises continue; the chapter counters reset; the scheduler's "final 48 game days" rule applies only to new triggers.
10. **Auction with no player bids:** NPC ladder alone clears it; results are still published.
11. **Auction award rounding:** pro-rata remainders in lots go in hash order; the sum of awards never exceeds offered.
12. **A bidder's cash hold fails at settlement** (cannot happen because the hold is taken at submission; if a hold is released by 13 for a Held character, the bid is cancelled at P1 of the auction tick and the auction clears without it).
13. **Capital controls while a player holds SRL cash and an FDL margin call (07):** margin calls in another currency are met from that currency first; if impossible, 07 liquidates FDL positions; SRL cannot be converted at level ≥ 2. This is intended crisis risk and shown on the margin forecast (RSK-03).
14. **Restructuring vote by a holder whose bonds are lent out (07 securities lending):** the vote belongs to the borrower holding the bonds at the snapshot (as in real markets); lenders can recall before the snapshot.
15. **Bonds pledged as CB repo collateral when the line is restructured:** the CB revalues the new bonds; if collateral is short, 07 calls for top-up within 1 game day.
16. **Default of a bloc whose bonds are CCP collateral:** 07 haircut tables react through grades; no special rule.
17. **N_a collapses (world empties):** scale shrinks at most 0.5% per game day and floors at 0.2; nominal quantities shrink smoothly; outstanding debts are not rescaled (only flows and pools scale), so debt/GDP rises if the world shrinks fast, which is reported but capped in hazard z1 by the clamp.
18. **No 07 yet (early builds and unit tests):** the §3.14.4 fallback provides credit inputs; facility intents return `CBK_NOT_ELIGIBLE`.
19. **Release measurement noise moves a print across a threshold** (e.g. the Cycle Committee condition): the committee reads published prints, so noise can delay or hasten a declaration; this is intended.
20. **YCC and QE caps both binding:** the YCC bid shrinks to the remaining capacity; the cap can break; Wire item "YCC under pressure".
21. **Peg break while players hold FX forwards (06):** forwards settle at market; no special rule.
22. **Two blocs meet within the same tick** (cannot happen by calendar; meetings are on distinct trading days of the quarter).
23. **Missing input from another module this day:** last value holds; the event log records `macro.input.stale` (internal) for 20.
24. **Stabilizer with a tiny population:** OBSERVE mode below 03's `PARAM.stab_min_sample` engaged characters (03 §3.7.5); MSI per 03 §3.8.
