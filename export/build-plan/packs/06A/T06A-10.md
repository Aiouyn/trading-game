## G4. Time (00 §5.1)

5 real seconds per tick; 720 ticks per game day (= 1 real hour); 30 ticks per game hour; one tick = 2 game minutes. Week = 7 game days (Mon–Fri trading, Sat–Sun weekend). Quarter = 13 weeks = 91 game days, months 28/28/35 days. Year = 364 game days = 262,080 ticks. Chapter = 8 real weeks = 1,344 game days. Real day = 24 game days.
Trading day tick-of-day `t`: pre-market 0–59; opening auction t=60; continuous 61–539; closing auction t=540; after-hours 541–719. Accruals (interest, rent, wages, fees) post at day close t=719. Business operations run once per game hour, staggered: an entity runs when `tickOfDay mod 30 == fnv1a32(id) mod 30`.

## G5. Tick pipeline (00 §5.2)

```
P0 ingest  P1 validate  P2 calendar  P3 world(16)  P4 npc(05,16)  P5 ai(11)  P6 match(05,06)
P7 clear(07)  P8 finance(07,08)  P9 real(09,10)  P10 conflict(12)  P11 law(13)  P12 social(14,15)
P13 ledger(03: commit postings atomically, settle/release holds, assert invariants)  P14 emit
```
A phase may read any committed state and the outputs of earlier phases of this tick; it writes only its own module's tables and queues postings for P13. Postings never commit before P13. A failed invariant rolls the tick back and replays it in safe mode. Consequences of tick N that other modules react to land in tick N+1 (via `ctx.send(..., 'NEXT')` or events).

### G6.1 Ports for later modules (dependency inversion)

A module may never import a module built after it. When its rules need data from a later module (for example 05 needs fundamental values from 09 or index weights from 08), it declares a **port**: a TypeScript interface in its own `ports.ts` (e.g. `MarketPorts`), and its factory takes the implementations: `createMarketsModule(ports: Partial<MarketPorts>)`. The later module exports an implementation of that port, and `packages/engine/index.ts` wires them when building the world. A missing port uses the default the spec gives for "module not present" (stated in the card), never an invented rule.

## G8. Determinism rules (02 §3.7, 19 Rule 3.6.2) — lint-enforced in packages/engine

Forbidden in engine code: `Date`, `performance`, `Math.random`, `crypto` randomness, timers, `process`, `globalThis`, `Intl`, `toLocaleString`, `localeCompare`, `async/await`/Promises, `for…in`, iterating `Object.keys/values/entries` of map-like objects, `Map`/`Set` iteration where order matters (use `SortedMap`/`SortedSet`), `Array.sort` without a total comparator (use `sortBy`), `JSON.stringify` for hashing/persistence (use `canonEncode`), `WeakMap/WeakRef`, `Math.exp/log/pow/sin/cos/tan/atan2/cbrt/hypot/...` (use `dmath`), `Math.round` (use `roundHalfEven`), `Number` for money or quantities. Allowed raw math: `+ - * /`, `Math.sqrt/abs/floor/ceil/trunc/min/max/sign/fround/imul/clz32`.
NaN/Infinity are illegal in state. Ties are broken by entity id then intent id. Iterate collections only in sorted order. Rejection sampling is forbidden; each variate uses a fixed number of draws. A module may draw only from its own streams. Split money into parts only with `allocate`. No exceptions for control flow: report impossible states with `ctx.fail`.

## Implementation steps
1. PD_P (§3.8.1), hourly in P2 at `t mod 30 == 0` for every issuer with outstanding bonds, loans visible to 07 or CDS: listed issuer: `E` = Σ shares × `markPrice`, `DP` = short-term debt + 0.5 × long-term debt, `D_total`, `σ_E` = 60-game-day EWMA of daily log returns of official closes (λ = 0.94 per trading day over the last 60 game days of bars, annualised × √260 because a game year has 52 weeks × 5 trading days), `r` = bloc 1y govt zero. Unlisted (player co not listed, NPC private firm): `E = max(1, EV_09 − D_total)`, `σ_E = 1.2·σ_sector`. Bank (`bnk`): `bankPd`. Sovereign: `sovereignPd` from 04 (06 does not model sovereign solvency).
2. Spread (§3.8.2): `fear = F/100` of the previous game hour; `PD_Q`, `h`, LGD table, `liq_bps` using the issue's outstanding face (per bond; the CreditState stores the issuer-level `spreadBpsBySeniority` using the issuer's largest issue), `spread_bps = 10,000·h·LGD + liq_bps`. Ratings never enter (they create cliffs elsewhere). Store `CreditState`; emit `mkt.credit.state` PUBLIC `{issuer, pdBand, spreads}` hourly.
3. Default (§3.8.3, D100): `recordMissedPayment` stores `BondState.missedDueTick/missedAmount`, sets `pdPhysical1y = max(PD, 0.5)` until paid (edge 6). `defaultCheckStep` at each DAY_CLOSE: retry the full missed amount if issuer available cash suffices (post the coupon/principal with the original codes, clear the miss, PD recomputes normally); else if `(tick − missedDueTick)/720 ≥ graceDaysFor` → `declareDefault('MISSED_PAYMENT')`. Grace: `bond_grace_days` (3) for corporate/bank; sovereign `macro_sov_grace_days` (7) (R29). Also default on: 09 BANKRUPTCY (via `onBankruptcyFiled` hook), 09 ACCELERATION unpaid within grace (same grace clock starting at the acceleration tick), 04 restructuring or moratorium. On default: every bond of the issuer status DEFAULTED, `BondState.accruedStop = true`, venue → `ven_DISTRESSED` (trades flat), `recoveryEstimate` from 09 (`ports.companies.recoveryEstimate`) or 04 (`sovereignRecovery`), emit `mkt.bond.default` PUBLIC and `mkt.asset.status`. No RNG is used anywhere in this file (06#15, D099); the registered stream `ast.recovery:<issuerId>` is never drawn (recoveries come from 09/04 and the DISTRESSED auction).
4. Recovery delivery at plan confirmation (09) or sovereign terms (04): `distributeRecovery` posts cash `BOND_DEFAULT_RECOVERY` issuer → holders pro rata (`proRata`) and moves new instruments (`moveQty`, same code); old bonds MATURED/DELISTED. Sovereign restructuring (edge 7): old bonds exchange into new bonds per 04's terms at the effective tick (`SOV_RESTRUCTURING_EXCHANGE` via `moveQty`), linkers keep indexation (new linker rows copy `inflationIndexBase`); 06B receives the RESTRUCTURING credit event.
5. Edge 19: a player company taken private keeps its bonds and CDS; PD switches to the unlisted method automatically because `financials.isListed === false`.
6. Callable bonds (§3.8.4): Hull-White one-factor trinomial lattice fitted to the bloc govt zero curve, mean reversion 0.05, vol 0.01, 64 steps to maturity, deterministic; backward induction with `value = min(continuation, callPrice)` at call dates, discount adds the credit spread; V passed as the anchor instead of the bullet DCF. Call: 09 notice ≥ 5 game days before a call date; at the call tick post `BOND_REDEMPTION` at the call price × face/100 plus accrued `BOND_COUPON`, status MATURED.

# SPEC EXCERPTS (verbatim; binding game rules)

**[06 §1 Purpose]** (context)

## §1 Purpose

This module defines **every tradeable thing in the world** and the rules that are specific to its asset class: what an instrument is (fields), what it is worth (its fundamental value, which 05's price model pulls toward), how it pays (dividends, coupons, funding, settlement), how it is created and destroyed (listing, series generation, issuance, expiry, default, delisting), who may trade it (licenses), how it is marked for net worth, and every class-specific event (earnings, splits, credit events, depegs, auctions).

Division of labour, binding:
- **05** owns *how* prices move tick to tick (the return equation, GARCH, jumps, factor model, batch auction, NPC market makers, square-root impact, halts). 06 owns *what* each asset's fundamental value `V_i` is, its class parameters (`PriceParams`, §3.21), and everything that is not the generic order book: OTC and RFQ fills (P6), DeFi venues, primary auctions, collectible auctions, option exercise, futures settlement, perp funding, coupons and corporate actions.
- **07** owns margin, collateral haircuts, securities lending, repo and the Clearing House. 06 tags each instrument with its `marginClass`, `collateralClass` and `clearing` service.
- **08** owns ETF creation and redemption, rating agencies, securitization tranches and fund units. 06 defines ETF and index instruments and their NAV.
- **09** owns company decisions (dividend amount, buybacks, issuance, M&A, bankruptcy, IPOs). 06 executes the security-level consequences.

Design laws (from 01 §0 and V3 T1–T3, kept):
1. Every price has a cause a player could have seen or inferred. Each class's `V_i` is a function of world state, never a random walk.
2. Parities hold by construction where they hold in reality (forward = CIP, put-call parity via NPC arbitrage, ETF ≈ NAV, cross FX from legs). Residual arbitrage after fees is ≤ fees.
3. Each class differs where the difference creates a decision (MASTER-BIBLE T02): fundamentals, sentiment, liquidity, financing, sessions and liquidation rules.
4. Defaults, depegs and failures are **mechanical outcomes of balance sheets**, never dice rolls with a fixed probability.

**Status of numbers:** every `PARAM.*` value in this module, and every choice tagged `DEFAULT`, is `DEFAULT (Mathis may override)`. Locked decisions L1–L15 (00) and the 00 time model are not defaults. The full list is in `_notes/06-notes.md`.

<!-- excerpt 06§3.8.1 -->
**[06 §3.8.1]** (from spec file 06-ASSET-CLASSES.md)

#### §3.8.1 Physical PD (hourly, per issuer)
- Listed issuer (Merton/KMV approximation): `E` = market cap from marks; `DP` = short-term debt + 0.5 × long-term debt (09 balance sheet); `σ_E` = 60-game-day EWMA realized equity vol; `A = E + D_total`; `σ_A = σ_E · E / A`;
  `DD = (ln(A / DP) + (r − 0.5σ_A²)·1) / σ_A`; `PD_P = N(−DD)` clamped to `[0.0003, 0.60]`.
- Unlisted issuer (player company not listed, NPC private firm): `E = max(1, EV_09 − D_total)`, `σ_E = σ_sector · 1.2`, then as above.
- Bank issuer (`bnk`): `PD_P = max(Merton PD, PD from CET1)`, where `PD_CET1 = 0.0003 · exp(60 · max(0, 0.10 − CET1))` (07 publishes CET1); an IN_RESOLUTION bank has `PD_P = 1`.
- Sovereign: 04 supplies `PD_P` (debt dynamics, rollover, reserves). 06 does not model sovereign solvency.


<!-- excerpt 06§3.8.2 -->
**[06 §3.8.2]** (from spec file 06-ASSET-CLASSES.md)

#### §3.8.2 Spread
```
PD_Q     = N( N⁻¹(PD_P) + λ_mpr ),   λ_mpr = 0.25 + 0.5 · fear           (market price of risk)
h        = −ln(1 − PD_Q)                                                  (hazard per game year)
LGD      = SOVEREIGN 0.60 | SENIOR_SECURED 0.35 | SENIOR_UNSECURED 0.55 | SUBORDINATED 0.75 | AT1 0.90
liq_bps  = clamp( 15 · (1 + 2·fear) · sqrt(500M / max(outstanding, 10M)), 5, 200 )
spread_bps(seniority) = 10,000 · h · LGD + liq_bps
```
Recovery implied by LGD lands inside the 20–60% range of 01 §3.6. Ratings (08) do not enter the formula; they create **cliffs** through rules elsewhere: index eligibility (IG index excludes sub-IG; NPC index funds sell within 5 game days), 07 collateral eligibility, fund mandates (08).


<!-- excerpt 06§3.8.3 -->
**[06 §3.8.3]** (from spec file 06-ASSET-CLASSES.md)

#### §3.8.3 Default is mechanical
A bond defaults only when (a) the issuer fails to pay a coupon or principal by `PARAM.bond_grace_days = 3` game days after the due date (except sovereign issuers, which use 04 §3.12's `PARAM.macro_sov_grace_days = 7`; a CDS FAILURE_TO_PAY on a sovereign reference uses 7 too) because its deposit balance is insufficient (03 posting fails), (b) the issuer files bankruptcy (09), (c) a covenant acceleration (09) is not paid within grace, or (d) for sovereigns, 04 declares a restructuring or moratorium. On default: status DEFAULTED, accrued interest stops, trades flat on DISTRESSED, `recoveryEstimate` set by 09 (corporate) or 04 (sovereign), CDS credit event process starts (§3.17.4). Recovery cash or new instruments are delivered when 09's plan confirms; holders' positions convert at P13.


<!-- excerpt 06§3.8.4 -->
**[06 §3.8.4]** (from spec file 06-ASSET-CLASSES.md)

#### §3.8.4 Callable bonds
Issuer (09) may call on a call date with 5 game days notice; priced with a deterministic lattice (Hull-White one-factor on the bloc `govt` curve, mean reversion 0.05, vol 0.01, 64 steps) for V. Callable bonds are rare (10% of corporate issues by default).
