## G4. Time (00 §5.1)

5 real seconds per tick; 720 ticks per game day (= 1 real hour); 30 ticks per game hour; one tick = 2 game minutes. Week = 7 game days (Mon–Fri trading, Sat–Sun weekend). Quarter = 13 weeks = 91 game days, months 28/28/35 days. Year = 364 game days = 262,080 ticks. Chapter = 8 real weeks = 1,344 game days. Real day = 24 game days.
Trading day tick-of-day `t`: pre-market 0–59; opening auction t=60; continuous 61–539; closing auction t=540; after-hours 541–719. Accruals (interest, rent, wages, fees) post at day close t=719. Business operations run once per game hour, staggered: an entity runs when `tickOfDay mod 30 == fnv1a32(id) mod 30`.

## G5. Tick pipeline (00 §5.2)

```
P0 ingest  P1 validate  P2 calendar  P3 world(16)  P4 npc(05,16)  P5 ai(11)  P6 match(05,06)
P7 clear(07)  P8 finance(07,08)  P9 real(09,10)  P10 conflict(12)  P11 law(13)  P12 social(14,15)
P13 ledger(03: commit postings atomically, settle/release holds, assert invariants)  P14 emit
```
A phase may read any committed state and the outputs of earlier phases of this tick; it writes only its own module's tables and queues postings for P13. Postings never commit before P13. A failed invariant rolls the tick back and replays it in safe mode. Consequences of tick N that other modules react to land in tick N+1 (via `ctx.send(..., 'NEXT')` or events).

### G6.1 Ports for later modules (dependency inversion)

A module may never import a module built after it. When its rules need data from a later module (for example 05 needs fundamental values from 09 or index weights from 08), it declares a **port**: a TypeScript interface in its own `ports.ts` (e.g. `MarketPorts`), and its factory takes the implementations: `createMarketsModule(ports: Partial<MarketPorts>)`. The later module exports an implementation of that port, and `packages/engine/index.ts` wires them when building the world. A missing port uses the default the spec gives for "module not present" (stated in the card), never an invented rule.

## G8. Determinism rules (02 §3.7, 19 Rule 3.6.2) — lint-enforced in packages/engine

Forbidden in engine code: `Date`, `performance`, `Math.random`, `crypto` randomness, timers, `process`, `globalThis`, `Intl`, `toLocaleString`, `localeCompare`, `async/await`/Promises, `for…in`, iterating `Object.keys/values/entries` of map-like objects, `Map`/`Set` iteration where order matters (use `SortedMap`/`SortedSet`), `Array.sort` without a total comparator (use `sortBy`), `JSON.stringify` for hashing/persistence (use `canonEncode`), `WeakMap/WeakRef`, `Math.exp/log/pow/sin/cos/tan/atan2/cbrt/hypot/...` (use `dmath`), `Math.round` (use `roundHalfEven`), `Number` for money or quantities. Allowed raw math: `+ - * /`, `Math.sqrt/abs/floor/ceil/trunc/min/max/sign/fround/imul/clz32`.
NaN/Infinity are illegal in state. Ties are broken by entity id then intent id. Iterate collections only in sorted order. Rejection sampling is forbidden; each variate uses a fixed number of draws. A module may draw only from its own streams. Split money into parts only with `allocate`. No exceptions for control flow: report impossible states with `ctx.fail`.

## Goal
"P1 checks used by every module" (19 §12.2). One cheap, read-only function answers "may this actor do this now?" for every intent class, and one place holds frozen assets. Modules call the gate; they do not read 13A tables.

## Implementation steps
1. The subject is `onBehalfOf ?? actorId`, resolved to the controlling character through the owner chain (03 §5.3), so a company owned by a Held character is gated too.
2. Held (13 §3.10): MANUAL_TRADE, OP_LAUNCH, LAW_FILE and PURCHASE are rejected `LAW_HELD`, unless `viaMandate` (AI within mandate) or `standing` (standing orders stay live). Defence actions and chat reads are OTHER and pass.
3. Op ban: OP_LAUNCH → `LAW_OP_BANNED` while `tick < untilTick`.
4. Licence suspension: LICENSED_TRADE on a SUSPENDED licence is allowed only with `closingOnly` (T14A-07 owns the licence state; the gate reads it).
5. Op lock (13 §3.6): OP_LAUNCH with a `targetId` that is the accuser of an open case against the subject → `LAW_OP_LOCK_ACCUSER`.
6. Freeze: `placeFreeze` places T03-08 holds totalling `1.2 × claim` (amount from 13B), or 30% as bond when `bond`; held positions stay marked and cannot be sold. It refuses if the result would breach the floor (T13A-04 `floorRoom`) and freezes only what is above it.
7. 14A ports: `isHeld` = `isHeldAt(tick)`; `handleChangeBlocked` = open defendant flag, Held, or a conviction applied in the last 7 real days (120,960 ticks); `licenseEligibility` → `{eligible:false, reason}` for HELD, SUSPENDED, an active S5 conviction this chapter (CONVICTION_S5_ACTIVE) or UNDER_INVESTIGATION (flag written by 13B; always false until 13B exists).
8. Cost: O(1) indexed reads; the gate never writes and never posts.

## Test plan
  - **AC-13A-06-1** Held character: manual buy rejected `LAW_HELD`; the same buy through an AI mandate is accepted; a standing order fills; a defence action passes.
  - **AC-13A-06-2** a company controlled by a Held character is gated the same way.
  - **AC-13A-06-3** op ban: an op at untilTick − 1 is rejected, and accepted at untilTick.
  - **AC-13A-06-4** a suspended Derivatives licence allows a closing order and rejects an opening order.
  - **AC-13A-06-5** a freeze places holds of 1.2 × claim, or 0.3 × claim as bond; frozen positions cannot be sold; the floor is never frozen; `releaseFreeze` clears all holds.
  - **AC-13A-06-6** `leverageCapFactorPpm` is 500,000 with an S3+ defendant flag and 1,000,000 with an S2 flag or none.
  - **AC-13A-06-7** the 14A ports replace `DEFAULT_PORTS` in T14A-11 wiring, and 14A's handle-change and licence tests pass with them.

  - **AC-13A-06-HELD-LAW** (E-24): the gate classes `law.post_bond`, `law.offer_settlement`, `law.accept_settlement` and `law.appeal` as OTHER (allowed while Held). `law.file_case` is LAW_FILE (blocked).

# SPEC EXCERPTS (verbatim; binding game rules)

**[13 §1 Purpose]** (context)

## §1 Purpose

1. Turn 12's raw events into a fair, deterministic justice system: evidence must be discovered (it costs money and time), guilt is probabilistic, and money can shade a close case but never buy a verdict.
2. Price crime: a sanction schedule by severity (S1–S6) as a percentage of net worth, split sink/victim-fund/whistleblower, with restitution always owed in full.
3. Give victims recourse: insurance, restitution, pre-trial measures, a victim compensation fund, case-selling, counter-suits, revenge discounts.
4. Guarantee no permanent ruin: no op, day or verdict takes a character below the $5,000 + one T1 business floor (L-floor principle).
5. Run four regulators with finite attention that players can steer but not spam.
6. Enforce anti-grief caps (shared with 12 §3.10) and void linked-account schemes (15 collusion graph).

Design principles kept from old vision 03 §0: every op leaves evidence; detection ≠ attribution; victims always have recourse; no permanent ruin; legibility before commitment; every money flow tagged sink/transfer; abstract fiction only.

### §3.6 Pre-trial measures

- **Asset freeze:** on an S4+ claim with evidence ≥ 55, the claimant may ask the court to freeze `1.2 × claim` of the defendant's assets (positions stay marked, cannot be sold). Defendant Reputation ≥ 60 may post a 30% bond instead. Reputation < 30 → the freeze is automatic.
- **Leverage cap:** a defendant in an active case of severity S3 or higher trades at half their license leverage (applied by 07's margin and buying-power rules, 07 §3.15.2; 05 only passes the result; ruling in 24).
- **Op lock:** a defendant cannot launch ops against their own accuser while the case is open (12 §4.1 BLOCKED).

### §3.10 Held (the freeze equivalent)

A Held character is frozen, not wiped. Duration 6 h (S5) or 12 h (S6), +6 h for repeat, max 24 real hours/verdict and 48/chapter. During Held: no manual trading, ops, filing or buying. Businesses run at 70%, AIs keep running within their mandate, standing orders stay live, defense keeps running. Grace: Held starts 1 game day (1 real hour) after the verdict so the player can de-risk. Margin calls during Held liquidate at fair value with the markets band (05), never at a crashed print. The Held screen (14) shows the countdown, live P&L and read-only chat.

Resolves old roadmap Q8: Held applies only in the online world; in a solo sandbox it is off (fines, op bans and record only), because freezing a solo session is a rage-quit. DEFAULT (Mathis may override).

## §9 Player intents

Namespace `law.*`. Rate limit 20/tick. Each shows the evidence score, the burden needed, and the likely outcome before confirming.

- `law.open_investigation { triple, suspectId }` — opens an Investigation (max 3 active). 
- `law.run_action { investigationId, action }` — buys an investigation action (§4 table).
- `law.file_case { triple, venue, claimMoney, counselGrade }` — only when evidence ≥ the venue bar; pays the 1% court fee.
- `law.offer_settlement { caseId, amount }` / `law.accept_settlement { caseId }`.
- `law.plead { caseId, guilty, nameCoConspirator? }`.
- `law.request_freeze { caseId }` — pre-trial asset freeze (S4+, evidence ≥ 55).
- `law.post_bond { caseId }` — defendant posts 30% bond instead of a freeze (Reputation ≥ 60).
- `law.appeal { caseId, grounds }`.
- `law.sell_case { caseId, assigneeId, share }` — assign a claim for 30–50% of the award.
- `law.report { subjectId, triple }` — whistleblower report.
- `law.file_insurance_claim { policyId, perilRef }`.
- `law.counter_suit { caseId }` — defendant files defamation-by-false-filing (malicious prosecution, §4).
- `law.set_bounty { triple, amount }` — public evidence bounty (paid on conviction, pro-rata by points).

Validation examples: `file_case` refused below the venue bar; `request_freeze` refused below S4/evidence 55; `appeal` refused without new evidence ≥ 10 or a procedural flag; `sell_case` share clamped to [0.30, 0.50]; all actions between linked accounts VOIDED and flagged.
