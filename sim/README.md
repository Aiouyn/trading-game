# Meme coin price-action sandbox (memecoin-v3)

Snapshot of the standalone sandbox used to calibrate the launchpad (Pump.fun-style) price simulation.

- `code/` – simulator versions (COH-v15.x = cohort/emotion NPC model, core-pf = exact Pump.fun curve)
- `flow/` – trade-flow measurement scripts
- `corpus/` – real-coin corpus scripts and summary stats (raw parquet trade data excluded)
- `refs-real/` – reference charts of real coins
- `charts-v15.8/` – latest real-vs-sim chart pairs
- `pumpfun-audit.md` – Pump.fun curve/fee audit with sources
