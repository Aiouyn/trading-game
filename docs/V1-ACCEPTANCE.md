# V1 acceptance matrix (Phase 9, track 9A)

Every row of the tape specs in `docs/team/specs/tape-*.md` (one table per spec file): id, one-line claim, status, the covering test (file and test name, or the ruling that defers it) and the command that runs it.

Every PASS names a Vitest file and a test (it or describe with an executable it) that ran green in the full Vitest run of this pass (the log is recorded in docs/V1-PHASE9.md). A describe whose tests are all todo or skip does not count. Rows marked NOT RUN name a Playwright spec or a balance harness that was not executed here. Re-run any row with its command.

**Status words.** PASS: the covering test ran and passed in this pass. PARTIAL: part of the row is covered and passes; the rest of the spec claim (named in the row) is not met or not written. FAIL: the covering test failed. NOT RUN: a Playwright spec or a balance harness covers the row, but it was not executed in this pass (its last recorded result is in the spec or the phase doc). NOT BUILT: no code or test for the row in this build. DEFERRED: a lead, Ledger or Mathis ruling moves it out of v1 (the ruling is named). N/A: the row is about a surface this build does not have (the reason is given).

X and N rows in the company and STONKS specs take the worst status of the gates they name (order: FAIL, NOT BUILT, DEFERRED, NOT RUN, PARTIAL, PASS).
